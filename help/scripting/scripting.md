# スクリプティング

プラグインを記述することでアプリケーションを制御することができます。 プラグインは、バージョン&#x200B;**3.9**&#x200B;を使用して&#x200B;**Python**&#x200B;スクリプト言語で記述できます。 アプリケーションで提供されるPython APIを使用すると、スクリプトから直接さまざまな機能にアクセスして使用できます。

[Python](https://www.python.org/)は、多くの業界で広く使用されているスクリプト言語です。 自動化、ワークフローの高速化、アセット管理ツールなどの構築に役立ちます。 APIドキュメントには、メインメニューから&#x200B;**ヘルプ** > **スクリプトドキュメント…**&#x200B;アクションでアクセスできます。
