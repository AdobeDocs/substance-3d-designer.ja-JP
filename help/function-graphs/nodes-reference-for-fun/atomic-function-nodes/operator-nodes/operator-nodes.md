# 演算子ノード

演算子ノードを使用すると、入力ノードに対して古典的な数学演算を実行できます。

![](operator-nodes.resources/image2015-12-23-10-55-31.png)

>[!NOTE]
>
> 除算とモジュロの場合、除数は下側入力になります。
> 
> 減算の場合、減算は下位入力でもあります。
