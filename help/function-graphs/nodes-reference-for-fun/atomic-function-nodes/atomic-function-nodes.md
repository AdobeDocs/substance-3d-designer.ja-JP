# アトミック関数ノード

グラフ[&#128279;](../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md)のアトミックノードと同様に、Substance関数グラフのアトミックノードは、その種類のグラフの最小ノード単位です。

目的に応じて、いくつかのカテゴリに分類できます。

| [定数](../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/constant-nodes/constant-nodes.md) | 浮動小数 | - | 浮動小数 | 一定浮動小数値を定義します（例： 0.1） |
|                                                                                                                                        | Float2 | - | Float2 | 2つの浮動小数値の定数ベクトルを定義します（例： 0.1、0.2） |
