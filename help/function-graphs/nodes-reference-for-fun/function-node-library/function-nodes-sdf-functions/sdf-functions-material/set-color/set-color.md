## 説明

SDF シーンのマテリアルのbase colorを設定します。

この色は、[Shape splatter v2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md)の&#x200B;*SDF color*&#x200B;出力のすべてのスプラッタSDFシェイプについて取得できます。

## 入力

|                            |                                  |
|----------------------------|----------------------------------|
| <b>SDF シーン</b> *浮動小数* | 入力SDF シーン。 |
| <b>Base color</b> *浮動小数3* | 設定するbase color値。 |
