# P軸回転

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![P回転アイコン](./3d-sdf-transform-rotate-p.png "P回転")

<b>イン：</b> SDF 関数 >変形

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

軸の周りでワールド空間を調整可能な角度で回転させます。<br>出力変換されたワールド位置は、ほとんどのSDF 関数の<b>P</b>入力に接続して、この変換されたワールド空間で定義できます。<br><br><b>3Dビューア</b>の<b>変形ピボット</b> ヘルパーを使用して、実行されたローテーションを視覚化します。<br><br><i>ヒント：</i> P変形は連鎖できますが、結果は処理順序に依存することに注意してください。

## 入力

|  |  |
| :--- | :--- |
| <b>角度</b> *フロート* | ワールド空間を回転する角度。<br><br><b>3Dビューアー</b>の<b>変形基点</b>ヘルパーの角度を円で表示します。 <b>軸</b>の矢印がこの円の中心になるようにカメラを合わせると、回転角度が回転の数分の1であることが明確になります。 |
| <b>軸</b> *浮動小数点3* | ワールド空間を回転させる軸を定義する正規化されたベクトルです。<br>例： (0, 1, 0)は、ピボットポイントのY軸を中心にワールド空間を回転させます。<br><br><b>3Dビューアー</b>の<b>変形ピボット</b> ヘルパーの矢印で軸を表示します。 矢印の色は、このベクトルのXYZ成分にマップされます。<br><br><i>既定： (0, 1, 0)</i> |
| <b>ピボットの位置</b> *浮動小数点3* | 回転の原点を定義するピボットのワールド空間位置。<br><br><b>3Dビューアー</b>の<b>ピボットの変形</b> ヘルパーの矢印の始点にピボット点が表示されます。 |
| <b>P</b> *浮動小数3* | ワールド空間の位置。 この入力を使用して、<b>Offset P</b>および<b>Rotate P</b>ノードを使用する他の変換を適用します。<br><br><i>既定：変換されていないワールド空間の位置。</i> |
