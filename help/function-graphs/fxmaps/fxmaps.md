# FXMaps

**FX-Mapノードでは、プロシージャル画像を作成できます**。 これは、Substanceテクノロジの最も強力な機能の1つです。

FX-Mapは、マルコフチェーンと呼ばれる特殊な種類のグラフを表します。 マルコフチェーンは単純なコアプロセスです。イメージを繰り返し複製し、再分割します。 各ステップで、画像を自由に回転、変換、ブレンドできます。 単純なパターンから複雑なノイズまで、様々な結果が得られます。 FX-Mapsは、Substance 3D Designerと一緒にインストールされる多くのサンプルSubstanceの基盤です。

## FX-Map グラフの作成

FX-Mapグラフを表示するには、[FX-Mapノード](../../compositing-graphs/nodes-reference-for-com/atomic-nodes/fx-map/fx-map.md)を[Substanceグラフ](../../compositing-graphs/substance-compositing-graphs.md)に追加し、ノードを右クリックしてCMD + Eキー(OS X)またはCTRL + Eキー(Windows)を押してグラフを開きます。 このFX-Map グラフは、 グラフパネルの新しいタブに表示されます。このタブをクリックすると、このグラフとSubstanceグラフを切り替えることができます。

## FX-Mapsとは何ですか？

FX-Mapsの最も一般的な用途は、ストライプやレンガなどの繰り返しパターンや、パーリン、ブラウン、ガウスノイズなどのノイズを作成することです。 ノイズは、Dirt、Dust、コンクリート、石の表面、液体の飛び散りなど、有機的で自然に見えるテクスチャを作成する場合に特に便利です。

FX-MapグラフはSubstanceグラフと同じようには機能しません。Substanceグラフでは、各ノードが独立しており、グラフ全体におけるノードの位置を把握する必要はなく、イメージデータの送信元や送信先にも影響しません。

次の章で、3つのFX-Map グラフノードについて詳しく説明します。ただし、各FX-Mapノードは、次の3つの操作のいずれかを提供しています。

### 四分割

これにより、グラフのこのステップの画像が4つの四半円に分割されます。 これは最も一般的なノードタイプです。 クアドラントノードのチェーンは、複雑なパターンだけでなく、非常に複雑な外観の画像を作成することができます。

実際、クアッドツリーグラフでは、クアッドノードはレベル（つまり&#x200B;**オクターブ**）を表します。 FX-Mapグラフでは、ツリー内の各レベルを1つのクアドラントで表すことで、このツリー構造を非表示にします。クアドラントノードを別のノードに接続するたびに、実際には完全なツリーレベルが作成されます。

この「カンニング」テクニックの目的は、木のすべてのレベルで個々のノードを表す必要をなくすことです。つまり、4つの深度レイヤの後に、4 x 4 x 4 x 4のノードを使用する必要があります。これは、256個の個々のノードです。 代わりに、各象限ノードはツリー内のどのレベルにあるかを「認識」し、それに応じてイメージを生成します。

これは多くの読者にはあまり理解できないかもしれませんが、これについては後ほど詳しく説明します。

### 反復

右側のコネクターに渡された画像と、左側のコネクターに渡された画像を、設定された反復数だけ繰り返します。

このノードは、1つまたは複数のダイナミック関数グラフで使用されることが最も多く、入力イメージを繰り返しごとに移動または回転します。

### スイッチ

これは2つの入力を取り、セレクターの設定で定義されているように、一方または他方を切り替えるだけです。 反復ノードと同様に、セレクター設定は多くの場合、ダイナミック関数によって選択されます。

## FX-Mapsシステム変数

FX-Mapsはシステム変数をサポートしています。 これらの変数は常にドル記号(「$」)で始まり、次のようになります。

| 名前 | 特殊性 | データ型 | 目的 |
| --- | --- | --- | --- |
| $time | - | float1 | この変数は、レンダリングエンジンが開始されてからの時間を秒単位で返します。時間に応じてアニメーション化する必要があるSubstanceに最適です。 (E.g. 時計の針。)Substance Playerを含む一部のアプリケーションでは、$timeを使用するSubstanceは、ユーザーインターフェイスにタイムラインを表示します。 |
| 深度($C) | - | float1 | FX-Mapノードのオクターブ（レベル）番号を返します。 これにより、ノードが表すクアッドツリーのレベルに応じてノードの動作を変更できます。 |
| $depthpow2 | - | float1 | 上記と同様ですが、オクターブ（レベル）数の累乗で2を返します。 これは、一般的な計算に役立つヘルパー値です。 |
| $number | ノードのみを反復 | float1 | 描かれたパターンの番号を返します。 これはIterateノードを制御するダイナミック関数グラフがアクセスでき、各反復ステップでの振る舞いを変更することができます（$numberは1ではなく0から数え始めることに注意してください）。 |
| $size | - | 浮動小数 2 | 現在のノードのサイズ（ピクセル単位）を返します。 |
| $sizelog2 | - | 浮動小数 2 | 上記と同様ですが、サイズを2の累乗値で返します（例： 2048\*2048画像の場合、$sizelog2は11を返します）。 |
| $pos | クアドラントノードのみ | 浮動小数 2 | パターンの発生位置を返します。 結果は常に0 ～ 1の値になります。 |
