# PBR ユーティリティ

このカテゴリには、PBRマテリアルを操作するためのヘルパーノードが含まれています。 このエフェクトは、「Specular光沢」と「メタリックの粗さ」の両方のPBRワークフローで使用することを目的としています。 すべてのノードはマルチチャンネルマテリアルを対象としており、チャンネルをアクティブ化（非）して、1つまたは両方のワークフローをサポートすることができます。

以下のノードは特に有用です。

* [ベースマテリアル](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/base-material/base-material.md)
* [PBRベースカラー/メタリックの検証](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/pbr-basecolor-metallic/pbr-basecolor-metallic-validate.md)
* [PBR レンダリング](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/pbr-utilities/pbr-render/pbr-render.md)
