## 説明

Specular PBRモデルを使用する場合のSpecular値のユーティリティ「プリセット」ノード。

開始点として正しい値をすばやく取得できるので、チャートから色を選ばないようにします。

<a name="parameters"></a>

## パラメーター

|  |  |
|:---|:---|
| <b>Specular F0</b> <i>プラスチック、木、石、レンガ、砂、コンクリート、布地、錆びた金属、水、氷、ガラス、カスタムIOR</i> | 定義済みのSpecular範囲を選択します。 |
| <b>Specular範囲</b> <i>0.01 - 1.0</i> | 選択したプリセットの範囲内でSpecular値を調整します。 微調整が可能です。 |
| <b>IOR</b> <i>1.0 - 5.0</i> | カスタムIORに設定されている場合にのみ有効になります。 独自の値を選択します。 |
