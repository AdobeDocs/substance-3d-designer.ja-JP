# PBR レンダリング

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![](../../../../../../assets/pbr-render.png){width="250px"}

<b>イン：</b> マテリアルフィルター > PBRユーティリティ

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

Image Based Lighting(IBL)を使用して、球体、プレーン、またはシリンダ上にPBR マテリアルをレンダリングします。これはノード内のレンダリングエンジンで、サムネール、プレビュー、または2Dアセットを生成する場合に非常に便利です。 これは3Dビューのようなレンダリングではなく、グラフに実際にテクスチャを生成するものです。

このノードを使用するには、少なくとも完全なPBR マテリアルが必要です。 リンク作成モードを使用してマテリアルをPBR レンダリングに接続するのが理想的です。 また、ライティングの計算元となるレンダリングには、球状にラップ解除されたHDRI環境が必要です。 テスト用のマテリアルはPBR マテリアルにあります。環境マップはライブラリの[3D ビューにあります。](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/3d-view-library/3d-view-library.md)

</td>
</tr>
</table>

>[!WARNING]
>
> **CPU (SSE2) エンジン**
> 
> PBR レンダリングノードは非常に重く、SSE2 CPU エンジンではうまく動作しません。 エンジンのパフォーマンスが非常に悪い場合は、F9キーを押して別のノードに切り替えます。

<a name="inputs"></a>

## 入力

|  |  |
|:---|:---|
| <b>マテリアルチャンネル入力</b> | 複数のマテリアル入力を使用して、次のジオメトリのマテリアルをレンダリングします：<br><br>-Base color<br> – 標準<br>- Emissive<br>-ラフネス<br>-メタリック<br>-Specular level<br>-Height<br>-Ambient occlusion<br> – 不透明度マスク<br>-Anisotropy level<br>-Anisotropy angle<br>-Translucency<br> – 散乱距離スケール |
| <b>レンズDirtマップ</b> <i>グレースケール入力</i> | レンズフレアの表示中に表示される、レンズのDirtのカスタムマップ |
| <b>レンズアパーチャマップ</b> <i>グレースケール入力</i> | ボケの焦点の外れたシェイプをオーバーライドする場合に使用します。 コントラストが強いほど、より見やすくなります。 テクスチャ内の円のみがサンプリングされることに注意してください。そのため、シェイプはすべて円内に収まっている必要があります。 |
| <b>バックグラウンド入力</b> <i>カラー入力</i> | <b>Background Mode</b>パラメーターが<i>Backgroud Input</i>に設定されている場合に、カスタムマップが背景として使用されます |
| <b>環境マップ</b> <i>カラー入力</i> | 照明の計算に使用する環境マップ。 HDR内で球面にマッピングされている必要があります。 |

<a name="outputs"></a>

## 出力

|  |  |
|:---|:---|
| <b>美しさ</b> | 最終レンダリング |
| <b>未処理の放射照度</b> | 最終レンダリングの放射データ<br><br><i>Alpha:</i>不透明度マップ |
| <b>未加工Specular</b> | 最終レンダリングのSpecularデータ<br><br><i>Alpha:</i> Specularシャドウマップ |
| <b>通常のワールド空間</b> | 最終レンダリングのワールド空間法線データ<br><br><i>Alpha:</i>ワールド空間高さマップ |
| <b>法線の接線空間</b> | 最終レンダリングの正接空間法線データ<br><br><i>Alpha:</i>正接空間高さマップ |
| <b>UV</b> | 最終レンダリングのUVデータ<br><br><i>Alpha:</i>不透明度マップ |

<a name="parameters"></a>

## パラメーター

|  |  |
|:---|:---|
| <b>図形</b> <i>球、平面、円柱</i> | レンダリングに使用するシェイプを設定します。 カスタムシェイプは使用できません。 |
| <b>ディスプレイスメントの適用度</b> <i>0.0 - 0.5</i> | Heightからのディスプレイスメントの強さを設定します。 |
| <b>環境のローテーション</b> <i>0.0 - 1.0</i> | 照明環境を回転します。 カメラを移動する場合と比較して事前に回転します。 |
| <b>背景モード</b> <i>色、環境、環境、背景入力</i> | 背景に表示する内容を設定します。 カラーは単色で、環境はオプションのぼかしを付けて接続したマップです。 アンビエントは環境の非常にぼやけたバージョンです。 |
| <b>背景色</b> <i>（カラー値）</i> | 背景モードが「カラー」に設定されている場合にのみ使用できます。 |
| <b>環境の背景のぼかし</b> <i>0.0 - 1.0</i> | 背景モードが「環境」に設定されている場合にのみ使用できます。 |
| <b>図形</b> |  |
| <b>スケール</b> <i>0.0 - 2.0</i> | 球のスケールを設定します。 |
| <b>平面サイズ</b> <i>0.0 - 1.0</i> | 平面の尺度を設定します。 |
| <b>円柱の半径</b> <i>0.0 - 1.0</i> | 円柱の半径を設定します。 |
| <b>円柱の長さ</b> <i>0.0 - 1.0</i> | 円柱の長さを設定します。 |
| <b>回転</b> <i>0.0 - 1.0</i> | 照明を回転せずにシェイプを回転します。 |
| <b>回転方向</b> <i>0.0 - 1.0</i> | 2Dの回転軸を設定します。 |
| <b>方向を中心とした回転</b> <i>0.0 - 1.0</i> | 回転軸上でシェイプをスピンします。 |
| <b>図形の位置</b> <i>-1.0 - 1.0</i> | シェイプを移動します。 |
| <b>タイリング</b> <i>1.0 - 6.0</i> | タイリング量を設定します。 |
| <b>球UV スケール</b> <i>0.0 - 4.0</i> | 球体上のUVのスケールを設定します。 |
| <b>平面UV スケール</b> <i>1.0 - 4.0</i> | 平面上のUVの尺度を設定します。 |
| <b>シリンダUV スケール</b> <i>1.0 - 6.0</i> | 円柱のUVのスケールを設定します。 |
| <b>UV オフセット</b> <i>0.0 - 1.0</i> | UVのオフセット&grave;s |
| <b>UVのティルト</b> <i>False/True</i> | 球のUVを45度傾けます。 |
| <b>カメラ</b> |  |
| <b>露光量</b> <i>-4.0 - 4.0</i> | カメラの露光量を設定します。 |
| <b>トーンマッパー</b> <i>リニア、ACE、Filmic Hejl</i> | 最終的な画像に使用するトーンマッピングソリューションを設定します。 |
| <b>カメラモード</b> <i>遠近法、正投影</i> | 2つの投影モード間でカメラを切り替えます。 |
| <b>視野</b> <i>0.01 - 100.0</i> | カメラの視野の角度を設定してください |
| <b>距離</b> <i>0.0 - 4.0</i> | オブジェクトの中心からカメラまでの距離を設定します。 |
| <b>周辺光量補正の適用度</b> <i>0.0 - 1.0</i> | ビネット効果の適用度を設定します。 |
| <b>周辺光量補正の半径</b> <i>0.0 - 1.0</i> | ビネット効果の半径を設定します。 |
| <b>画面の位置</b> | オブジェクトの周囲でカメラを移動します。2Dビューでギズモを使用して変更することもできます。 |
| <b>フィールドの深度</b> |  |
| <b>アパーチャの半径</b> <i>0.0 - 0.1</i> | アパーチャの半径を設定します。 値が大きいほど、焦点が外れた領域がぼやけます（ボケ）。 |
| <b>アパーチャブレード</b> <i>3 - 9</i> | ボケぼかしの形状を設定します。 |
| <b>アパーチャリング</b> <i>0.0 - 1.0</i> | ボケのシェイプに内側グラデーションを追加します。 |
| <b>分数のアパーチャ</b> <i>0.0 - 2.0</i> | ボケに色収差を加えます。 |
| <b>渦巻き型のボケ</b> <i>0.0 - 1.0</i> | ぼかし（ボケ）部分にぼかし（渦巻き）効果を追加します。 |
| <b>フォーカスモード</b> <i>自動、ポイント</i> | フォーカスが事前に決定されているか、ユーザーが設定しているかを設定します。 ポイントフォーカス:2Dビューでポイントを移動してフォーカス距離を決定できます。 |
| <b>フォーカスポイント</b> | フォーカスがポイントに設定されている場合は、そのポイントを移動できます。 には2Dビューギズモがあります。 |
| <b>フォーカスのオフセット</b> <i>-0.5 - 0.5</i> | フォーカスが自動に設定されている場合、フォーカスを前後に移動できます。 |
| <b>カスタムアパーチャマップを使用する</b> <i>False/True</i> | 上記の絞り設定をオーバーライドし、絞りマップ入力を使用してボケの形状を決定します。 入力が必要です。 |
| <b>ポストエフェクト</b> |  |
| <b>ポストエフェクトを有効にする</b> <i>False/True</i> | 最終レンダリングの<i>すべて</i>のポストエフェクトを切り替えます。 |
| <b>ブルームの強さ</b> <i>0.0 - 2.0</i> | ブルーム効果の強さを設定します。 |
| <b>ブルームのしきい値</b> <i>0.0 - 2.0</i> | ブルームを表示する下限を設定します。 |
| <b>ブルームクロマシフト</b> <i>0.0 - 1.0</i> |  |
| <b>レンズのハロー強度</b> <i>0.0 - 1.0</i> | レンズハロー効果の強さを設定します。 |
| <b>レンズフレアの適用度</b> <i>0.0 - 1.0</i> | レンズフレアの強さを設定します。 この効果を正しく表示するには、環境の背景からの光が視野に入っていることを確認してください。 |
| <b>レンズDirtの強さ</b> <i>0.0 - 1.0</i> | Dirtマップの効果を設定します。 |
| <b>レンダリング設定</b> |  |
| <b>Diffuse品質</b> <i>16個のサンプル、32個のサンプル、64個のサンプル、128個のサンプル</i> | 拡散反射光マップの品質レベルを切り替えます。 |
| <b>Diffuse Emissiveマルチプライア</b> <i>0.0 - 1.0</i> | 放射パーツが放射に寄与する度合いをコントロールします。 |
| <b>Diffuseシャドウの適用度</b> <i>0.0 - 1.0</i> | 拡散シャドウの強度を制御します。 |
| <b>Specular ディザリング</b> <i>0.0 - 1.0</i> | Specularのディザリング量を設定します。 |
| <b>Specularシャドウマルチプライヤ</b> <i>0.0 - 1.0</i> | Specular反射のシャドウの強さを制御します。 |
| <b>不透明度モード</b> <i>ディザAlphaテスト、シンプルAlphaブレンド</i> | 透明度の適用方法を制御します。 <i>シンプルAlphaブレンド</i>モードは、均一な背景で最も目立ちます。 |
| <b>Ambient occlusionの適用度</b> <i>0.0 - 1.0</i> | 環境オクルージョンのシャドウの強さを設定します。 |
| <b>材料調整</b> |  |
| <b>法線の再計算</b> <i>False/True</i> | 法線は、ディスプレイスメントの強さに従ってHeightマップから再計算されます。 |
| <b>標準の形式</b> <i>DirectX、OpenGL</i> | 法線マップ形式を切り替える（グリーンチャンネルを反転する） |
| <b>誘電体F0入力</b> <i>定数値、Specular level入力</i> | どのドライブのF0値を設定します。 Specular level入力：入力マップによって駆動されます。 |
| <b>誘電体F0</b> <i>0.0 - 0.08</i> | 誘電体F0入力に定数値を選択した場合、このスライダを使用してグローバル値を設定できます。 |
| <b>クリアコート</b> |  |
| <b>クリアコートを有効にする</b> <i>False/True</i> | 入力材料の上に、追加のシンプルなクリアコート層を可能にします。 |
| <b>クリアコートの重さ</b> <i>0.0 - 1.0</i> | クリアコート層の強度を設定します。 |
| <b>Coat specular levelをクリア</b> <i>0.0 - 1.0</i> | クリアコート層の粗さを設定します。 |
| <b>基準レイヤーから法線を継承</b> <i>False/True</i> | クリアコートがベースマテリアルの法線を無視するか使用するかを設定します。 |
| <b>放射体</b> |  |
| <b>Emissive照明を有効にする</b> <i>真/偽</i> | emissive照明の拡散反射光の効果を切り替えます。 |
| <b>放射強度</b> <i>0.0 - 10.0</i> | 放射マップのグローバルマルチプライヤを設定します。 |
| <b>サブサーフェススキャッタリング</b> |  |
| <b>表面化散乱を有効にする</b> <i>真/偽</i> | 最終的なレンダリングの表面化散乱を切り替えます。<br><br><i>注意：</i>表面化散乱では、<b>Translucency</b>の入力値が<i>0.0</i>より高い値である必要があります |
| <b>散乱距離</b> <i>0.0 - 1.0</i> | 散乱効果の最大距離を調整します。<br><br><i>注意：</i>この値は、<b>散乱距離スケール</b>入力値<i>カラーチャンネル単位</i>に乗算されます。 |
| <b>レッドシフト</b> <i>0.0 - 1.0</i> | 散布の赤シフト効果の強度を調整します。 |
| <b>レイリー</b> <i>0.0 - 1.0</i> | スキャッタリングでのレイリー効果の強度を調整します。 |
