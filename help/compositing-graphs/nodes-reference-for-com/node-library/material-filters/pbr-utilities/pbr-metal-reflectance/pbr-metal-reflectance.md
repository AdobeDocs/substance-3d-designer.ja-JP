## 説明

これは、事前に定義された&#x200B;**純粋**&#x200B;金属の正しい反射カラーを返すためのクイックプリセットヘルパーノードです。 メタリックモデルの場合はベースカラーで使用でき、Specular/光沢モデルの場合はSpecularチャンネルで使用できます。

このノードは、純粋な金属の開始点を必要とする場合に便利で、チャートから色を選ばないようにすることができます。
