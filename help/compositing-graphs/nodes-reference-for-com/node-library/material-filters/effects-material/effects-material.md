# 効果（マテリアル）

このカテゴリには、[ウェザリング](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/weathering/weathering.md)のノードと似た、本格的なマテリアル効果を生成するノードが含まれています。ただし、主な違いは、これらの効果のノードは、入力として任意のマテリアルを取ることができるということです。 また、入力としてベイク済みマップが必要で、主にHeightmapです。

良い例としては、[水位](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/water-level/water-level.md)と[Snowカバー](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/effects-material/snow-cover/snow-cover.md)の2つがあります。
