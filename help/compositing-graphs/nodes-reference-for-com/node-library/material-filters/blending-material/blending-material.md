# 描画(マテリアル)

描画カテゴリは、最も重要なマルチチャンネルマテリアルカテゴリの1つです。 これには、複数の同時出力で構成されるマテリアルの結合、切り替え、およびブレンドを目的としたノードが含まれています。

これらのノードを使用すると、大量の作業を節約できますが、ノードを正しく利用するには、[リンク作成モード](../../../../../interface/the-graph-view/link-creation-modes/link-creation-modes.md)について十分に理解する必要があります。

以下のノードから始めることをお勧めします。

* [マルチマテリアルブレンド](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/multi-material-blend/multi-material-blend.md)
* [マテリアル調整ブレンド](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/material-adjustment-blend/material-adjustment-blend.md)
