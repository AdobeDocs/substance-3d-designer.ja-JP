# スキャン処理

このカテゴリは、写真やスキャンをタイリングのフルPBRマテリアルに処理するためのニーズを満たすことを目的としています。 これには、照明を取り除き、境界線を切り抜き、タイリングを向上させる機能を備えたツールの大規模な品揃えが含まれています。
