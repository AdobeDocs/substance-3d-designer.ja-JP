# Atlas Scatter

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![](atlas-scatter.resources/atlas-scatter.png){width="200px"}

<b>イン：</b> マテリアルフィルター > スキャン処理

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

アトラスから要素を抽出し、背景に散乱を付けます。 Atlas入力は、単一のテクスチャシートに配置され、パックされた個々の要素で構成される完全なマテリアルです。 このノードは、[シェイプスプラッター](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter/shape-splatter.md)と同様に、（内部[Atlas Splitter](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/scan-processing/atlas-splitter/atlas-splitter.md)プロセスを使用して）それらを分割し、散乱化します。 Atlas Scatterが機能するには、少なくともアトラスの不透明度マップ入力とHeightマップ入力が必要です。

</td>
</tr>
</table>

>[!NOTE]
>
> Atlas Scatterノードで使用可能な数百の[アトラス](https://source.substance3d.com/allassets?assetType=substanceAtlas)が[Substance Source](https://source.substance3d.com/)で利用できます。

## パラメーター

|  |  |
|:---|:---|
| <b>アトラス入力解像度</b> <i>解像度、1 ～ 12</i> | 完全な入力アトラスの解像度を手動で設定して、良好なパフォーマンスと品質比を確保します。 |
| <b>X金額</b> <i>1 - 64</i> | パターンのX反復の量。 |
| <b>Y金額</b> <i>1 - 64</i> | パターンのY反復の量。 |
| <b>パターン</b> |  |
| <b>パターン範囲</b> <i>0 - 10</i> | 散布するパターンの範囲を定義します。 0に設定すると、すべてのパターンが使用されます。 |
| <b>パターン配布モード</b> <i>ランダム、パターンインデックス、行インデックス、列インデックス</i> | アトラスエレメントが使用される順序を定義します。 |
| <b>パターン分布マップ乗数</b> <i>0.0 - 1.0</i> | 入力画像のグレースケール値の関数でシェイプのパターンを選択します。 |
| <b>パターンの回転</b> <i>0, 90, 180, 270</i> | 選択した度数だけ、各アトラスエレメントに固定回転を適用します。 |
| <b>パターンの回転ランダム</b> <i>0.0 - 1.0</i> | アトラス要素の設定部分にランダムな回転を適用します。 |
| <b>アトラス図形の検出精度</b> <i>単純または小さい図形、複雑または大きい図形、エラーなしモード</i> | シェイプの検出精度を設定します。 精度が高いほど、パフォーマンスへの影響が大きくなります。 |
| <b>アトラスの不透明度を下げる（検出速度を上げる）</b> <i>-4 - 0</i> | 入力アトラスの不透明度マップのダウンスケール比率を制御できます。このマップは、シェイプの検出に使用されます。 解像度が低いとパフォーマンスが向上しますが、精度が低下します。 |
| <b>次より小さい図形を無視</b> <i>0.0 - 1.0</i> | 検出するシェイプの最小サイズを画像全体の比率で表して設定します |
| <b>サイズ</b> |  |
| <b>スケール</b> <i>0.0 - 5.0</i> | 散布シェイプの相対的なスケールを設定します。 |
| <b>ランダムに拡大・縮小</b> <i>0.0 - 1.0</i> | 各散布シェイプにランダムな拡大/縮小を適用するための乗数を定義します。 |
| <b>スケール（重なりを除く）</b> <i>0.0 - 1.0</i> | 重ならないようにシェイプのスケールを小さくします。 |
| <b>スケールマップマルチプライヤ</b> <i>0.0 - 1.0</i> | 入力画像グレースケール値に応じてシェイプのスケールを乗算します。 |
| <b>サイズ</b> <i>0.0 - 1.0</i> | 長さ(X)と幅(Y)で散布シェイプの相対的な拡大・縮小を設定します。 |
| <b>Bg 勾配からのサイズ比</b> <i>0.0 - 1.0</i> | 背景勾配の関数でシェイプのサイズ比を変更します。 |
| <b>アスペクト比を保持</b> <i>0.0 - 1.0</i> | グリッドセルの割合（「X量」と「Y量」の値の割合）ではなく、散乱した図形の元の比率を維持する量を指定します。 |
| <b>位置</b> |  |
| <b>ランダムな配置</b> <i>0.0 - 2.0</i> | グリッドの始点からランダムな方向に各シェイプを動かす乗数。 |
| <b>ランダム配布</b> <i>ガウス、均一</i> | ガウス分布からランダム位置の均一分布に切り替えます。 ガウス分布は、均一分布に比べてより有機的な結果を生み出します。 |
| <b>ベクトルマップマルチプライヤ</b> <i>0.0 - 1.0</i> | マップの赤(X)チャンネルと緑(Y)チャンネルで指定されたベクトルの方向にシェイプを移動するための、ベクトルマップ入力の影響を制御します。 |
| <b>水平方向のオフセット</b> <i>-2.0 - 2.0</i> | X軸に沿った位置オフセットの乗数。 |
| <b>垂直方向のオフセット</b> <i>-2.0 - 2.0</i> | Y軸に沿った位置オフセットの乗数。 |
| <b>枠からはみ出させるオプション</b> <i>シェイプを拡大・縮小、位置を固定</i> | スプラッタは技術的な性質を備えているため、元の位置から2セルを超えるサイズでシェイプを描画することはできません。 シェイプが大きくなりすぎたり、移動されすぎたりした場合、次の2つのオプションがあります。 - 「シェイプを拡大・縮小」を使用すると、境界に達したときにシェイプのサイズが小さくなります。「位置を制限」を使用すると、シェイプが元の位置に戻ります |
| <b>回転</b> |  |
| <b>回転</b> <i>0.0 - 1.0</i> | すべてのシェイプのローカルな回転を制御できます。 |
| <b>ランダムな回転</b> <i>0.0 - 1.0</i> | シェイプごとに適用されるランダムな回転量の乗数。 |
| <b>Bg 勾配からの回転</b> <i>0.0 - 1.0</i> | 背景勾配の機能でシェイプの回転を変更します。 通常、「背景勾配からのサイズ比」パラメーターと組み合わせて使用します。 |
| <b>回転マップ乗数</b> <i>0.0 - 1.0</i> | 入力画像グレースケール値を関数としてシェイプの回転角度を乗算します。 |
| <b>ベクトルマップマルチプライヤ</b> <i>0.0 - 1.0</i> | ベクトル画像入力の関数でシェイプの回転を設定します。 |
| <b>Height</b> |  |
| <b>Heightスケールの自動調整</b> <i>False/True</i> | パターンスケールの機能でHeightを自動調整し、シェイプのHeightを背景のHeightに比例させます。 |
| <b>描画モード</b> <i>ブレンド、Alphaテスト</i> | シェイプのオーバーラップを解決する方法を設定します。 |
| <b>Heightオフセット</b> <i>-1.0 - 1.0</i> | 図形Heightにグローバルオフセットを適用します |
| <b>Heightオフセットランダム</b> <i>0.0 - 1.0</i> | シェイプごとに適用されるランダムHeightオフセットの乗数 |
| <b>Heightオフセットマップマルチプライア</b> <i>0.0 - 1.0</i> | シェイプHeightのオフセットを入力画像グレースケール値の関数で乗算します。 |
| <b>Heightスケール</b> <i>0.0 - 1.0</i> | 散布シェイプのグローバルなHeightスケールを制御できます |
| <b>Heightスケールのランダム</b> <i>0.0 - 1.0</i> | シェイプごとに適用されるランダムHeightスケールの乗数 |
| <b>Heightスケールマップマルチプライヤ</b> <i>0.0 - 1.0</i> | 入力画像グレースケール値を関数としてシェイプHeightスケールを乗算します。 |
| <b>背景に合わせる</b> <i>0.0 - 1.0</i> | 0の場合、シェイプHeightはそのままです。1の場合、シェイプHeightは下にあるHeightの背景によって変形されます。 |
| <b>最適化された滑らかな背景</b> <i>0.0 - 2.0</i> | 背景に合わせてシェイプを変形する際に、シェイプのHeightに適用されるスムージングの量を制御します。 |
| <b>Bg 勾配からの歪み</b> <i>0.0 - 1.0</i> | ローカル背景勾配の機能でシェイプHeightを変形します。背景勾配に対応する線形グラデーションがシェイプHeightに追加されます。 |
| <b>バックグラウンド勾配 Smoothness</b> <i>0.0 - 2.0</i> | 背景の勾配に基づいてシェイプをゆがめたときに、背景の勾配に適用される滑らかさを調整します。 |
| <b>黒ピクセルのカットアウト</b> <i>False/True</i> | パターンの入力値から黒の値を無視します。 |
| <b>パターンベースをフラット化</b> <i>False/True</i> | シェイプの下の背景Heightを統合して、開始時のHeightに合わせることができます。 |
| <b>マスク</b> |  |
| <b>ランダムなマスク</b> <i>0.0 - 1.0</i> | 全体の割合で表されるランダムな量のシェイプをマスクします。 |
| <b>マスクランダムマップマルチプライヤ</b> <i>0.0 - 1.0</i> | グレースケール画像入力の関数でランダムシェイプマスクを設定します。 |
| <b>Bg 勾配からのマスク</b> <i>-1.0 - 1.0</i> | シェイプの位置の背景の勾配に基づいて、シェイプのマスクを制御します。 |
| <b>色</b> |  |
| <b>カラー調整</b> <i>-1.0 - 1.0</i> | 散布されたエレメントのカラーをグローバルに調整できます。 |
| <b>カラーランダム</b> <i>0.0 - 1.0</i> | シェイプごとにカラー値をランダムな量だけシフトする乗数。 |
| <b>背景の色</b> <i>0.0 - 1.0</i> | シェイプのカラーを、その位置にある背景のカラーにシフトします。 |
| <b>標準</b> |  |
| <b>Bg 勾配からの歪み</b> <i>0.0 - 1.0</i> | 背景の法線に従ってシェイプの法線をゆがめます。 |
| <b>標準ランダム</b> <i>0.0 - 1.0</i> | シェイプごとにランダムな量だけシェイプ法線を傾斜させる乗数。 |
| <b>標準の形式</b> <i>DirectX、OpenGL</i> | 法線マップ形式を切り替える（グリーンチャンネルを反転する） |
| <b>粗さ</b> |  |
| <b>ラフネス調整</b> <i>-1.0 - 1.0</i> | グローバルシェイプの粗さをオフセットできます。 |
| <b>背景からのラフネス</b> <i>0.0 - 1.0</i> | シェイプの位置で、シェイプの粗さを背景の粗さにシフトします。 |
| <b>ラフネスランダム</b> <i>0.0 - 1.0</i> | シェイプごとにランダムな量だけラフネスをオフセットする乗数。 |
