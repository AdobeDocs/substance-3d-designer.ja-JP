# テクスチャ生成

テクスチャジェネレータは、入力を必要としないノードです。つまり、イメージを完全にゼロから生成します。 「テクスチャジェネレーター」は「手続き」の別語と考えることができます。

これらは2つのカテゴリに分類されます。

* [ノイズ](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/noises/noises.md)\
  ノイズは、既知のパーリンや雲のノイズと同様に、実際のプロシージャルグラフィック、ランダムなシェイプ、ピクセルです。
* [パターン](../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/patterns.md)\
  パターンの大部分は人工的に見えるシェイプで、多くの追加コントロールを使用してランダム化します。
