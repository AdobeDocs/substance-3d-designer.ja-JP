## 説明

単純で高速なピクセルスケールのノイズです。

## パラメーター

* **回転**: *0.0 ～ 1.0*&#x200B;エフェクトの内部計算を回転します。 これにより、ノイズの見た目が大きく変わる場合があります。1から遠くなるほどエフェクトのピクセルスケールが小さくなり、より目に見える「波」が追加されます。
