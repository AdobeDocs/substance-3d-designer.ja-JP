# ノイズ

ノイズは、有機的で混沌とした見た目のプロシージャルグラフィックです。 ノイズによって生成された出力は、[パターンカテゴリの人工的な形状とは非常に異なって見えます。](../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/patterns.md)

[Substance 3D Designer](https://www.adobe.com/jp/products/substance3d-designer.html)のノイズは、グリット、Dirt、ランダムな伸縮、あらゆる種類の微妙な変化のレイヤーなどに使用できる開始点または詳細レイヤーとして使用できます。

すべてのノイズは解像度に完全に依存しないため、画質を損なうことのないスケールアップまたはスケールダウンが可能です。

ノイズカテゴリーには、次の3つの異なる使用グループがあります。

* 大多数は標準的なノイズであり、広範囲に広がり、多くの場合に有用である。
* 経年劣化マップは、標準的なノイズよりもはるかに多くの深度と詳細を備えた複合ノイズですが、計算速度ははるかに遅くなります。
* メッシュからベイクされたポジションマップを必要とする3D ノイズは、非常に特殊なユースケースを想定しています。

左側の<b>ナビゲーションリスト</b>を使用して、ノイズの下にあるすべてのノードを参照します。
