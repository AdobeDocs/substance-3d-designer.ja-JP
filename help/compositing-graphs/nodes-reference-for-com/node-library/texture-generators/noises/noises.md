# ノイズ

ノイズは有機的で混沌とした見た目のプロシージャルグラフィックです。 ノイズによって生成された出力は、[パターンカテゴリの人工的な形状とは非常に異なって見えます。](../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/patterns.md)

[Substance 3D Designer](https://www.adobe.com/jp/products/substance3d-designer.html)のノイズは、グリット、Dirt、不規則な伸び、微妙なバリエーションのレイヤーなどのあらゆる種類に対して、開始点または詳細レイヤーとして使用できます。

すべてのノイズは解像度に完全に依存しないため、画質を損なう心配なしに結果をスケールアップまたはスケールダウンできます。

Noisesカテゴリには、次の3つの異なる使用グループがあります。

* 大部分は標準的なノイズで、広範囲に広がり、多くの場合に有用です。
* 経年劣化マップは、標準的なノイズよりもはるかに深度と詳細を備えた複合ノイズであり、計算速度が大幅に遅くなります。
* 少なくともメッシュからのベイクされた位置マップを必要とする3Dノイズは、非常に特定のユースケースを目的としています。

左側の<b>ナビゲーションリスト</b>を使用して、「ノイズ」の下にあるすべてのノードを参照します。
