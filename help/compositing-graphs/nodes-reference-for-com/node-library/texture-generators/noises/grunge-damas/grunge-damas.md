## パラメーター

* **バランス** *浮動小数*&#x200B;暗い値と明るい値のバランスを調整します。
* **コントラスト** *浮動小数*&#x200B;画像のコントラストを調整します。
* **反転** *ブーリアン*&#x200B;画像の出力を反転します。`1-x`操作を使用します。
* **非正方形拡張** *ブーリアン*&#x200B;カボチャの補正を有効にし、非正方形の比率で伸縮します。
* アドバンス
  * **ゆがみ** *浮動小数*&#x200B;パターン内のゆがみの量を調整します。
  * **分割数** *整数*&#x200B;パターン内の分割数、つまりグラデーションの繰り返し数を調整します。
  * **波** *整数*&#x200B;パターン内の波の量を調整します。
  * **詳細** *浮動小数*&#x200B;小さいゆがみの強さを調整します。
  * **回転ランダム** *浮動小数*&#x200B;各波の回転のランダム度を調整します。
