## 説明

**経年劣化スプラッシュダスティ**&#x200B;ノードは、汚れた面に液体が飛び散ったような経年劣化マップを生成します。

## パラメーター

* **バランス** *浮動小数*&#x200B;暗い値と明るい値のバランスを調整します。
* **コントラスト** *浮動小数*&#x200B;画像のコントラストを調整します。
* **反転** *ブール値*`1-x`操作を使用して画像の出力を反転します。
* **非正方形拡張** *ブーリアン*&#x200B;カボチャの補正を有効にし、非正方形の比率で伸縮します。
* アドバンス
  * **スプラッシュの量** *浮動小数*&#x200B;表面のスプラッシュの量を調整します。
  * **スプラッシュのゆがみ** *浮動小数*&#x200B;スプラッシュに適用されるワープ効果の強さを調整します。
  * **スプラッシュ/Dirt比** *浮動小数*&#x200B;表面のDirtとスプラッシュの&#x200B;*比*&#x200B;を調整します。
  * **Dirtの範囲** *浮動小数* Dirtの範囲を調整します。
