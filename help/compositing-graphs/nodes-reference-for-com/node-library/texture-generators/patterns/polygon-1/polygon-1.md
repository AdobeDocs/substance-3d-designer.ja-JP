## 説明

調整のための多くのオプションを持つ多角形を生成します。 より単純なバージョンについては、[ポリゴン2](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/polygon-2/polygon-2.md)を参照してください。

## パラメーター

* **辺**: *3 - 32*&#x200B;多角形の辺の数を設定します。
* **分解**: *0.0 ～ 1.0*&#x200B;多角形の「スライス」を離します。
* **三角形のサイズ**: *0.0 ～ 1.0*&#x200B;スライスや三角形のサイズを調整します。 調整をおこなうと、シェイプは1,1だけ分解されます。 完全に連携しています。
* **拡大・縮小**: *0.0 ～ 1.0*&#x200B;図形全体を1つに縮小します。
* **自動スケール**: *偽/真*&#x200B;既定のパラメーターを使用して、多角形の全体がビューに収まるようにスケールを調整します。
* **回転**: *0.0 ～ 1.0*&#x200B;シェイプ全体を回転します。
* **グラデーション**: *False/True*&#x200B;グラデーションスライスまたは三角形をソリッドスライスではなく生成します。 注：この設定を有効にすると、ポリゴン2に似た状態になります。
* **グラデーション反転**: *偽/真*「グラデーション」が有効な場合にグラデーションの方向を反転します。
* **タイル**: *1 - 16*\
  結果をタイルする回数を設定します。
* **非正方形拡張**: *False/True*\
  スカッシュとストレッチを非正方形の比率で補正できます。
* **非正方形タイリング**&#x200B;**:** *偽/真*非正方形拡張が有効な場合、これによりシェイプが押しつぶされずにタイリングされます。
