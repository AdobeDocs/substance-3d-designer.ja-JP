## パラメーター

|  |  |
|:---|:---|
| <b>方向オフセット</b> | 立方体の3DのようなXおよびY回転を可能にします。 2Dプレビューで小さな点を操作することでも実行できます。 |
| <b>サイズ</b> <i>0.0 - 1.0</i> | 立方体の不均等な再スケールを可能にします。 |
| <b>スケール</b> <i>0.0 - 1.0</i> | 立方体全体を均一にスケール変更します。 |
| <b>非正方形拡張</b> <i>False/True</i> | スカッシュとストレッチを非正方形の比率で補正できます。 |
