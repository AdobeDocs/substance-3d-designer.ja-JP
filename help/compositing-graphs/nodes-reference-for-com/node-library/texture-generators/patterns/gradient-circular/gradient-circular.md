# 円形グラデーション

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![](../../../../../../assets/gradient-circular.png){width="128px"}

<b>イン：</b> テクスチャジェネレーター>パターン

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

2つのカスタムポイントで定義されたグレースケールグラデーションを円形に作成します。 この変化はaからbへではなく、第1の点を中心とした回転であり、第2の点から始まり、第2の点で終わります。 結果がタイル表示されないことに注意してください。

</td>
</tr>
</table>

<a name="parameters"></a>

## パラメーター

|  |  |
|:---|:---|
| <b>ポイント1</b> | グラデーションを回転させる1点目は、必ずしも中心に配置する必要はありません。 |
| <b>ポイント2</b> | グラデーションの開始点と終了点の2番目の点。 |
| <b>非正方形拡張</b> <i>False/True</i> | カボチャの補正を有効にし、非正方形の比率で伸縮します。 |
