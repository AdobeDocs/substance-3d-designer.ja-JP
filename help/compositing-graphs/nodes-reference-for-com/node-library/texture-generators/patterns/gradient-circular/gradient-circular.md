## 円形グラデーション

**イン：** *テクスチャジェネレーター**/パターン*

**単純**

</td>
<td style="border: 0;" valign="top">

## 説明

2つのカスタムポイントで定義されたグレースケールグラデーションを円形に作成します。 この変化はaからbへではなく、第1の点を中心とした回転であり、第2の点から始まり、第2の点で終わります。 結果がタイル表示されないことに注意してください。

## パラメーター

* **ポイント1**:\
  グラデーションを回転させる1点目は、必ずしも中心に配置する必要はありません。
* **ポイント2**:\
  グラデーションの開始点と終了点の2番目の点。
* **非正方形拡張**: *False/True*\
  スカッシュとストレッチの非正方形の比率での補正を有効にします。
