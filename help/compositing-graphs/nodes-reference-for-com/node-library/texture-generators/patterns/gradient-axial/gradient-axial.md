## 説明

カスタムで定義された2つのポイント間にグレースケールグラデーションを作成します。 線形グラデーションは任意の角度で作成できますが、結果が常にタイリングされるとは限りません。

<a name="parameters"></a>

## パラメーター

|  |  |
|:---|:---|
| <b>ポイント1</b> | グラデーションの開始点（黒） |
| <b>ポイント2</b> | グラデーションを終了する2番目のポイント（白） |
| <b>非正方形拡張</b> <i>False/True</i> | スカッシュとストレッチの非正方形の比率での補正を有効にします。 |
