**単純**

</td>
<td style="border: 0;" valign="top">

## 説明

カスタムで定義された2つのポイント間にグレースケールグラデーションを作成します。 線形グラデーションは任意の角度で作成できますが、結果が常にタイリングされるとは限りません。

## パラメーター

### パラメーター

* **ポイント1**:\
  グラデーションの開始点（黒）
* **ポイント2**:\
  グラデーションを終了する2番目のポイント（白）
* **非正方形拡張**: *False/True*\
  スカッシュとストレッチの非正方形の比率での補正を有効にします。
