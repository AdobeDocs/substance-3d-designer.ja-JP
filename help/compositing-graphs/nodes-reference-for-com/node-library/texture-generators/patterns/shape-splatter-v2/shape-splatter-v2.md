## 説明

位置、回転、拡大/縮小およびランダム性のコントロールを使用して、仮想<b>3D空間</b>での散布に関する高度な機能を使用して、背景Height面上のシェイプを散乱します。<br><br>ノードは基本的なプリミティブ3D図形を提供し、複雑なカスタム3D図形に対して<b>パターン画像</b>、<b>アトラス</b>、または<b>署名付き距離フィールド(SDF)</b>関数として提供されるカスタム3D図形をサポートします。<br><br>シェイプを配布する<b>いくつかの方法</b>を利用できます。これには、完全に制御するためのカスタム関数の作成も含まれます。<br><br>カスタム<b>密度マップ</b>を使用して、図形を特定の領域に引き寄せることができます。<br><br><i>注意：</i>このノードは、Substance エンジンのCPUバージョン(SSE2 (Windows、Linux)およびNEON (macOS)で使用されるものではありません。

## パラメーター

|                                                   |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|:--------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>職位の配布モード</b> *整数* | 空間に図形を分布させる方法：<br><br>- <b>2Dグリッド：</b>単純な均一グリッド。<br>- <b>ポアソンディスク：</b>使用可能な空間を利用しながら、グリッドのセルをランダムにオフセットしてオーバーラップを防止することを目的としたシミュレーション。<br>- <b>均一：</b>指定された数の図形の均一分布。 より集中的な計算が必要です。<br>- <b>カスタム関数：</b>関数グラフを作成して、図形の分布を定義します。 使用可能な変数は、ノードの説明に一覧表示されます。 |
| <b>位置関数</b> *浮動小数点2* | シェイプの分布を定義するために使用する関数グラフ。<br><br>グラフは、画像内の図形のXY正規化位置のFloat2値を出力します。<br><br>使用可能な変数：<br> - <code>shape.id</code> （フロート）図形の一意の識別子です。<br> - <code>shape.amount</code> （フロート） <b>Amount</b>パラメーターで指定された図形の量です。 |
| <b>X金額</b> *整数* | 配布グリッドの列の量。<br><br>X軸に生成される図形の量です。 |
| <b>Y金額</b> *整数* | 分配グリッドの行数。<br><br>Y軸上で生成される図形の数です。 |
| <b>金額</b> *整数* | 生成されるシェイプの量。 |
| <b>標準形式の出力</b> *整数* | 出力法線マップの形式。<br><br>グリーンチャンネルを効果的に反転します。<br><br>- <b>DirectX:</b> Y軸は上を指しています。<br>- <b>OpenGL:</b> Y軸は下を指しています。 |
| <b>非正方形の拡張</b> *ブール値* | 非正方形の画像では、シェイプの比率が保持され、画像の境界に合わせて生成が拡張されます。 |
| <b>図形の種類</b> *整数* | 散布できるシェイプにはいくつかの種類があり、それぞれ特定の機能を提供します。<br><br><b>SDF 関数</b>は、3D図形の表面を表すSDF (Signed Distance)を生成する関数グラフです。 これにより、動的に変化する複雑な手続き型シェイプの3Dスキャッタリングが可能になります。<br><br><b>単純なレイ/サーフェス交差関数を使用して計算されたプリミティブシェイプ</b>を使用する準備が整いました：立方体、球、円柱、平面、ディスク<br><br><b>入力パターン</b>はグラフによって提供されるイメージです。 これらは平面にマップされ、3D形状に<i>押し出し</i>できます：<br> – 画像入力： <b>パターン入力#</b>入力ピンに接続されたパターン。<br> -グリッドアトラス: <b>グリッドアトラス</b>の入力に接続されたアトラス画像にパックされたパターンです。 |
| <b>グリッドアトラスサイズ</b> *整数2* | <b>グリッドアトラス</b>の画像入力に指定されたアトラスの行数と列数です。<br><br><i>注意：</i>アトラスの空のセルでは、図形の分布に空白が生じます。 |
| <b>グリッドアトラス法線を再計算</b> *ブール値* | <i>True</i>の場合、<b>グリッドアトラス法線</b>画像入力に指定された法線マップは無視され、<b>グリッドアトラスHeight</b>に指定されたパターンの法線は最初から計算されます。<br><br><i>False</i>の場合、<b>グリッドアトラス法線</b>に指定された法線マップがそのまま使用されます。<br><br><i>注：</i>法線の強さは、<b>シェイプの押し出しHeight</b>に従って調整されます。 |
| <b>グリッドアトラスの標準の書式</b> *整数* | <b>グリッドアトラス法線</b>の画像入力に指定された法線マップのフォーマット。<br><br>グリーンチャンネルを効果的に反転します。<br><br>- <b>DirectX:</b> Y軸は上を指しています。<br>- <b>OpenGL:</b> Y軸は下を指しています。 |
| <b>パターンの入力番号</b> *整数* | 入力画像として提供されるパターンの量。<br><br>ノードに<b>パターン入力#</b>入力ピンを追加します。 |
| <b>シェイプの押し出しを有効にする</b> *ブール値* | 入力パターンの押し出しをHeightマップとして変換して切り替えます。これにより、複雑で複雑な3Dシェイプが作成されます。 |
| <b>シェイプの押し出しの対称</b> *ブール値* | 入力パターンの前後の対称押し出しを有効にします。<br><br>対称軸は押し出しの<i>中間点</i>です。対称軸の場所は、図形のピボットの位置に応じて変わる場合があります。 |
| <b>シェイプの押し出しHeight</b> *フロート* | 画像空間での押し出しの最大距離です。1は画像の最も長い辺です。<br><br>この距離は、<b>図形の縮尺</b>の値に対して縮尺されます。 |
| <b>シェイプの押し出しサンプル</b> *整数* | 入力パターンの押し出しを描画するために実行されるサンプルの量です。<br><br>この量が多いほど、より滑らかで輪郭の明瞭な押し出しが得られますが、パフォーマンスが低下します。 |
| <b>パターン関数</b> *フロート* | 3D平面のSDFにマッピングされたパターンの計算に使用される、作成されたSubstance関数グラフです。<br><br>これらのパターンは、<b>シェイプの押し出しを有効にする</b>を使用して押し出すこともできます。 |

| <b>SDF境界フレームサイズ</b> *浮動小数点3* | SDF図形の境界ボックス(Bbox)の最大サイズを定義します。このサイズは、2D Bboxの計算に使用されます。<br><br>図形は2D Bboxの境界内にのみ描画され、残りはトリムされます。 |

| <b>Heightオフセットマップマルチプライヤ</b> *フロート* | 指定された係数を使用して、<b>Heightオフセットマップ</b>によって適用されるオフセットの強さを調整します。ここで、1は、マップの強さの値がそのまま適用されることを意味します。<br><br>図形全体のHeightは、オフセットマップのXY基点の位置に値を加えることによってオフセットされます。<br><br>乗数の値は、<code>[0, 1]を超えて手動で設定できます</code> 範囲： |

| <b>ポアソンの後の形状スケール</b> *フロート* | ポアソン円盤シミュレーションの後に適用されるスケール係数。 |
