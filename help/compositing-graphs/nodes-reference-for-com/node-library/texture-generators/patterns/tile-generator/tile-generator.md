## 説明

Tile Generatorは、ライブラリ内の最も高度なノードの1つです。 これをマスターすれば、あらゆる種類のパターンを作成できます（いくつかの制限があります）。 Version 2017 2.1以降、いくつかの大きな更新が行われ、[タイルSampler](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-sampler/tile-sampler.md)の機能に合わせてこのノードが使用されるようになりました。

このノードは、さまざまなシナリオで非常に便利ですが、パラメータを読むだけでは使用方法を完全には学習できないことに注意してください。 あなたも試してみることをお勧めします！

すべてのケースの99%で、カラーバージョンは不要です。

一般的な使用のヒント：

* 基本のシェイプから始めることができますが、カスタム入力（**パターンの種類**&#x200B;を&#x200B;*画像入力*&#x200B;に設定）がある場合は、最初に作成してください。 これで外観の大部分が決まります。
* まず、XとYの量を正しく設定します。
* 適切な&#x200B;**サイズ**&#x200B;モードを見つける： **インタースティス**&#x200B;などの相対モードは、**絶対**&#x200B;モードとはまったく異なる動作をします。
* 次に、グローバル&#x200B;**拡大・縮小**&#x200B;と不均等&#x200B;**サイズ**&#x200B;を調整します。
* 最後に、必要に応じて&#x200B;**「バリエーション」**&#x200B;パラメーターを調整します。 繊細さが鍵を握るバリエーション！

## パラメーター

### 入力

* **パターン入力1-6**: *グレースケール入力*\
  カスタムパターン画像。「Pattern」パラメーターが「Image Input」に設定されている場合に使用されます。
* **背景**:*グレースケール入力*&#x200B;単色の代わりに使用する背景。

### パラメーター

* **X金額**: *1 - 64*\
  パターンのX繰り返しの量。
* **Y金額**: *1 - 64*\
  パターンのY繰り返しの量。
* **非正方形拡張**: *False/True*\
  スカッシュとストレッチを非正方形の比率で補正できます。
* **パターン**
  * **パターン**: *画像入力、正方形、ディスク、放物面、ベル、ガウス、とげ、角錐、レンガ、グラデーション、ウェーブ、ハーフベル、縁の付いたベル、三日月、カプセル、コーン*\
    使用するパターン形状を選択します。
  * **パターン入力番号**: *1 ～ 6*&#x200B;使用する異なる画像入力の数。 上で&#x200B;*画像入力*&#x200B;が選択されている場合にのみ使用できます。
  * **パターン入力の分布**: *パターン番号でランダム*&#x200B;異なる画像入力の間で選択する方法（1を超える値が選択されている場合）。
  * **パターン固有**: *0.0 ～ 1.0*\
    選択したパターンのシェイプを変更できます。 効果は選択したパターンによって異なります。
  * **画像入力フィルター（エンジン>v4のみ）**: *バイリニア+ミップマップ、バイリニア、ニアレスト*
  * **回転**: *0, 90, 180, 270*&#x200B;すべてのタイルを90度ステップで設定角度でグローバルに回転します。
  * **ランダムな回転**: *0.0 ～ 1.0* 4つの90度ステップの1つでタイルを回転させます。
  * **Quincunxフリップ**: *False/True*&#x200B;タイルを1つおきに90度回転します。
  * **対称ランダム**: *0.0 ～ 1.0*&#x200B;選択した対称ランダムモードで特定のパターンをランダムにミラーします。 この値が大きいほど、ミラーされるパターンの数が多くなります。
  * **対称ランダムモード**: *水平+垂直、水平、垂直*&#x200B;対称ランダムが0より大きい場合のミラーリング動作を決定します。
* **サイズ**
  * **** Size Mode **:***Normal - Interstice、Normal - Size、Keep Ratio、Absolute、Pixel*パターンサイズの一般的な動作を設定します。\
    Normal — Intersticeを使用すると、パターン要素間のギャップを定義できます。 XおよびYの量の影響を受けます。\
    標準 – サイズ：間隔に関係なく、パターン要素のサイズを定義できます。 XおよびYの量の影響を受けます。\
    縦横比を維持を使用すると、XとYの量による影響を受けるサイズを設定できますが、両者のXとYの比率はそのまま維持されます。\
    [絶対]: XおよびYの量の影響を受けない絶対サイズを設定します。\
    「ピクセル」を使用すると、XおよびYの量に影響されない絶対サイズをピクセル単位で設定できます。 解像度を変更すると、エレメントのサイズに影響します。
  * **中央のサイズ**: *0.0 - 1.0*&#x200B;列と行を交互にサイズを変更します。
  * **間隔X/Y**: *0.0 - 1.0*&#x200B;通常 – 間隔サイズモードでのみ使用できます。 間隔ギャップを変更します。 シェイプ間の継ぎ目に影響し、**スケール**&#x200B;とは異なり、不均等なコントロールが可能です。
  * **サイズ（絶対/ピクセル）**: *0.0 ～ 1.0*\
    Normal - Intersticeサイズモード以外でのみ使用できます。 **拡大・縮小**&#x200B;とは異なり、不均等なサイズを設定します。
  * **スケール**: *0.0 ～ 2.0*&#x200B;グローバルスケールを設定します。
  * **ランダムにスケール**: *0.0 ～ 1.0*&#x200B;タイルごとのグローバルスケールのバリエーションを設定します。
  * **スケールランダムシード**: *0 - 1000*&#x200B;変動シードをオフセットします。
* **位置**
  * **オフセット**: *0.0 ～ 1.0*&#x200B;連続する行または列に対して、パターン全体を徐々にオフセットします（動作は垂直オフセットパラメーターによって異なります）。
  * **オフセットランダム**: *0.0 ～ 1.0*&#x200B;ラインオフセットをランダム化します。
  * **オフセットランダムシード**: *0 - 1000*&#x200B;ランダムオフセット効果の相対シードを変更します。
  * **垂直方向のオフセット**: *False/True*&#x200B;オフセットの効果が行と行のどちらで発生するかを設定します。水平方向または垂直方向です。
  * **位置のランダム**: *0.0 ～ 1.0* X方向とY方向に個別に制御して、位置を不均等にランダム化します。
  * **グローバルオフセット**: *0.0 ～ 1.0*&#x200B;結果全体をX軸とY軸の両方にシフトします。
* **回転**
  * **回転**: *0.0 ～ 1.0*&#x200B;すべてのパターンタイルを均等に自由回転します。
  * **回転ランダム**: *0.0 ～ 1.0*&#x200B;すべてのタイルの自由な回転をランダム化します。 この値が大きいほど、より多くのタイルを回転できます。
* **色**
  * **色**: *（グレースケール値）*タイルの単色を設定します。
  * **輝度/カラーランダム**: *0.0 ～ 1.0*&#x200B;タイルごとの色または輝度のバリエーションを導入します。
  * **数値による輝度**: *偽/真*&#x200B;パターン全体で輝度をフェードします。
  * **尺度による輝度**: *偽/真*&#x200B;タイルの尺度に応じて輝度の変動を決定します。
  * **チェッカーマスク**: *False/True*&#x200B;他のすべてのタイルを非表示にします。
  * **水平マスク**: *偽/真*&#x200B;列をすべて非表示にします。
  * **垂直方向マスク**: *False/True* 1行おきに非表示にします。
  * **ランダムマスク**: *0.0 ～ 1.0*&#x200B;タイルをランダムに非表示にします。 この値が高いほど、タイルがより多く消えます。
  * **マスクの反転**: *偽/真*&#x200B;このセクションから任意のマスク効果の結果を反転します。
  * **描画モード**: *追加、最大、サブの追加*&#x200B;使用する描画モードを設定します。
  * **背景色**: *（グレースケール値）*べた塗りの背景色を設定します。
  * **グローバルの不透明度**: *0.0 ～ 1.0*&#x200B;グローバルタイルの不透明度を設定します。
  * **レンダリング順序の反転**: *偽/真*&#x200B;タイルを前面にレンダリングするか、前面のタイルを前面にレンダリングします。
