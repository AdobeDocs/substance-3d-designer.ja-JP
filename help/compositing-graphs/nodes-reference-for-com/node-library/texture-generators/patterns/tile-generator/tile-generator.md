## 説明

Tile Generatorは、ライブラリ内の最も高度なノードの1つです。 これをマスターすれば、あらゆる種類のパターンを作成できます（いくつかの制限があります）。 Version 2017 2.1以降、いくつかの大きな更新が行われ、[タイルSampler](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-sampler/tile-sampler.md)の機能に合わせてこのノードが使用されるようになりました。

このノードは、さまざまなシナリオで非常に便利ですが、パラメータを読むだけでは使用方法を完全には学習できないことに注意してください。 あなたも試してみることをお勧めします！

すべてのケースの99%で、カラーバージョンは不要です。

一般的な使用のヒント：

* 基本のシェイプから始めることができますが、カスタム入力（**パターンの種類**&#x200B;を&#x200B;*画像入力*&#x200B;に設定）がある場合は、最初に作成してください。 これで外観の大部分が決まります。
* まず、XとYの量を正しく設定します。
* 適切な&#x200B;**サイズ**&#x200B;モードを見つける： **インタースティス**&#x200B;などの相対モードは、**絶対**&#x200B;モードとはまったく異なる動作をします。
* 次に、グローバル&#x200B;**拡大・縮小**&#x200B;と不均等&#x200B;**サイズ**&#x200B;を調整します。
* 最後に、必要に応じて&#x200B;**「バリエーション」**&#x200B;パラメーターを調整します。 繊細さが鍵を握るバリエーション！

<a name="inputs"></a>

## 入力

|  |  |
|:---|:---|
| <b>パターン入力1-6</b> <i>グレースケール入力</i> | カスタムパターン画像。「Pattern」パラメーターが「Image Input」に設定されている場合に使用されます。 |
| <b>背景</b> <i>グレースケール入力</i> | 単色の代わりに使用する背景。 |

<a name="parameters"></a>

## パラメーター

|  |  |
|:---|:---|
| <b>X金額</b> <i>1 - 64</i> | パターンのX繰り返しの量。 |
| <b>Y金額</b> <i>1 - 64</i> | パターンのY繰り返しの量。 |
| <b>非正方形拡張</b> <i>False/True</i> | スカッシュとストレッチを非正方形の比率で補正できます。 |
| <b>パターン</b> |  |
| <b>パターン</b> <i>画像入力，正方形，ディスク， 放物面,ベル，ガウス， とげ, ピラミッド, レンガ,グラデーション，波，ハーフベル,うね付きベル,三日月,カプセル,円錐</i> | 使用するパターン形状を選択します。 |
| <b>パターンの入力番号</b> <i>1 - 6</i> | 使用する異なる画像入力の数。 上で<i>画像入力</i>が選択されている場合にのみ使用できます。 |
| <b>パターン入力の分布</b> <i>ランダム、パターン番号順</i> | 複数の画像入力を選択している場合に、異なる画像入力の間で選択する方法。 |
| <b>パターン固有</b> <i>0.0 - 1.0</i> | 選択したパターンのシェイプを変更できます。 効果は選択したパターンによって異なります。 |
| <b>画像入力フィルタリング （エンジン >v4のみ）</b> <i>バイリニア+ミップマップ，バイリニア，最も近い</i> |  |
| <b>回転</b> <i>0, 90, 180, 270</i> | すべてのタイルを設定角度で90度ステップでグローバルに回転します。 |
| <b>ランダムな回転</b> <i>0.0 - 1.0</i> | ランダム偏差は、4つの90度ステップの1つでタイルを回転させます。 |
| <b>クインカンクスフリップ</b> <i>False/True</i> | 1つのタイルを90度回転します。 |
| <b>対称ランダム</b> <i>0.0 - 1.0</i> | 選択した対称ランダムモードで特定のパターンをランダムにミラーします。 この値が大きいほど、ミラーされるパターンの数が多くなります。 |
| <b>対称ランダムモード</b> <i>水平方向+垂直方向、水平方向、垂直方向</i> | 対称ランダムが0より大きい場合のミラーリングの動作を指定します。 |
| <b>サイズ</b> |  |
| <b>サイズモード</b> <i>Normal – 間隔、Normal – サイズ、縦横比を維持、絶対、ピクセル</i> | パターンサイズの一般的な動作を設定します。<br><br>標準 – 間隔を使用すると、パターン要素間の間隔を定義できます。 XおよびYの量の影響を受けます。<br><br>標準 – サイズを使用すると、間隔に関係なくパターン要素のサイズを定義できます。 XおよびYの量の影響を受けます。<br><br>縦横比を維持を使用すると、XとYの量による影響を受けるサイズを設定できますが、両者のXとYの比率は変更されません。<br><br>絶対： XとYの量に影響されない絶対サイズを設定します。<br><br>ピクセルでは、XおよびYの量に影響されない絶対サイズをピクセル単位で設定できます。 解像度を変更すると、エレメントのサイズに影響します。 |
| <b>中央サイズ</b> <i>0.0 - 1.0</i> | 列と行を交互にサイズを変更します。 |
| <b>間隔X/Y</b> <i>0.0 - 1.0</i> | Normal - Interstice Sizeモードでのみ使用できます。 間隔ギャップを変更します。 シェイプ間の継ぎ目に影響し、<b>スケール</b>とは異なり、不均等なコントロールが可能です。 |
| <b>サイズ（絶対/ピクセル）</b> <i>0.0 - 1.0</i> | Normal - Intersticeサイズモード以外でのみ使用できます。 <b>拡大・縮小</b>とは異なり、不均等なサイズを設定します。 |
| <b>スケール</b> <i>0.0 - 2.0</i> | グローバルスケールを設定します。 |
| <b>ランダムに拡大・縮小</b> <i>0.0 - 1.0</i> | タイルごとのグローバルスケールの変動を設定します。 |
| <b>ランダムシードのスケール</b> <i>0 - 1000</i> | スケールバリエーションシードをオフセットします。 |
| <b>位置</b> |  |
| <b>オフセット</b> <i>0.0 - 1.0</i> | 連続するすべての行または列に対して、パターン全体を徐々にオフセットします（[垂直オフセット]パラメータによって動作が異なります）。 |
| <b>オフセットランダム</b> <i>0.0 - 1.0</i> | ラインオフセットをランダム化します。 |
| <b>オフセットランダムシード</b> <i>0 - 1000</i> | ランダムオフセット効果の相対シードを変更します。 |
| <b>垂直方向のオフセット</b> <i>False/True</i> | オフセット効果を行または行に適用するかどうかを設定します。水平または垂直です。 |
| <b>ランダムな配置</b> <i>0.0 - 1.0</i> | XとYを個別に制御して、位置を不均等にランダム化します。 |
| <b>グローバルオフセット</b> <i>0.0 - 1.0</i> | 結果全体をX方向とY軸にシフトします。 |
| <b>回転</b> |  |
| <b>回転</b> <i>0.0 - 1.0</i> | すべてのパターンタイルに均一な自由回転を実行します。 |
| <b>ランダムな回転</b> <i>0.0 - 1.0</i> | すべてのタイルの自由回転をランダム化します。 この値が大きいほど、より多くのタイルを回転できます。 |
| <b>色</b> |  |
| <b>色</b> <i>（グレースケール値）</i> | タイルの単色を設定します。 |
| <b>輝度/カラーランダム</b> <i>0.0 - 1.0</i> | タイルごとのカラーまたは輝度のバリエーションを導入します。 |
| <b>番号による輝度</b> <i>False/True</i> | パターン全体に輝度をフェードします。 |
| <b>尺度による輝度</b> <i>False/True</i> | 輝度のバリエーションをタイルの尺度に依存させます。 |
| <b>チェッカーマスク</b> <i>False/True</i> | 他のすべてのタイルを非表示にします。 |
| <b>水平マスク</b> <i>False/True</i> | 1列おきに非表示にします。 |
| <b>垂直方向マスク</b> <i>False/True</i> | 1行おきに非表示にします。 |
| <b>ランダムマスク</b> <i>0.0 - 1.0</i> | タイルをランダムに非表示にします。 この値が高いほど、タイルがより多く消えます。 |
| <b>マスクを反転</b> <i>False/True</i> | このセクションのマスキング効果の結果を反転します。 |
| <b>描画モード</b> <i>追加、最大、サブを追加</i> | 使用する描画モードを設定します。 |
| <b>背景色</b> <i>（グレースケール値）</i> | 単色の背景色を設定します。 |
| <b>グローバル不透明度</b> <i>0.0 - 1.0</i> | グローバルタイルの不透明度を設定します。 |
| <b>レンダリング順序を反転</b> <i>False/True</i> | タイルを前面または前面にレンダリングします。 |
