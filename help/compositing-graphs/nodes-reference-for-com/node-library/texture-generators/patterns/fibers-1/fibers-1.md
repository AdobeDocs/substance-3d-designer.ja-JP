## 説明

単純なファイバー状パターン。 ロープ、メッシュ、または布のハイトマップやディテールに[Substance 3D Designer](https://www.adobe.com/jp/products/substance3d-designer.html)で使用できます。

## パラメーター

* **タイリング**: *1 - 16*\
  結果をタイルする回数を設定します。
* **非正方形拡張**: *False/True*\
  カボチャと伸縮の補正を非正方形の比率で有効にします。
