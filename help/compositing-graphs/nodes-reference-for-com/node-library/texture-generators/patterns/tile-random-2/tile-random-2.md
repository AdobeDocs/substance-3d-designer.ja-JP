## 説明

**タイルランダム2**&#x200B;ノードは、ランダムサイズとHeightと幅の比率で隣接するタイルを生成します。

グリッドは、シェイプの側面をランダムに&#x200B;*斜め*&#x200B;して角度を分割することで微調整できます。

*拡大・縮小*、*面取り*、*角の丸み*&#x200B;および&#x200B;*回転の調整*&#x200B;のオプションを使用して図形を調整できます。

これらの調整は、*入力マップ*&#x200B;によって制御される場合があります。

専用の出力を使用すると、図形の&#x200B;**UV**&#x200B;を&#x200B;**Flood Fillに入力して(...)**&#x200B;できます 追加のバリエーションを適用するノードです。

## パラメーター

### 入力

* **ランダムサイズマップ** *グレースケール*\
  シェイプのランダムスケールを制御するグレースケール入力画像です。\
  その影響は、**ランダムサイズ入力マップ乗数**&#x200B;パラメーターによって制御されます。
* **ランダムな傾斜地図** *グレースケール*&#x200B;図形のランダムな傾斜を制御するグレースケール入力画像です。\
  その影響は、**ランダム傾斜角入力マップ乗数**&#x200B;パラメーターによって制御されます。
* **角丸の半径マップ** *グレースケール*\
  シェイプの角丸の半径を制御するグレースケール入力画像です。\
  その影響は、**角丸の半径の入力マップ乗数**&#x200B;によって制御されます。 パラメータで指定します。
* **ベベル距離マップ** *グレースケール*\
  シェイプのベベルを制御するグレースケール入力画像です。\
  その影響は、**ベベル距離入力マップ係数**&#x200B;によって制御されます。 パラメータで指定します。
* **マスクマップ** *グレースケール*\
  シェイプのマスクを制御するグレースケール入力画像。\
  この影響は、**マスクマップの入力開始**&#x200B;および&#x200B;**マスクマップの入力終了**&#x200B;パラメーターによって制御されます。

### パラメーター

* **金額X** *整数*\
  **X** 軸のセルの数です。
* **適用量Y** *整数*\
  **Y** 軸上のセルの数です。
* サイズ
  * **ランダムサイズ乗数** *浮動小数*\
    ランダムな拡大・縮小の強さに&#x200B;*全体*&#x200B;調整を適用します。
  * **ランダムサイズ入力マップ乗数** *浮動小数*\
    **ランダムサイズマップ**&#x200B;入力の値&#x200B;*サンプリング*&#x200B;を使用して、ランダムスケーリングの強度を調整します。
  * **ランダムサイズX** *浮動小数*\
    **X**&#x200B;軸&#x200B;*のみ*&#x200B;でランダムスケールの適用度を調整します。
  * **ランダムサイズY** *浮動小数*\
    **Y**&#x200B;軸&#x200B;*のみ*&#x200B;のランダムスケールの適用度を調整します。
  * **ランダムサイズの分布** *整数*\
    ランダムスケール値を配分する方法をコントロールします。
    * *均一*:ランダムスケールは、すべてのセルに&#x200B;*同じ方法*&#x200B;で適用されます
    * *青のノイズ*：青のノイズパターンを使用して、ランダムなスケールを&#x200B;*調整*&#x200B;しています
* シェイプの縦横比 – 変形
  * **間隔のThickness** *浮動小数*&#x200B;図形の間隔のThicknessを調整します。 すべての&#x200B;*図形に対して*&#x200B;等しい。
  * **ランダム位置乗数** *浮動小数*\
    図形の上の&#x200B;*セルの境界に合わせて*&#x200B;図形にランダムな位置オフセットを適用します。
  * **角丸の半径** *浮動小数*&#x200B;シェイプの角丸の&#x200B;*半径*&#x200B;を調整します。 値&#x200B;**0**&#x200B;は、丸めが適用されていないことを意味します。\
    *注意*：この効果は、**軸ごとのベベルコントロールを有効にする**&#x200B;パラメーターが&#x200B;*True*&#x200B;に設定されている場合は適用できません。
  * **角丸の半径の入力マップ係数** *浮動小数&#x200B;***角丸の半径マップ**&#x200B;の入力マップが角丸の半径に与える影響の強さを調整します。\
    このマップは、**角丸の半径**&#x200B;パラメーターの&#x200B;*ピクセル単位*&#x200B;乗数として機能します。\
    *注意*：この効果は、**軸ごとのベベルコントロールを有効にする**&#x200B;パラメーターが&#x200B;*True*&#x200B;に設定されている場合は適用できません。
  * **スケール乗数** *浮動小数*\
    各図形のサイズを、そのセルの&#x200B;*面積*&#x200B;に対する比率で調整します。
  * **ランダムに拡大・縮小** *浮動小数*&#x200B;図形の&#x200B;*個*&#x200B;にランダムな拡大・縮小を適用する際の強さを調整します。
  * **回転** *浮動小数*&#x200B;各&#x200B;*角*&#x200B;をセルの境界線に沿って&#x200B;*隣*&#x200B;に動かして、セル内の図形を回転します。\
    このメソッドを使用すると、ある程度の&#x200B;*ゆがみ*&#x200B;と&#x200B;*拡大/縮小*&#x200B;がis回転で図形に適用されます。
  * **ランダムな回転** *浮動小数*&#x200B;各図形にランダムな回転量を適用する際の強さを調整します。\
    回転の方法は、**Rotation**&#x200B;パラメーターで説明されています。
  * **コーナーの位置をランダムに** *浮動小数*&#x200B;各&#x200B;*コーナー*&#x200B;にセルの境界線に沿ってランダムに&#x200B;*オフセット*&#x200B;を適用することで、図形を変形させます。
* 傾斜角
  * **ランダム傾斜乗数** *浮動小数*\
    ランダムな傾斜の強さに&#x200B;*グローバル*&#x200B;調整を適用します。
  * **ランダム傾斜角入力マップ乗数** *浮動小数*\
    **ランダム傾斜マップ**&#x200B;入力の値&#x200B;*サンプリング*&#x200B;を使用して、ランダム傾斜の強度を調整します。
  * **ランダムな傾斜角X** *浮動小数*\
    ランダムな傾斜の強度を調整します\
    **X** 軸 *のみ*&#x200B;上。
  * **ランダム傾斜角** *浮動小数*\
    ランダムな傾斜の強度を調整します\
    **Y** 軸 *のみ*&#x200B;に対して実行します。
  * **ランダム傾斜分布** *整数*\
    ランダムな傾斜値を分布する方法をコントロールします。
    * *均一*:ランダムな傾斜角は、すべてのセルに&#x200B;*同じ方法*&#x200B;で適用されます
    * *青のノイズ*：青のノイズパターンを使用して、ランダムな傾斜角を&#x200B;*調整*&#x200B;しています
* ベベル
  * **ベベル距離モード** *整数*\
    図形のベベルの基準となる&#x200B;*距離の取得方法*&#x200B;を設定します：
    * *グリッドサイズを基準にして*：図形の面取りは、指定された&#x200B;*グリッドサイズの比率*- *図形サイズを基準にして*：図形の面取りは、指定された&#x200B;*サイズの比率*&#x200B;で行われます
    * *画像サイズを基準にする*:シェイプは、指定された&#x200B;*画像の比率*&#x200B;でベベルされます
  * **ベベル距離乗数** *浮動小数*\
    *グローバル*&#x200B;調整をベベルの距離に適用します。
  * **ベベル距離入力マップ係数** *浮動小数*\
    **ベベルの距離マップ**&#x200B;を&#x200B;*ピクセル単位*&#x200B;の乗数として使用して、ベベルの入力マップを調整します。
  * **ベベルの角丸カーブ** *浮動小数*\
    ベベル角度に適用される丸みの強度を調整して、より&#x200B;*凸状*&#x200B;にします。
  * **軸ごとのベベルコントロールを有効にする** *ブーリアン*\
    *真*&#x200B;の場合、**X**&#x200B;および&#x200B;**Y**&#x200B;軸で&#x200B;*個別に*&#x200B;適用および調整できます。\
    *注意*：この&#x200B;*は&#x200B;**角丸**&#x200B;効果をキャンセル*&#x200B;します。
  * **ベベル距離X** *浮動小数*\
    **X**&#x200B;軸&#x200B;*のみ*&#x200B;のベベルの間隔を調整します。 この距離は、**ベベル距離モード**&#x200B;パラメーターの値によって異なります。\
    *注意*：このパラメーターは、**軸ごとのベベルコントロールを有効にする**&#x200B;パラメーターが&#x200B;*True*&#x200B;に設定されている場合にのみ使用できます。
  * **ベベル距離Y** *浮動小数*\
    **Y**&#x200B;軸&#x200B;*のみ*&#x200B;のベベルの間隔を調整します。 この距離は、**ベベル距離モード**&#x200B;パラメーターの値によって異なります。\
    *注意*：このパラメーターは、**軸ごとのベベルコントロールを有効にする**&#x200B;パラメーターが&#x200B;*True*&#x200B;に設定されている場合にのみ使用できます。
* マスク
  * **マスクのランダム反転** *ブール値*\
    シェイプのランダムマスクを反転します。
  * **マスクのランダムスタート** *浮動小数点*\
    指定された&#x200B;**ランダムシード**&#x200B;に対して、疑似ランダムマスクが開始シェイプから終了シェイプまでの&#x200B;*特定の順序*&#x200B;に従って適用されます。 このパラメーターを使用すると、*開始*&#x200B;図形のインデックス&#x200B;*を*&#x200B;オフセットできます。\
    *注意*：これにより、マスクの&#x200B;*値の範囲*&#x200B;の上限が1つ決定されます。 したがって、値は&#x200B;**マスクランダム終了**&#x200B;値よりも&#x200B;*大きい*&#x200B;値になる可能性があります。
  * **マスクのランダムな端** *浮動小数点*&#x200B;任意の&#x200B;**ランダムシード**&#x200B;に対して、疑似ランダムマスクは、開始シェイプから終了シェイプまでの&#x200B;*特定の順序*&#x200B;に従って適用されます。 このパラメーターを使用すると、*end*&#x200B;図形のインデックス&#x200B;*を*&#x200B;オフセットできます。\
    *注意*：これにより、マスクの&#x200B;*値の範囲*&#x200B;の上限が1つ決定されます。 したがって、値は&#x200B;**マスクランダム開始**&#x200B;値よりも&#x200B;*大きい*&#x200B;値になる可能性があります。
  * **セル領域の反転でマスク** *ブーリアン*\
    セルの面積に応じてシェイプのマスクを反転します。
  * **セル領域の開始位置でマスク** *浮動小数*\
    シェイプをマスクするための&#x200B;*最小*&#x200B;セルの領域のしきい値を調整します。\
    *注意*：これにより、マスクの&#x200B;*値の範囲*&#x200B;の上限が1つ決定されます。 したがって、この値は&#x200B;**セル領域の終わりによるマスク**&#x200B;値よりも&#x200B;*大きい*&#x200B;値になる可能性があります。
  * **セル領域の端でマスク** *浮動小数*&#x200B;図形をマスクするための&#x200B;*最大*&#x200B;セル領域のしきい値を調整します。\
    *注意*：これにより、マスクの&#x200B;*値の範囲*&#x200B;の上限が1つ決定されます。 したがって、この値は、**セル領域の開始によるマスク**&#x200B;値よりも&#x200B;*低い*&#x200B;値になる可能性があります。
  * **マスクマップの入力反転** *ブール値*\
    **マスクマップ**&#x200B;入力マップで図形のマスクを反転します。
  * **マスクマップの入力開始** *浮動小数点*\
    シェイプをマスクするための&#x200B;**マスクマップ**&#x200B;入力マップの&#x200B;*最小グレースケール値*&#x200B;のしきい値を調整します。\
    *注意*：これにより、マスクの&#x200B;*値の範囲*&#x200B;の上限が1つ決定されます。 したがって、値は&#x200B;**マスクマップ入力端**&#x200B;値よりも&#x200B;*大きい*&#x200B;値になる可能性があります。
  * **マスクマップの入力の終わり** *浮動小数点*&#x200B;シェイプをマスクするための&#x200B;**マスクマップ**&#x200B;入力マップの&#x200B;*最大グレースケール値*&#x200B;のしきい値を調整します。\
    *注意*：これにより、マスクの&#x200B;*値の範囲*&#x200B;の上限が1つ決定されます。 したがって、値は&#x200B;**Mask Map Input Start**&#x200B;値よりも&#x200B;*低い*&#x200B;値になる可能性があります。
