## 説明

非常に単純なチェックパターンです。 タイリングを意図的に低く設定して、可能な限り一般的にします。

コントラストとタイリングが明らかなので、テストケースに有用なパターンです。

## パラメーター

* **タイリング**: *1 - 16*\
  結果をタイルする回数を設定します。
* **45度回転**: *False/True*&#x200B;パターン全体を45度回転します。
* **非正方形拡張**: *False/True*\
  スカッシュとストレッチを非正方形の比率で補正できます。
