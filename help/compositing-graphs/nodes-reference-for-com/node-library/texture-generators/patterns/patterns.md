# パターン

パターンは人工のグラフィックで、人工的に作られたように見えます。 ルールに従って配置するのが一般的ですが、ほとんどの場合、ランダムなバリエーションを導入できます。

レンガ、タイル、織り模様など、基本となる規則的なパターンが必要な場合に便利です。

ほぼすべてのパターンが完全にタイル化され、解像度に依存しません。つまり、品質を損なうことなくサイズを変更できます。

左側の<b>ナビゲーションリスト</b>を使用して、[パターン]の下にあるすべてのノードを参照します。

* [Tile Generator](../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md)
