## 説明

[シェイプスプラッタv2](../shape-splatter-v2/shape-splatter-v2.md)ノードを使用して生成および散布されたシェイプに、ノードによって提供される追加データを使用して、カラー画像をマッピングします。<br><br>イメージは、個別のパターン入力として提供されるか、またはグリッドアトラスにパックされます。イメージは、UVマッピング、3平面投影、またはカスタムマッピングを使用してシェイプに適用できます。<br><br>図形は色を付けることができ、図形ごとに均一またはランダムに色を調整できます。

[シェイプスプラッタv2マッパーグレースケール](../shape-splatter-v2-mapper-grayscale/shape-splatter-v2-mapper-grayscale.md)も参照してください。

</td>
</tr>
</table>

>[!INFO]
>
> このノードには、[Shape splatter v2](../shape-splatter-v2/shape-splatter-v2.md)ノードによって生成された入力データが必要です。
> 
> Shapeスプラッタv2ファミリのその他のノード：
> * [シェイプスプラッタv2をマスクに](../shape-splatter-v2-to-mask/shape-splatter-v2-to-mask.md)
>
> [グリッドアトラスカラー](../grid-atlas-color/grid-atlas-color.md)のノードでは、画像をカスタムサイズのアトラス（4*4セルで最大16パターン）にパックできます。

>[!TIP]
> 
> [**&#39;錆びたボルト&#39;**&#x200B;材料サンプル](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-nodes-sdf-functions/working-with-sdf-functions.md#material-sample)は、シェイプスプラッタv2ノードの使用を開始するために使用できます。
> 
> SDF 関数に関する概念やワークフローについて詳しくは、専用ページ（[SDF 関数の操作](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-nodes-sdf-functions/working-with-sdf-functions.md)）を参照してください

## パラメーター

|                                            |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
|:-------------------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>プロジェクションモード</b> *整数* | 入力画像を図形に投影する方法：<br><br>- <b>スプラッタUVから：</b> &#39;Shape splatter v2&#39;ノードが提供するUVを使用します。<br>- <b>三平面投影：</b>三平面投影を使用して、図形のローカルXYZ軸に画像をマッピングします。<br>- <b>カスタム関数：</b>図形に画像をマッピングする関数グラフを作成します。 |
| <b>カスタム関数</b> *浮動小数点4* | 図形のRGBAピクセル単位の色をFloat4として指定します。<br><br>次の変数を使用できます。<br>- <code>shape.position.os</code> (Float3)オブジェクト空間でのシェイプサーフェスの位置。<br>- <code>shape.position.ws</code> （フロート3）ワールド空間でのシェイプサーフェスの位置*.<br>- <code>shape.normal.os</code> (Float3)オブジェクト空間内のシェイプサーフェスの法線です。<br> - <code>shape.normal.ws</code> (Float3)ワールド空間のシェイプサーフェスの法線*.<br>- <code>shape.id</code> （フロート）図形の一意の識別子です。<br>- <code>material.id</code> （フロート） &#39;Shape splatter v2&#39;ノードで定義されたシェイプサーフェスのマテリアルIDです。<br><br>*：図形のワールド空間はピボットの中心に配置され、図形のHeightは考慮されません。 これは、オブジェクト空間との唯一の違いが方向であることを意味します。<br><br>&#39;Shape splatter v2 mapper color&#39;ノードの入力をサンプリングする必要がある場合は、次の<b>Sample color</b>ノード入力スロットを使用できます：<br>- 0: グリッドアトラス<br>- 1-8:パターン入力1-8 |
| <b>標準マップです</b> *ブール値* | <b>グリッドアトラス入力</b>または<b>パターン入力#</b>に提供される画像が通常のマップかどうかを指定します。<br><br>これは、通常のベクトルを正しく処理し、図形に適用するために必要な処理を有効にするために必要です。 |
| <b>標準形式を入力</b> *整数* | <b>グリッドアトラス入力</b>または<b>パターン入力#</b>.<br><br>グリーンチャンネルを有効に反転します。<br><br>- <b>DirectX:</b> Y軸は上を指しています。<br>- <b>OpenGL:</b> Y軸は下を指しています。 |
| <b>コントラストのブレンド</b> *フロート* | 平面投影間の遷移のシャープです。1はフェードグラデーションがないことを意味します。 |
| <b>イメージプロジェクション</b> *整数* | 3平面マッピングに寄与する平面投影全体に分散された<b>パターン入力#</b>画像の量。<br><br>形状の全側面を覆うために、各軸で前面(+)と背面(-)の平面投影が行われ、合計6つの投影が行われます。<br><br>- <b>1画像：</b>パターン入力1はすべての平面投影に使用されます。<br>- <b>3画像：</b>各軸の+/ – 投影に個別のパターン入力が使用されます。<br>- <b>6画像：</b>各投影は個別のパターン入力を使用します。<br>- <b>入力1マテリアルID。各画像がすべての平面投影に使用されます。</b> |
| <b>プロジェクションセンター</b> *浮動小数点3* | オブジェクト空間で、軸ごとに三面体投影をオフセットします。<br><br>オフセットは<i>投影空間全体</i>に適用されるため、1つの軸でのオフセットが、<i>他の2つの</i>軸に投影されたテクスチャの配置に影響します。 |
| <b>投影尺度</b> *フロート* | <i>すべての軸</i>の投影されたテクスチャの尺度を、指定した係数で調整します。 |
| <b>選択モードの入力</b> *整数* | シェイプにマップする入力画像を選択する方法。<br><br>ソース&#39;Shape splatter v2&#39;ノードで選択された<b>図形の種類</b>によって、図形へのイメージの割り当て方法が変わります：<br><br>- <b>グリッドアトラス</b>は、一致するグリッドインデックスによって&#39;グリッドアトラス入力&#39;にイメージがフェッチされることを示します（両方のアトラスで同じグリッドサイズを使用する必要があります）<br>- <b>パターン入力</b>は、一致するインデックスによって&#39;パターン入力#&#39;入力にイメージががフェッチされることを示します。<br>- &lbrace;1111111111111 s.<br><br>インデックスを選択する方法：<br>- <b>スプラッタデータから：</b> &#39;パターン入力#&#39;または&#39;グリッドアトラス入力&#39;のイメージのインデックスを、&#39;Shape splatter v2&#39;ノードによって割り当てられた図形のインデックスと一致させてください。<br>- <b>手動：</b>&#39;Image index&#39;パラメーターで指定されたインデックスを使用してください。<br>- <b>ランダム：</b> &#39;Random範囲&#39;パラメーターでで指定した範囲範囲範囲で範囲範囲でランダムインデックスをを使用してください。<b></b> |
| <b>パターンの入力番号</b> *整数* | 図形にマップする<b>パターン入力#</b>入力画像の量です。 |
| <b>画像インデックス</b> *整数* | 図形にマップする<b>パターン入力#</b>または<b>グリッドアトラス入力</b>の入力パターンのインデックスです。 |
| <b>ランダム範囲</b> *整数2* | 図形にマップするパターンをランダムに選択する必要がある、<b>パターン入力#</b>または<b>グリッドアトラス入力</b>のインデックスの範囲。 |
| <b>HSL調整</b> *浮動小数点3* | すべてのシェイプの色相、彩度、輝度(HSL)に均一に適用されるオフセット。 |
| <b>HSLランダム</b> *浮動小数点3* | シェイプの色相、彩度、輝度(HSL)に適用される正または負のランダムなオフセット。指定した値まで適用されます。 |
| <b>カラー入力の不透明度</b> *フロート* | 選択した<b>色の入力の描画モード</b>に従って、<b>色の入力</b>が図形の色に与える影響の強さです。 |
| <b>カラー入力の描画モード</b> *整数* | 前景と背景の画像を合成するのに使用するカラーのブレンド操作です。<br><br>これらの操作は、<b>ブレンド</b>ノードの対応する操作と同じです。<br><br>使用可能なモード：<br>- <b>コピー</b><br>- <b>追加（線形覆い焼き）</b><br>- <b>削除</b><br>- <b>乗算</b><br>- <b>オーバーレイ</b> |
| <b>標準角度ランダム</b> *フロート* | 法線ベクトルの原点から、当該法線ベクトルを中心とした円錐台台上のランダム点までの方向ベクトルを生成し、当該法線ベクトルと当該ランダム方向ベクトルとをブレンドする。<br><br>このパラメーターは、円錐の<i>角度</i>を調整します。ここで、1は半球で、0は方向ベクトルが法線ベクトルと等しいことを意味します。 |
| <b>タイルモード</b> *整数* | テクスチャの繰り返し軸： <br> - <b>タイル表示なし</b><br> - <b>水平タイル表示</b><br> - <b>垂直タイル表示</b><br> - <b>HとVのタイル表示</b> ：水平タイルと垂直タイルを組み合わせます。 |
| <b>UVタイル</b> *フロート* | 図形にマップされた画像の全体表示を調整します<br><br>値が大きいほど、反復回数が多くなります。 |
| <b>UV スケール</b> *浮動小数点2* | シェイプにマッピングされた画像のタイリングを、指定した係数で調整します。UスケールとVスケールには個別のコントロールがあります。 値が大きいほど、反復回数が多くなります。 |
| <b>UV オフセット</b> *浮動小数点2* | シェイプ間の画像のマッピングにオフセットを適用します。これにより、シェイプ上の画像の位置を微調整できます。<br><br>このオフセットは、<b>ランダムオフセット</b>に追加されます。 |
| <b>ランダムオフセット</b> *フロート* | 正または負のランダムなオフセット<i>を、指定された値までのシェイプ間の画像のマッピングに適用します</i>。<br><br>このオフセットは、存在する場合<b>UV オフセット</b>に追加されます。 |
