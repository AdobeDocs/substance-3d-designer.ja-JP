## 説明

細いブロックでシンプルなメッシュパターン。 Heightマップと詳細マップの作成に適しています。

## パラメーター

* **タイリング**: *1 - 16*\
  結果をタイルする回数を設定します。
* **45度回転**: *False/True*&#x200B;結果を45度回転します。
* **非正方形拡張**: *False/True*\
  カボチャと伸縮の補正を非正方形の比率で有効にします。
