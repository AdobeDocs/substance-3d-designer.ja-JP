## 説明

[スプラッタ円]は、さまざまなコントロールを持つリングベースのパターンを生成します。 定義済みのシェイプまたはカスタム入力を使用できます。 [Tile Generator](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md)に似ていますが、グリッドの代わりに円の配置が使用されます。

この機能は、様々なランダム化オプションを使用してシェイプを円形に配置する場合に便利です。

</tr>
</table>

<a name="inputs"></a>

## 入力

両方の入力はオプションです。

|  |  |
|:---|:---|
| <b>パターン画像の入力1-6</b> <i>グレースケール入力（カラー入力）</i> | スプラッタ円形のみ：カスタムパターンイメージ。[パターン]パラメータが[イメージ入力]に設定されている場合に使用されます。 |
| <b>背景</b> <i>グレースケール入力（カラー入力）</i> |  |

<a name="parameters"></a>

## パラメーター

|  |  |
|:---|:---|
| <b>パターン適用量</b> <i>1 - 64</i> | リング上に配置するパターンタイルの量。 |
| <b>パターン適用量ランダム</b> <i>0.0 - 1.0</i> | 配置するパターンの量をランダム化します。 リングの量が1より大きい場合に最適です。 |
| <b>パターン適用量ランダム最小</b> <i>1 - 10</i> | ランダム化するパターンの最小量を設定します。 |
| <b>リングの量</b> <i>1 - 10</i> | 埋めるリングの数を設定します。 リングは常に外側の内側に配置され、均等に間隔を空けています。 |
| <b>非正方形拡張</b> <i>False/True</i> | スカッシュとストレッチを非正方形の比率で補正できます。 |
| <b>パターン</b> |  |
| <b>パターン</b> <i>画像入力，正方形，ディスク， 放物面,ベル，ガウス， とげ, ピラミッド, レンガ,グラデーション，波，ハーフベル,うね付きベル,三日月,カプセル,円錐</i> | 使用するパターン形状を選択します。 |
| <b>パターンの入力番号</b> <i>1 - 6</i> | 使用する異なるイメージ入力の数を設定します。 上で<i>画像入力</i>が選択されている場合にのみ使用できます。 |
| <b>パターン入力の分布</b> <i>ランダム、パターン番号、リング番号</i> | 複数のパターン入力の選択方法を設定します。 ランダムとは、ランダムなパターンが選択されることを意味します。パターン番号とは、ループするシーケンスに配置されることを意味します。 |
| <b>画像入力フィルタリング</b> <i>バイリニア+ミップマップ，バイリニア，最も近い</i> |  |
| <b>パターン固有</b> <i>0.0 - 1.0</i> | 選択したパターンのシェイプを変更できます。 効果は選択したパターンによって異なります。 |
| <b>対称ランダム</b> <i>0.0 - 1.0</i> | 以下の動作に従って、ランダムにフリップ/ミラーするタイルの数を設定します。 |
| <b>対称ランダムモード</b> <i>水平方向+垂直方向、水平方向、垂直方向</i> | 対称ミラーリングの動作を決定します。 |
| <b>位置</b> |  |
| <b>半径</b> <i>0.0 - 1.0</i> | パターンが配置される中心からの半径を設定します。 |
| <b>半径ランダム</b> <i>0.0 - 1.0</i> | すべてのパターンタイルの半径をランダム化します。 |
| <b>リング半径マルチプライヤ</b> <i>0.0 - 1.0</i> | 複数のリングの間隔に影響します。 |
| <b>角度ランダム</b> <i>0.0 - 1.0</i> | 各パターンの角度をランダム化します。 値を大きくすると、回転が大きくなります。 |
| <b>らせん因子</b> <i>0.0 - 1.0</i> | リングをスパイラルに変換します。すべてのタイルは、わずかに大きくなる半径で配置されます。 |
| <b>スプレッド</b> <i>0.0 - 2.0</i> | リングの回転量を設定します。 これは、その制限を超えて増加することができます。 |
| <b>方向に沿ったオフセット</b> <i>0.0 - 1.0</i> | すべてのパターンをその角度に沿って中心から外側に移動します。 この効果は角度ランダムに大きく依存するか、または半径の乗数のように見えます。 |
| <b>グローバルオフセット</b> <i>0.0 - 1.0</i> | シェイプ全体を移動します。 |
| <b>サイズ</b> |  |
| <b>パターンの接続</b> <i>False/True</i> | パターンタイルの長さを半径に依存させます。つまり、各シェイプは前後のシェイプに接する必要があります。 |
| <b>サイズ（接続済み）</b> <i>0.0 - 1.0</i> | 各パターンのサイズをグローバルに変更します。 接続されている場合は、合計半径に対する相対値になります。 |
| <b>サイズがランダム</b> <i>0.0 - 1.0</i> | 各パターンのサイズを個別にランダム化します。 |
| <b>スケール</b> <i>0.0 - 2.0</i> | 各パターンを均一に拡大/縮小します。 |
| <b>ランダムに拡大・縮小</b> <i>0.0 - 1.0</i> | 均等スケーリングをランダム化します。 |
| <b>パターン番号でスケール</b> <i>0.0 - 1.0</i> | パターンの尺度をリングに沿った位置に依存させます。 |
| <b>パターン番号の反転</b> <i>False/True</i> | 前のオプションで使用すると、拡大/縮小を小から大に、またはその逆に反転できます。 |
| <b>リング番号でスケール</b> <i>0.0 - 1.0</i> | スケールをリング番号に依存させます。 |
| <b>リング番号の反転</b> <i>False/True</i> | 前のオプションで使用すると、拡大/縮小を小から大に、またはその逆に反転できます。 |
| <b>回転</b> |  |
| <b>パターンの回転</b> <i>0.0 - 1.0</i> | すべてのパターンを均等に回転します。 |
| <b>パターンの回転ランダム</b> <i>0.0 - 1.0</i> | パターンの回転をランダムにします。 |
| <b>パターンの回転の基点</b> <i>中心、最小X、最大X、最小Y、最大Y</i> | すべてのパターンを個別に回転する基点の位置を設定します。 |
| <b>中心の向き</b> <i>False/True</i> | すべてのパターンを回転して、リングの中心に向かいます。 の方向を変更すると、すべてのオブジェクトの方向が同じになります。これにより、方向に沿ったオフセットで不要な効果が生じることがあります。 |
| <b>リングの回転</b> <i>0.0 - 1.0</i> | リング全体を中心に回転させます。 |
| <b>リング回転ランダム</b> <i>0.0 - 1.0</i> | リングあたりの回転をランダム化します。 |
| <b>リングの回転オフセット</b> <i>0.0 - 1.0</i> | リングごとに回転をオフセットします。 |
| <b>色</b> |  |
| <b>色</b> <i>（グレースケール値）</i> | 選択したパターンと乗算する色。 |
| <b>輝度ランダム</b> <i>0.0 - 1.0</i> | すべてのパターンタイルにカラーまたは輝度をランダムに適用します。 |
| <b>尺度による輝度</b> <i>0.0 - 1.0</i> | 輝度を個々のパターン尺度に依存させます。 |
| <b>パターン番号ごとの輝度</b> <i>0.0 - 1.0</i> | 輝度をパターンシーケンスに依存させます。 たとえば、緩和曲線と共に使用できます。 |
| <b>パターン番号の反転</b> <i>False/True</i> | 前のオプションを反転します。 |
| <b>リング番号ごとの輝度</b> <i>0.0 - 1.0</i> | 輝度をリングシーケンスに依存させます。 |
| <b>リング番号の反転</b> <i>False/True</i> | 前のオプションを反転します。 |
| <b>ランダムマスク</b> <i>0.0 - 1.0</i> | パターンをランダムに非表示にします。 |
| <b>背景色</b> <i>（グレースケール値）</i> | 単色の背景色を変更します。 |
| <b>描画モード</b> <i>追加、最大、サブを追加</i> | 重なり合うパターンのブレンド方法を設定します。 |
| <b>グローバル不透明度</b> <i>0.0 - 1.0</i> | 結果全体のグローバル不透明度を設定します。 |
