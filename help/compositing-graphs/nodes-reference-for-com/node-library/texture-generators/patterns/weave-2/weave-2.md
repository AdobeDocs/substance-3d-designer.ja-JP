## 説明

単純な織りパターンを生成します。 ランダム化のコントロールがあります。 最大の障害では、これはノイズとしても使用できます。

## パラメーター

* **タイリング**: *1 - 16*\
  結果をタイルする回数を設定します。
* **障害**: *0.0 ～ 100.0*\
  編み目のステッチの周りを飛び散って、バリエーションを生み出します。
* **45度回転**: *False/True*&#x200B;あらかじめ設定された角度に回転します。
* **非正方形拡張**: *False/True*\
  カボチャと伸縮の補正を非正方形の比率で有効にします。
