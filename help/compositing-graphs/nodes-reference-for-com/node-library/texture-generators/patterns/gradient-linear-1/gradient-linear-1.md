## 説明

単純な白黒の線形グラデーション。 グラデーションの変化が完全に滑らかになるように、補間した結果が得られます。

シンプルであるにもかかわらず、これは他の多くのノードとの構成要素として使用できる非常に便利なパターンです。 [ヒストグラムスキャン](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/histogram-scan/histogram-scan.md)などで試してみてください。

## パラメーター

* **タイリング**: *1 - 16*\
  結果をタイルする回数を設定します。
* **回転**: *0°、90°、180°、270°*&#x200B;あらかじめ定義された角度に沿って回転します。 グラデーションの方向を変更します。
