## 説明

[シェイプスプラッタ](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/shape-splatter/shape-splatter.md)データを入力として受け取り、カラーまたはグレースケールのマップを生成します。

## パラメーター

* **背景色**: *色入力*
* **パターン1-8**: *カラー入力*
* **カラー入力**: *カラー入力*
* **スプラッタデータ1**: *色入力*
* **スプラッタデータ2**: *色入力*

### パラメーター

* **パターン番号**: *1 - 8*
* **ランダムパターンの割り当て（色のみ）**: *0.0 ～ 1.0*
* **&#x200B;標準マップ**（カラーのみ）です****: *False/True*
* **HSL/輝度調整**: *-1.0 - 1.0*
* **HSL/輝度ランダム**: *-1.0 - 1.0*
* **&#x200B;標準角度ランダム**（カラーのみ）****: *0.0 ～ 1.0*
* **カラー入力の不透明度**: *0.0 ～ 1.0*
