## 説明

タイルSamplerは、究極のタイルパターン生成ノードです。 これは、[Tile Generator](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md)の進化した、より複雑なバージョンです。 2017年2.1より、タイルSamplerと[Generator](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md)の違いははるかに小さくなっています。 主な違いは、スケール、位置、回転、サイズ、カラー、およびマスクを制御するために使用できる7つの異なるマップスロットだけです。 これらのエフェクトは、で個別にブレンドできます。

タイルSamplerは、外部入力マップによって駆動される特定のパラメーターをさらに制御する人工のプロシージャルパターンを作成するのに便利です。

タイルSamplerに進む前に、[Tile Generator](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md)をよく理解していることを確認してください。 ほとんどの場合、[Tile Generator](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/texture-generators/patterns/tile-generator/tile-generator.md)で十分であり、「タイルSampler」をさらに複雑にする必要はありません。

<a name="inputs"></a>

## 入力

|  |  |
|:---|:---|
| <b>パターン入力1-6</b> <i>グレースケール入力/カラー入力</i> | カスタムパターン画像。「Pattern」パラメーターが「Image Input」に設定されている場合に使用されます。<br><br>使用可能な入力の量は、<b>Pattern Input Number</b>パラメーターによって決定されます。 |
| <b>マップ入力の拡大/縮小</b> <i>グレースケール入力</i> | グレースケールマップはタイルの拡大・縮小を促進します。 |
| <b>ディスプレイスメントマップの入力</b> <i>グレースケール入力</i> | グレースケールマップでタイルのディスプレイスメントを促進。 |
| <b>回転マップ入力</b> <i>グレースケール入力</i> | グレースケールマップはタイルの回転を促進します。 |
| <b>ベクトルマップ入力</b> <i>カラー入力</i> | カラーベクトルマップを使用して不均等なスケーリングを行います。 |
| <b>カラーマップの入力</b> <i>グレースケール入力/カラー入力</i> | タイルごとの色合いをドライブにマップします。 |
| <b>マスクマップの入力</b> <i>グレースケール入力</i> | 特定のタイルを非表示にするために使用されるマスクスロット。 |
| <b>パターン配布マップの入力</b> <i>グレースケール入力</i> | 複数のカスタムパターン入力を駆動するために使用されるマスクスロット。 |
| <b>バックグラウンド入力</b> <i>グレースケール入力/カラー入力</i> | オプションの背景画像。 |

## パラメーター

|  |  |
|:---|:---|
| <b>X金額</b> <i>0 - 64</i> | パターンのX繰り返しの量。 |
| <b>Y金額</b> <i>0 - 64</i> | パターンのY繰り返しの量。 |
| <b>非正方形拡張</b> <i>False/True</i> | カボチャと伸縮の補正を非正方形の比率で有効にします。 |
| <b>パターン</b> |  |
| <b>パターン</b> <i>パターン入力，正方形，円盤， 放物面,ベル，ガウス， とげ, ピラミッド,レンガ,グラデーション，波，ハーフベル，うね付きベル,三日月,カプセル,円錐</i> | 使用するパターン形状を選択します。 |
| <b>パターンの入力番号</b> <i>1 - 6</i> | ランダムに選択するカスタムパターンの量。 |
| <b>パターン入力の分布</b> <i>ランダム、パターン番号、配布マップ</i> | 複数のパターン入力の選択方法を設定します。 「ランダム」はランダムな番号を選択し、「パターン番号」はループシーケンスにそのまま配置されることを意味します。 分布マップでは、グレースケールマップ入力を使用して配置を行います。 |
| <b>パターン入力フィルタリング (エンジン > v4)</b> <i>バイリニア+ミップマップ，バイリニア，最も近い</i> |  |
| <b>パターン固有</b> <i>0.0 - 1.0</i> | 選択したパターンのシェイプを変更できます。 効果は選択したパターンによって異なります。 |
| <b>パターン固有のランダム</b> <i>0.0 - 1.0</i> | ランダム化効果は、選択したパターンに依存します。 |
| <b>回転</b> <i>0, 90, 180, 270</i> | ステップ回転（90度） |
| <b>ランダムな回転</b> <i>0.0 - 1.0</i> | タイルごとにランダムに自由回転します。 |
| <b>対称ランダム</b> <i>0.0 - 1.0</i> | 以下の動作に従って、ランダムにフリップ/ミラーするタイルの数を設定します。 |
| <b>対称ランダムモード</b> <i>水平方向+垂直方向、水平方向、垂直方向</i> | 対称ミラーリングの動作を決定します。 |
| <b>サイズ</b> |  |
| <b>サイズモード</b> <i>標準、縦横比を維持、絶対、ピクセル</i> | パターンサイズの一般的な動作を設定します。<br><br>標準では、パターン要素のサイズを定義できます。 XおよびYの量の影響を受けます。<br><br>縦横比を維持を使用すると、XとYの量による影響を受けるサイズを設定できますが、両者のXとYの比率は変更されません。<br><br>絶対： XとYの量に影響されない絶対サイズを設定します。<br><br>ピクセルでは、XおよびYの量に影響されない絶対サイズをピクセル単位で設定できます。 解像度を変更すると、エレメントのサイズに影響します。 |
| <b>サイズ（絶対/ピクセル）</b> <i>0.0 - 1.0</i> | タイルの縦横比を変更します。 正確な動作は、サイズモードによって異なります。 |
| <b>サイズがランダム</b> <i>0.0 - 1.0</i> | タイルあたりの比率をランダム化します。 |
| <b>スケール</b> <i>0.0 - 10.0</i> | グローバルタイル尺度を設定します。 |
| <b>ランダムに拡大・縮小</b> <i>0.0 - 1.0</i> | タイルごとにスケールをランダム化します。 |
| <b>スケールマップマルチプライヤ</b> <i>0.0 - 1.0</i> | スケールマップの効果のブレンド。 |
| <b>スケールベクトルマップマルチプライヤ</b> <i>0.0 - 1.0</i> | 不均等なスケーリングを行うスケールベクトルマップの効果のブレンド。 |
| <b>スケールパラメーター化の影響</b> <i>XとY、X、Y</i> | スケールパラメータ化が影響する軸を設定します。 スケールマップが要素のXまたはYにのみ影響するようにするために使用できます。 |
| <b>位置</b> |  |
| <b>ランダムな配置</b> <i>0.0 - 10.0</i> | 両方の軸のタイルの位置をランダムに変化させます。 |

| <b>グローバルオフセット</b> <i>0.0 - 1.0</i> | すべてのタイルをX方向またはY軸にグローバルにオフセットします。 |
| <b>ディスプレイスメントマップの適用度</b> <i>0.0 - 1.0</i> | オフセットのディスプレイスメントマップの強さのブレンド。 |
| <b>ディスプレイスメント角度</b> <i>0.0 - 1.0</i> | ディスプレイスする角度を設定します。 |
| <b>ベクトルマップディスプレイスメント</b> <i>0.0 - 1.0</i> | ベクトルマップを使用して、ディスプレイスメントと角度を制御します。 |
| <b>回転</b> |  |
| <b>回転</b> <i>0.0 - 1.0</i> | すべてのタイルをグローバルに回転します。 |
| <b>ランダムな回転</b> <i>0.0 - 1.0</i> | タイルごとにランダムに回転します。 |
| <b>回転マップ乗数</b> <i>0.0 - 1.0</i> | タイルごとの回転に対する回転マップの効果をブレンドします。 |
| <b>ベクトルマップマルチプライヤ</b> <i>0.0 - 1.0</i> | ベクトルマップを使用して、タイルごとの回転を制御します。 |
| <b>色</b> |  |
