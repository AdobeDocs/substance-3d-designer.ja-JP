## 説明

空間内の2点の座標に基づいて、球状に投影された線形状を生成します。 [シェイプライト](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/3d-view-library/hdri-tools/shape-light/shape-light.md)と比較して、シェイプの方向を変更したり、光のシェイプに繰り返しパターンを適用したりするためのオプションが多く用意されています。

このノードの配置モードは、他のHDRIライトノードよりも多少複雑です。 いくつかの異なるサイズモードを試して、どのモードが自分のシナリオに適しているかを見つけることをお勧めします。

## 入力

* **背景画像の入力**: *色入力*\
  生成されたライトを構成するオプションの背景。
* **シェイプ画像の入力**: *カラー入力*\
  ラインライトにマッピングするオプションの画像。 シェイプのカラーモードが画像入力に設定されている場合にのみ使用されます。
* **パターン画像の入力**: *グレースケール入力*\
  カスタムパターン画像。「Pattern」パラメーターが「Image Input」に設定されている場合に使用されます。

## パラメーター

* **ポジションモード**: *地面/天井、原点、ワールドポジション*\
  3つの異なる配置モードから選択します。 地面/天井と原点のサポートの操作2Dビューでは、ワールド位置はプロパティを通じてのみ変更できますが、より正確な配置をサポートします。
* **グリッドの表示**: *False/True*\
  デバッググラウンドグリッドの描画を有効にするヘルパー関数。 スペース内の行の位置の推定に役立ちます。
* **位置の座標**
  * **上向きベクター**: *Z上向き、Y上向き*\
    ワールド位置モードでのみ、座標系の方向を決定します。
  * **ポイント1 UV位置**:\
    地面/天井と原点のみ。 UV空間の1点目の位置を設定します。
  * **ポイント2 UV位置**:\
    地面/天井と原点のみ。 UV空間の2番目のポイント位置を設定します。
  * **ポイント1ワールド位置**: *-2.0 - 2.0*\
    ワールド位置モードの場合のみ。 ワールド空間の1点目を設定します。 2Dビューのインタラクションはサポートされていません。
  * **ポイント2ワールド位置**: *-2.0 - 2.0*\
    ワールド位置モードの場合のみ。 ワールド空間の2番目の点を設定します。 2Dビューのインタラクションはサポートされていません。
  * **行絶対Height**: *0.0 - 1.0*\
    Ground/Ceiling Position Modeでのみ、天井からの絶対Heightを設定します。 [グリッドを表示]を使用して、位置をより正確に推定します。
  * **原点**: *0.0 ～ 1.0*\
    原点ポジションモードの場合のみ 両方のポイントのパノラマ中心からの距離を設定します。
* **図形のカラーモード**: *RGB、色温度（ケルビン）、画像入力*\
  シェイプカラーの設定に使用する方法を選択します。 イメージ入力により、2番目の入力スロットが使用可能になります。
* **色**: *（色値）*\
  シェイプカラーモードを「RGB」に設定した場合のみ シェイプのカラーを選択します。
* **温度**: *800.0 - 20000.0*\
  Shape Color ModeがTemperatureに設定されている場合のみ シェイプのカラーのケルビン値を設定します。
* **シェイプ画像のUVモード**: *伸縮、中央のみ伸縮、繰り返し+間隔*\
  シェイプのカラーモードを画像入力に設定した場合のみ。 イメージをラインシェイプに適用する方法を設定し、UVの繰り返し動作を決定します。
* **図形の画像の繰り返し間隔**: *0.0 ～ 1.0*\
  シェイプカラーモードを画像入力に設定し、UVモードを繰り返し+間隔に設定した場合のみ。 画像が線に沿って繰り返される際の間隔を設定します。
* **シェイプ画像のガンマ**: *sRGB、リニア*\
  シェイプのカラーモードを画像入力に設定した場合のみ。 シェイプ画像の入力を解釈する方法を指定します。
* **露光量(EV)**: *0.0 - 10.0*\
  生成されたシェイプの露光量値を設定します。背景画像の露光量値と理想的に一致させます。
* **行の回転**: *0.0 ～ 1.0*\
  長さの軸に沿って線分を回転します。 ラインは回転時にフラットカードとして扱われます。
* **回線Thickness**: *0.0 - 1.0*\
  ラインカードのThicknessを設定します。
* **パターン**: *正方形、正方形（シャープ）、円錐、半球、画像入力*\
  使用するパターン形状を選択します。
* **パターンの硬さ**: *0.0 ～ 1.0*\
  パターンの硬さ/コントラストを設定します。
* **パターンUVモード**: *伸縮、中央のみ伸縮、繰り返し+間隔*\
  シェイプ画像の上に適用される第2パターンマスクの使用方法を設定します。
* **パターンの繰り返し間隔**: *0.0 ～ 1.0*\
  パターンUVモードが繰り返し+間隔に設定されている場合のみ。 繰り返されるパターンの間隔を設定します。
* **グラウンドクリッピングを有効にする**: *False/True*\
  線画のクリッピングを有効にします。 地面/天井の配置モードを使用している場合、効果は表示されません。
* **地上Height**: *-2.0 - 0.0*\
  クリッピングに使用するフロンド平面の相対Heightを設定します。 描画されたグリッドに影響します。
* **バックグラウンド入力を有効にする**: *False/True*\
  オプションの背景画像の使用を切り替え 生成されたライトを背景の上に合成します。
* **背景色**: *（色値）*\
  背景入力を使用しない場合は、単色の背景色を設定します。
* **バックグラウンドガンマ**: *sRGB、リニア*&#x200B;バックグラウンド入力を使用する場合は、バックグラウンド入力の解釈方法を設定します。
