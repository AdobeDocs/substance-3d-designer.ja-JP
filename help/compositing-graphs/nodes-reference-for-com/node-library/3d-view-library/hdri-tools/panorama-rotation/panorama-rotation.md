## 説明

入力された球面にマップされたパノラマ画像を中心点を中心に回転させ、投影/マッピングを正確に保ちます。 HDRI画像のティルトや調整に便利です。

| <b>方向角度</b> <i>0.0 - 1.0</i> |  |

| <b>柱の周りのポスト回転</b> <i>0.0 - 1.0</i> |  |
