## 説明

入力画像のカラーバランスを調整します。 写真のホワイトバランスの調整と同様です。 オフキーのHDR画像のカラーを暖色または寒色にするために使用できます。

## パラメーター

* **温度**: *-1.0 - 1.0*\
  暖色と寒色のカラーを切り替えます。
* **マゼンタ – グリーン**: *-1.0 - 1.0*\
  マゼンタとグリーンの間でトーンをシフトします。
* **カラースペース**: *HDR （リニア）、LDR (sRGB)*入力画像のカラースペースの変換方法を決定します。
