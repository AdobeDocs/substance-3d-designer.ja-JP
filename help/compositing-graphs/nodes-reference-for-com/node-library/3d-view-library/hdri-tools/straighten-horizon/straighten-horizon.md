## 説明

水平がまっすぐでないHDRIの場合、このノードを使用すると、これを簡単に修正できます。

## パラメーター

* **水平方向の補正を有効にする**: *False/True*\
  エフェクトを有効または無効にします。 補正前と補正後を比較して正しいポイントを見つけるかどうかを切り替えることができます。
* **水平点#1位置**:\
  最初のポイントは2D ビューハンドルです。
* **水平点#2位置**:\
  2番目の点には2D ビューハンドルがあります。
* **水平方向の回転**: *0.0 ～ 1.0\
  中央の軸を中心とした回転を追加します。*
