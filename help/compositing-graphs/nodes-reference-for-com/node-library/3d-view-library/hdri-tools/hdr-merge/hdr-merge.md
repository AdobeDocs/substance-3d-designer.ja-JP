## 説明

複数の写真の露光量を結合して、ハイダイナミックレンジの画像を作成します。 最初の入力は、最も表示が少ないイメージです。

## 入力

* **入力1-**&#x200B;**&#x200B; 16**: *カラー入力*入力画像。 使用可能な量はパラメーターによって異なります。

## パラメーター

* **入力**: *2 - 16*\
  使用可能な入力量を設定します。
* **露出デルタ(EV)**: *0.0 - 4.0*\
  イメージ間で解釈する露出の差を設定します。
* **白色点**: *0.0 ～ 13.0*&#x200B;最終結果に対して調整を行う白色点を設定します。
