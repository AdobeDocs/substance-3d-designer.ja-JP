# 3Dビュー（ライブラリ）

「3Dビュー」カテゴリには、球面投影HDRIに関連するノードのみが含まれます。このノードは、Substance 3D Designerの3Dビューで使用されるか、Substance 3D Painterなどの他のアプリケーションに書き出すために使用されます。

次の2つのサブカテゴリがあります。

* **HDRI環境**：ドキュメントは利用できません。これらは3Dビューで表示するための純粋な画像であり、追加のパラメーターはありません。
* **HDRI ツール**：球HDRI画像を作成および編集するためのツールノード。 SD 2019.2で導入されました。
