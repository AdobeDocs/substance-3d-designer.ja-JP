# フィルター

フィルターは、入力を処理して、他の既知の画像処理アプリケーションで使用されるような、変更された「フィルター処理」出力を作成するノードです。 [マテリアルフィルター](../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/material-filters.md)との大きな違いは、完全なマテリアルを表さない1つ（場合によってはそれ以上）の入力でのみ動作することです。

フィルターは、最もよく使用される主要カテゴリの1つです。 [アトミックノード](../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/atomic-nodes.md)以外のカテゴリは、テクスチャを最初から作成する場合に便利です。 時間をかけて、各サブカテゴリについて理解してください。

* [調整](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/adjustments.md)\
  カラー、トーン、値の調整を拡張しました。
* [ブレンド](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blending/blending.md)\
  高度な描画モードと拡張された描画モード
* [ぼかし](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/blurs.md)\
  高度で高品質なぼかし。
* [チャネル](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/channels/channels.md)\
  拡張されたチャンネルミキシングノード。
* [効果](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/effects/effects.md)\
  テクスチャリングを使用するイメージエフェクトと「レイヤースタイル」タイプのエフェクト。
* [標準マップ](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/normal-map/normal-map.md)\
  Normal Mapのフォーカスされた操作。
* [タイル表示](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/tiling/tiling.md)\
  ノードは、タイリングの修正と向上に重点を置いています。
* [変形](../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/transforms/transforms.md)\
  高度な（数学的な）2D空間変換操作。

>[!NOTE]
>
> *カスタム*&#x200B;フィルターの簡単な設定を示すプロジェクトファイルは、このドキュメントの[Substance合成グラフのサンプル](../../../../compositing-graphs/sample-compositing-graphs/sample-substance-compositing-graphs.md)セクションにあります。
