## 説明

入力値を定義済の制限にクランプします。

## パラメーター

* **分**: *0.0 ～* 1.0\
  クランプ下限。
* **最大**: *0.0 ～ 1.0*&#x200B;クランプ上限。
* **Alphaに適用**: *False/True* （カラーバージョンのみ）\
  クランプをアルファにも適用するかどうかを選択します。
