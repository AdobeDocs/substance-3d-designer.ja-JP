## パラメーター

|  |  |
|:---|:---|
| <b>グレースケールの種類</b> <i>彩度低下、輝度、平均、最大、最小</i> | 彩度を下げると彩度が0、ルミナンスでは公式の輝度のウェイト値が使用され、平均値はアトミックノードと同じ、最大値と最小値は各チャンネルで最も明るい値を使用します。 |
