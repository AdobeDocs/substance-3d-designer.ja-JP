## 説明

コントラストと輝度（明るさ）を簡単に調整できます。

## パラメーター

* **コントラスト**: *-1.0 - 1.0*\
  結果のコントラストを調整します。
* **輝度**: *-1.0 - 1.0*\
  結果の輝度（明るさ）を調整します。
