## 説明

指定された指数で入力を指数します。 [レベル](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/levels/levels.md)中間点の調整に似ていますが、より単純なパッケージです。 正確な数値の累乗演算を実行する場合にも便利です。

重要：カラーとグレースケールのどちらの入力があるかに応じて、正しいバージョンを使用してください。

## パラメーター

* **指数**: *0.0 ～ 10.0*&#x200B;入力の指数を求める指数。
