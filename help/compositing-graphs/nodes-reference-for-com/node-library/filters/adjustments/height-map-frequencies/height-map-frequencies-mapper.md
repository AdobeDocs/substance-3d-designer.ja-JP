## 説明

ハイトマップの周波数を2つの個別のマップ（大きなスケールの違いのあるマップと小さなスケールの違いのあるマップ）に分割します。

## パラメーター

* **リリーフ**: *0.0 ～ 32.0*&#x200B;ディスプレイスメント出力の詳細サイズを制御します。
