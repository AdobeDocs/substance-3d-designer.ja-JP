## パラメーター

|  |  |
|:---|:---|
| <b>範囲の最小値</b> <i>-2.0 - 0.0</i> | ハイライト表示を開始する最小範囲。 |
| <b>範囲の最大値</b> <i>1.0 - 3.0</i> | ハイライト表示する最大の範囲。 |
