## 説明

ハイダイナミックレンジで正確な領域を確認するためのデバッグツール。 カラーバージョンとグレースケールバージョンの両方が存在します。

## パラメーター

* **範囲の最小値**: *-2.0 ～ 0.0*&#x200B;ハイライト表示を開始する最小範囲。
* **範囲の最大値**: *1.0 ～ 3.0*&#x200B;最大ハイライト表示する範囲。
