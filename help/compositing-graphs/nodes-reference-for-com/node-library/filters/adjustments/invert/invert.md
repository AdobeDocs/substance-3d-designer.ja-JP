## 説明

入力カラーを反転します。

重要：入力に適したバージョンを使用してください。 カラー入力には「反転」、グレースケール入力には「グレースケール反転」を使用します。

## パラメーター

* **反転**: *偽/真*&#x200B;効果のオンとオフを切り替えます。
