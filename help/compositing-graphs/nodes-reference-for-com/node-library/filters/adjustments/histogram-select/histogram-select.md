## 説明

[ヒストグラムのスキャン](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/adjustments/histogram-scan/histogram-scan.md)と同様に、このエフェクトは、フェードアウトする範囲を含むグレースケール値の位置を設定します。 コントラストを調整して、範囲をよりシャープにすることができます。

[ここをクリックして、ヒストグラムの選択に関するSubstanceアカデミーのビデオをご覧ください。](https://youtu.be/p9wcmJBFyGA?t=535)

## パラメーター

* **位置**: *0.0 ～ 1.0*&#x200B;範囲の選択を行う中央の位置を設定します。
* **範囲**: *0.0 ～ 1.0*&#x200B;選択範囲の幅を設定します。
* **コントラスト**: *0.0 ～ 1.0*\
  結果のコントラスト/フォールオフを調整します。
