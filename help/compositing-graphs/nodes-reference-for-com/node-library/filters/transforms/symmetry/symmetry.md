## 説明

入力画像に対して各種の対称処理を実行します。 幾何学的シェイプを対称にするために使用できます。

このノードは[ミラー](../../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/transforms/mirror-filter-node/mirror-filter-node.md)によく似ていますが、描画モードの制御が追加されています。

## パラメーター

* **対称モード**: *ミラーY、ミラーX、斜め左、対角線右、ミラーX/Y、ミラーX/ミラーY、対角線左/対角線右、対角線右/対角線左、8*&#x200B;対称幾何モードを選択します。
* **転送モード**: *0 ～ 6*&#x200B;対称描画モード（コピー、追加、減算、乗算、サブを追加、最大、最小）を選択します。
