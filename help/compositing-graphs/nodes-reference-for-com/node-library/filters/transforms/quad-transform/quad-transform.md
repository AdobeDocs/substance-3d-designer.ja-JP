## 説明

特別なトランスフォームノードで、四半円シェイプのコーナーポイントとの相互作用を通してトランスフォームできます。 非常に特定の変換を実践的に実行できます。

## パラメーター

* **p00**：左上のポイントです。
* **p01**：左下の点
* **p10**：右上の点。
* **p11**：右下の点。
* **カリング**: *前面のみ、背面のみ、前面から背面、背面から前面*&#x200B;ポイントが交差している場合にシェイプのカリング/非表示を設定します。
* **タイル表示を有効にする**: *False/True*
* **背景色**: *（グレースケール値）*タイル表示がオフの場合は単色の背景色。
* **サンプリング**: *バイリニア、最も近い*&#x200B;サンプリング品質を設定します。
