## 説明

遠近法/台形ワープで入力を変更する特殊な変形ノード。 上下の伸縮を制御できます。 より強いエフェクトを得るには、値を制限を超える値に設定します。

## パラメーター

* **上の伸縮率**: *0.0 ～ 1.0*&#x200B;上の伸縮率または収縮の量を設定します。
* **下の伸縮率**: *0.0 ～ 1.0*&#x200B;底の伸縮率または収縮の量を設定します。
* **背景色**: *（グレースケール/カラー値）*\
  タイル表示がオフになっている場合は、単色の背景色を設定します。
* **サンプリング**: *バイリニア、最も近い*&#x200B;サンプリング品質を設定します。
