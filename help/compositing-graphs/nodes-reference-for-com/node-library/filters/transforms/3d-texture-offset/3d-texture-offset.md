## 説明

**3Dテクスチャオフセット**&#x200B;ノードは、**入力**&#x200B;に接続された&#x200B;*3Dテクスチャ*&#x200B;によって記述されるオブジェクトの&#x200B;**X**、**Y**&#x200B;および&#x200B;**Z**&#x200B;軸の&#x200B;*オフセット変換*&#x200B;を適用します。

</td>
</tr>
</table>

## パラメーター

### 入力

* **入力** *グレースケール/カラー*\
  3Dオブジェクトを表す&#x200B;*3Dテクスチャ*。\
  オブジェクトは通常、*単位キューブ*&#x200B;で記述されます。

### パラメーター

* **オフセット** *浮動小数点3*\
  **入力**&#x200B;に接続された&#x200B;*3Dテクスチャ*&#x200B;によって記述されたオブジェクトに適用された&#x200B;*ワールド空間*&#x200B;のオフセットの量です。
