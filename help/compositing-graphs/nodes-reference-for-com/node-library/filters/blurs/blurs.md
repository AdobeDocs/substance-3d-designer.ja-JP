# ブラー

[ぼかし]カテゴリが[標準のアトミックボックスぼかしノード](../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/blur/blur.md)で展開されます。 より高度で高品質なぼかしは、複数の用途に使用できます。

ライブラリぼかしノードには、必ずグレースケールとカラーのバージョンがあります。 入力に適したバージョンを使用してください。

おすすめのブラー：

* [ブラー HQ](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/blur-hq/blur-hq.md)
* [ぼかし(勾配)](../../../../../compositing-graphs/nodes-reference-for-com/node-library/filters/blurs/slope-blur/slope-blur.md)
