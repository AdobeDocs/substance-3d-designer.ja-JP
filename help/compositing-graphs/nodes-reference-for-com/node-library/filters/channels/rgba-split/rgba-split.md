## 説明

入力画像を赤、緑、青、アルファチャンネルに分割します。 画像を効果的に「アンパック」します。

パックされたチャネルを個別に分析および使用する場合に便利です。 Substance Painterのエフェクトにベイク位置マップまたはベイクワールド空間ノーマルマップを使用する場合、例えばX、Y、またはZコンポーネントをシングルアウトできます。
