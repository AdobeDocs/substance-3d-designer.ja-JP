## 説明

入力画像を赤、緑、青、Alphaの各チャンネルに分割します。 画像を効果的に「アンパック」します。

パックされたチャネルを個別に分析および使用する場合に便利です。 ベイク処理された位置マップ、またはベイク処理されたワールド空間の法線マップを使用してSubstance Painterのエフェクトを作成する場合、たとえばX、Y、またはZコンポーネントをシングルアウトできます。
