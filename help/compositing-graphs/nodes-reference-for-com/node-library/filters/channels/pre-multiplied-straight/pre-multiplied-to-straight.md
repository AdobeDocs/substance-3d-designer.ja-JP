## 説明

アルファブレンドされたエッジ上のRGBから乗算済みのカラーを削除します。 背景色の合成を実質上解除しますが、このときアルファチャンネルは除去されます。

これにより、アルファチャンネル画像のエッジの周囲に見られるフリンジ効果を取り除くことができます。
