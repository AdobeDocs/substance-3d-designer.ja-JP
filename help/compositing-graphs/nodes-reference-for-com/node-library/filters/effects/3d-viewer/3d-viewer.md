## 説明

関数グラフで定義された指定のSDFまたは交差点シーンの3Dレンダリングを、カスタムのカメラと環境光を使用して計算します。<br><br>このノードは、[Shape splatter v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md)ノードで使用される[SDF 関数](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions)を作成および視覚化するのに役立ちます。<br><br>ヘルパーは、空間における図形のキー属性を視覚化するために使用できます。<br><br>上級ユーザーの場合、カスタム関数を作成して、カメラやピクセル単位の3Dレンダリングを設定できます。

</tr>
</table>

> 
> SDF 関数に関する概念やワークフローについて詳しくは、専用ページ（[SDF 関数の操作](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-nodes-sdf-functions/working-with-sdf-functions.md)）を参照してください

<a name="inputs"></a>

## 入力

|                            |                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
|:---------------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>環境</b> *色* | シーンの環境として使用され、環境照明に使用される無限球に投影されるイメージ。<br><br>投影は<i>正距円筒図法</i>で、Designerの既定の環境で使用されているものと同じです（ライブラリの<b>3D ビュー/HDRI環境マップ</b>カテゴリで使用可能）。<br><br>接続されていない状態では、既定の環境が使用されます。<br><br><i>ヒント：</i>正確な照明を得るには、HDRイメージ（32ビット）を使用してください。 |
| <b>入力1</b> *色* | <b>Output</b>パラメーターが&#39;Custom&#39;に設定されている場合に、<b>Custom output</b>関数グラフでサンプリングできるイメージ。<br><br>&#39;Image input 0&#39;に設定された[Sample color](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md)ノードを使用して、このイメージからサンプリングします。 |
| <b>入力2</b> *色* | <b>Output</b>パラメーターが&#39;Custom&#39;に設定されている場合に、<b>Custom output</b>関数グラフでサンプリングできるイメージ。<br><br>&#39;Image input 1&#39;に設定された[Sample color](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md)ノードを使用して、このイメージからサンプリングします。 |

<a name="outputs"></a>

## 出力

|               |                                                                                                                                                                                                                                    |
|:--------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>出力</b> | <b>Output</b>パラメーターで選択されたAOVを使用してレンダリングされたシーン。<br><br><i>注意：</i>一部のAOVを正確に読み取るには、2D ビューに線形カラースペースを使用し、ノードでHDR 32ビット出力フォーマットを使用していることを確認してください。 |

<a name="parameters"></a>

## パラメーター

|                                               |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
|:----------------------------------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| <b>シーンの種類</b> *整数* | レンダリングするサーフェスと図形の記述に使用する関数の種類：<br>- <b>SDF:</b>複雑な図形を記述できるSDF (Signed Distance Field)関数を使用してください。<br>- <b>交差点：</b>交差関数を使用すると、単純なプリミティブ図形のみが必要な場合に高速になります。 |
| <b>SDF シーン</b> *フロート* | シーン内のサーフェスとシェイプを記述するSDF（符号付き距離フィールド）関数。<br><br>関数を作成するには、ライブラリの[SDF 関数](../../../../../../function-graphs/nodes-reference-for-fun/function-node-library/function-node-library.md#sdf-functions)カテゴリのノードを使用します。 |
| <b>シーンの共通範囲</b> *フロート* | シーン内のサーフェスとシェイプを記述する交差関数。<br><br>単純なプリミティブおよび演算子の交差関数は、<b>3d_functions.sbs</b>ライブラリパッケージの<b>3d_intersection</b>フォルダで使用できます。<br><br><i>ヒント：</i>ライブラリのSDFノードをエクスプローラにドロップすると、パッケージにアクセスできます。 |
| <b>出力</b> *整数* | ノードによって出力される必要がある3Dレンダリングの種類。一般にAOV （任意出力変数）と呼ばれます。<br><br>使用可能なAOVは次のとおりです。<br>- <b>美しさ：</b> 3Dレンダリングの最終結果。芸術的な色と効果を使用します。<br>- <b>法線WS:</b>シーン内のシェイプのワールド空間法線。<br>- <b>法線TS:</b>シーン内のシェイプのの接線空間法線。<br>- <b> position:</b>シーン内のシェイプのサーフェスのワールドスペース位置。<br>- <b>Distance:</b>カメラからシーン内のシェイプまでのRaw Distance<br>- <b>深度:</b> The signed distance of the shapes target plane, where the plane were faces the camera.<br>- <b>Color:</b> Shapes&#39;基本色（&#39;Set color&#39;ノードを使用してシーン関数のシェイプに色を割割り当てる）<br>- <b> ID:</b>シェイプサーフェスに適用されたマテリアルID （&#39;マテリアルIDを設定&#39;ノードを使用して、シーン関数のシェイプにマテリアルIDを割り当てます）<br>- <b>球トレーシングステップ：</b>シェイプのサーフェスを定義するために必要なステップの量の視覚化。 値を明るくすると、より多くのステップが必要になります。<br>- <b>カスタム：</b>ピクセルごとにレンダリングの色を計算するカスタム関数を作成します。<br><br><i>注意：</i>一部のAOVで正確な値を取得するには、2Dビューで線形カラースペースを使用し、ノードでHDR 32ビット出力形式を使用していることを確認してください。 |
| <b>カスタム出力</b> *浮動小数点4* | レンダリングされたシーンのピクセルごとのRGBAカラーを定義する関数グラフ。Float4値で表されます。<br><br>使用可能な変数：<br>- <code>scene.position</code> (Float3)シーンのサーフェスのワールド空間の位置。<br>- <code>scene.normal</code> (Float3)シーンのサーフェスのワールド空間法線です。<br>- <code>scene.hit</code> （ブール型）サーフェスがカメラレイに当たると&#39;True&#39;を返します。<br>- <code>view.origin</code> (Float3)カメラビューのピクセルごとのワールド空間の位置。<br>- <code>view.direction</code> (Float3)投影モードに応じた、カメラビューのピクセル単位の前方ベクトル。 (E.g. 遠近法または直交投影)<br>- <code>material.color</code> (Float3)シーンのサーフェスのベースカラー。<br>- <code>material.metalness</code> （フロート）シーンの表面のメタネス。<br>- <code>material.roughness</code> （フロート）シーンの表面の粗さ。<br>- <code>material.id</code> （整数）シーンのサーフェスのマテリアルID。<br><br>ノードの画像入力は、次の[サンプルカラー](../../../../../../function-graphs/nodes-reference-for-fun/atomic-function-nodes/sampler-nodes/sampler-nodes.md)ノードスロットを選択してサンプリングできます： <br>- <b>画像入力0</b>サンプル入力1.<br>- <b>画像入力1</b>サンプル入力2。 |
| <b>環境のローテーション</b> *浮動小数* | <b>Environment</b>の回転をターン数で指定します。 |
| <b>背景モード</b> *整数* | シーンの背景のソースを指定します。図形の面が表示されない場所に描画されます。<br><br>- <b>色：</b>平坦な&#39;背景色&#39;。<br>- <b>環境：</b> &#39;Environment&#39;入力に指定された画像が、正距円筒投影を使用して無限球に適用されました。  （入力が接続されていない場合は、デフォルトの環境が使用されます）。 |
| <b>背景色</b> *浮動小数4* | シーンの背景として使用する単色です。 |
| <b>IBLサンプル</b> *整数* | カメラサンプルごとに行われる光サンプルの量です。<br><br>値が大きいほど、より滑らかで正確な照明になりますが、パフォーマンスが低下します。 |
| <b>カメラのサンプル</b> *整数* | 1ピクセルあたりに実行されるカメラサンプルの量。<br><br>このパラメーターは、アンチエイリアスの画質とフィールド効果の深度に影響します。<br><br>値を大きくすると、ノイズの少ない鮮明な画像になりますが、パフォーマンスが低下します。 |
| <b>行進ステップのレイ</b> *整数* | 球トレーシングプロセスで実行されるステップの量です。これは、図形の表面を検出して描画するために使用されるレイマーチング技法です。<br><br>値を高くすると、正確で一貫性のある表面（特に複雑な図形の場合）が得られますが、パフォーマンスが低下します。<br><br><i>ヒント：</i> <b>出力</b>パラメーターを&#39;球トレーシングステップ&#39; AOVに設定して、より多くのステップを必要とする図形の領域を表示します。 これらの領域は、手順の数を減らすことによって、最初に影響を受けます。 |
| <b>セカンダリレイマーチングステップ</b> *整数* | キャストした影を描くために、球トレーシングプロセスで拡散とSpecularのオクルージョンを計算するために実行されるステップの量です。<br><br>値が高いほど、パフォーマンスを犠牲にして正確な影を描くことができます。 |
| <b>カメラモード</b> *整数* | シーンをレンダー画像に映し出す方式：<br><br>- <b>遠近法:</b>この投影は、深度を伝え、フィールドの深度などのレンズ効果を有効にします。<br>- <b>正投影:</b>この投影はシーンを統合し、深度を無効にします。<br>- <b>カスタム関数：</b>関数グラフを作成して、カスタムカメラを設定します。 |
| <b>カメラ関数</b> *浮動小数点3* | カメラの変形を定義する関数グラフ。 これは、カスタムカメラを設定するために使用できます。<br><br>関数は<b>set</b>これらの変数を<br>- <code>view.originにする必要があります</code> (Float3)カメラビューのピクセルごとのワールド空間の位置。<br>- <code>view.direction</code> (Float3)投影モードに応じた、カメラビューのピクセル単位の前方ベクトル。 (E.g. 遠近法または正投影)<br><br>次の変数を<b>get</b>で使用できます：<br>- <code>カメラ.origin</code> (浮動小数3)カメラのワールド空間位置。 （カメラ.方向* カメラ_距離+ カメラ.ターゲット）<br>- <code>カメラ.方向</code> (浮動小数3) カメラのワールド空間方向 （カメラのY前方ベクトル）。<br>- <code>カメラ。right</code> (浮動小数3) カメラのX右ベクトルです。<br>- <code>カメラ.up</code> (浮動小数3) カメラのZアップベクトル。<br>- <code>カメラ.target</code> (浮動小数3)カメラ目標のワールド空間位置。 |
| <b>UVの位置</b> *浮動小数点2* | 2D画像空間内の位置は、<b>目標位置</b>を周回するカメラの位置と方向を推測するのに使用されます。<br><br><i>ヒント：</i>このパラメーターは、ノードが選択されたときに2D ビューで利用可能な<i>位置ギズモ</i>を使用することで、直感的に調整できます。 |
| <b>視野</b> *フロート* | ズーム倍率に影響するカメラの視野(FOV)です。 |
| <b>焦点距離</b> *フロート* | ズーム倍率とフィールド効果の深度に影響するカメラの焦点距離です。 |
| <b>ターゲットからの距離</b> *浮動小数* | カメラが<b>目標位置</b>から離れる必要がある距離です。<br><br>これを調整すると、カメラがカメラからターゲットに向かって移動します。 |
| <b>ターゲット位置</b> *浮動小数3* | カメラが常に向いているカメラターゲットの位置。 |
| <b>トネマッパー</b> *整数* | シーンレンダリングに適用する必要があるトネマッピングアルゴリズムです。<br><br>- <b>なし(Raw)<br>- <b>sRGB</b><br>- <b>AgX</b><br>- <b>ACE</b> |
| <b>フィールドの深度を有効にする</b> *ブーリアン* | カメラの「深度の被写界像」カメラ効果をシミュレートします。<br><br><b>F値</b>と<b>焦点距離</b>のパラメーターを使用して、それぞれ効果のアパーチャと焦点を調整します。<br><br>結果も<b>焦点距離</b>に影響を受けます。 |
| <b>F番号</b> *浮動小数* | カメラの<i>アパーチャ</i>.<br><br>値が小さいほど、フィールドの<i>深度</i>が短くなり、オブジェクトがシャープな場合の距離範囲が短くなり、その範囲からの距離が長くなるにつれて、ぼかし効果が強くなります。 |
| <b>焦点距離</b> *浮動小数* | フォーカルポイントの前方ベクトルに沿ったカメラからの距離を設定します。<br><br>指定した距離内のサーフェスは、その範囲（フィールド</i>の<i>深度）が<b>F-number</b>によって定義され、シャープに表示されます。 |
| <b>露光量(EV)</b> *浮動小数* | カメラセンサーに届く光の量、つまりレンダリング時の照明の強さです。<br><br>値が小さいほど、レンダリングされたシーンの色が暗くなります。<br><br>&#39;露出値&#39; (EV)は、カメラセンサーが<i>露出</i>する光の量を具体的に示します。 |
| <b>基本色</b> *浮動小数点3* | SDFまたは交差関数によって色が定義されていないサーフェスの既定の基本色。 |
| <b>粗さ</b> *フロート* | サーフェスの既定の粗さの値。この値は、SDFまたは交差関数によって定義されていません。 |
| <b>メタル</b> *フロート* | SDFまたは交差関数によって値が定義されていないサーフェスの既定のメタネス値。 |
| <b>ヘルパーの不透明度</b> *フロート* | 3Dヘルパーの不透明度。この値を小さくすると、ヘルパーの密度が低くなります。 |
| <b>バウンディングフレーム</b> *ブール値* | シーン全体の境界を定義する6つの側面のケージを視覚化したもの。 理想的には、シーンを完全に含む可能な最小サイズにする必要があります。<br><br><b>バウンディングフレームサイズ</b>パラメーターを使用して、ケージのサイズを調整します。<br><br><b>フレームからカラー化</b>パラメーターを使用すると、ケージの外側のサーフェスを簡単に視覚化できます。これは、そのシーンを[シェイプスプラッターv2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md)ノードで使用した結果に影響します。 （「バウンディングフレームサイズ」ツールヒントを参照）。 |
| <b>境界フレームサイズ</b> *浮動小数点3* | 境界フレームのXYZサイズを設定します。<br><br>シーンにフレームを調整し、同じ値を[Shape splatter v2](../../../texture-generators/patterns/shape-splatter-v2/shape-splatter-v2.md)ノードの<b>SDFバインドフレームサイズ</b>パラメーターに適用して、シーン内のすべてのシェイプがそのノードに正しく含まれ、描画されるようにします。 |
| <b>フレームの色抜き</b> *ブール値* | 境界フレームの外側のサーフェスに赤色を適用します。<br><br>これにより、シーンがバウンディングフレームに完全に含まれていることを確認できます。 |
| <b>軸</b> *ブール値* | シーンの原点から始まる色付きの線としてシーンのXYZ軸を視覚化したもの。 |
| <b>グリッド</b> *ブール値* | XY軸上に配置されたグリッドのビジュアライゼーション。XとYの1セルのサイズは1つのシーン単位です。 |
| <b>ヘルパーの変形</b> *ブール値* | 最後に適用された回転を視覚化したものです。<br><br>視覚エフェクトには、回転軸の方向ベクトルを表す<br>- <b>矢印</b>が含まれ、各ワールド空間軸の重みの後に色が付けられています。<br>- <b>矢印に直交する、回転角度を表す円弧</b>。 |
| <b>SDFアイソライン</b> *ブール値* | 署名付き距離フィールド(SDF)機能のアイソラインを色付きで表示します。<br><br>等値線は、指定されたHeightのXY平面上の図形の<i>距離フィールド</i>を表す定期的な繰り返し線です。<br><br>SDF 関数によって定義された<i>空間の均一性</i>を確認する場合に便利です。<br><br><b>SDFアイソラインの頻度</b>と<b>SDFアイソラインの位置</b>パラメーターを使用して、アイソラインの密度とHeightを調整します。 |
| <b>SDFアイソラインの頻度</b> *フロート* | 一定の距離内でのアイソライン繰り返しの量です。<br><br>値が大きいほど、線は細く、密度が高くなります。 |
| <b>SDFアイソラインの位置</b> *フロート* | アイソラインの描画に使用するXY平面のHeight。<br><br>これを使用して、さまざまな標高で図形の距離フィールドを確認します。 |
| <b>分 ヒット距離</b> *フロート* | SDFレイマーチングプロセスのヒットに移動する最小距離を定義します。<br><br>値が小さいほど、レイマーチングステップの数が増えます。 |
