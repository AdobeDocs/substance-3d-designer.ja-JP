## 説明

入力の断面プロファイルを描画します。 スライスの垂直方向または水平方向に調整でき、描画スタイル、グラフのオフセット、拡大・縮小を制御できます。

</td>

このノードは、特にハイトマップのデバッグや分析に役立ちます。 複雑なノードや3Dビューでの長く精度の低い設定を必要とせずに、ピクセルが完全なプロファイル表示を実現します。

また、2Dシェイプやシルエットを作成する場合にも使用できます。これらの方法で2Dシェイプやシルエットを作成することは困難です。 [曲線ノード](../../../../../../compositing-graphs/nodes-reference-for-com/atomic-nodes/curve/curve.md)と組み合わせると、線形グラデーションに適用された曲線プロファイルを直接視覚化できます。

## パラメーター

<b>断面座標</b> *フロート*\
スライスをサンプリングする座標を設定します。 断面の軸に応じて、X座標またはY座標を指定できます。

<b>セクション軸</b> *整数*\
スライスが垂直か水平かを設定します。

<b>ヘルパーの表示</b> *ブール値*\
入力画像上のセクションの位置を表示するオーバーレイを有効にします。

ヘルパーの設定

<b>ヘルパーのスケール</b> *フロート*\
オーバーレイのサイズを倍数で表します。1.0は画像全体です。

<b>ヘルパーの位置</b> *浮動小数点2*\
出力画像のオーバーレイの(X、Y)位置。(0.0、0.0)は左上、(1.0、1.0)は右下です。

<b>Heightスケール</b> *フロート*

グラフ全体を縮小します。 HDR表示に便利です。

<b>Heightオフセット</b> *フロート*\
グラフ全体を上下にシフトします。 HDR表示に便利です。

<b>描画スタイル</b> *整数*\
塗りつぶしと線の描画を切り替えます。

<b>グラデーションを反転</b> *ブール値*&#x200B;描画スタイルが&#x200B;*グラデーション*&#x200B;または&#x200B;*グラデーションミラー*&#x200B;に設定されている場合、背景に影響を与えずにグラデーションを反転できます。\
*注意：* &#39;描画スタイル&#39;が&#39;グラデーション&#39;または&#39;グラデーションミラー&#39;に設定されている場合にのみ使用できます。

<b>滑らか/多角形</b> *ブール値*\
シェイプを完全に滑らかなプロファイルにするか、ギザギザの多角形にするかを切り替えます。\
*注意：* &#39;描画スタイル&#39;が&#39;実線&#39;、&#39;グラデーション&#39;、または&#39;グラデーションミラー&#39;に設定されている場合にのみ使用できます。

<b>セグメントの金額</b>: *整数*\
ポリゴンスタイルまたはラインスタイルで描画するときに使用するセグメントの数を設定します。\
*注意：*&#x200B;を使用できるのは、&#39;スムーズ/ポリゴン&#39;が&#39;ポリゴン&#39;に設定されているか、&#39;描画スタイル&#39;が&#39;線&#39;に設定されている場合のみです。

<b>行のThickness</b> *フロート*\
線のThicknessを設定します。\
*注意：* &#39;図面スタイル&#39;が&#39;線&#39;に設定されている場合にのみ使用できます。

<b>線のスタイル</b> *整数*\
線のカラーと減衰を選択できます。\
*注意：* &#39;図面スタイル&#39;が&#39;線&#39;に設定されている場合にのみ使用できます。

<b>行のSmoothness</b> *フロート*\
線のグラデーションの減衰を設定します。\
*注意：* &#39;図面スタイル&#39;が&#39;線&#39;に設定されている場合にのみ使用できます。

<b>色</b> *フロート*\
線または図形のグレースケールの色です。\
*注意：* &#39;描画スタイル&#39;が&#39;実線&#39;または&#39;線&#39;に設定され、&#39;線スタイル&#39;が&#39;滑らか&#39;または&#39;実線&#39;に設定されている場合にのみ使用できます。

<b>背景色</b> *フロート*&#x200B;背景のグレースケールの色です。\
*注意：* &#39;描画スタイル&#39;が&#39;線&#39;に設定され、&#39;線のスタイル&#39;が&#39;セグメントID&#39;または&#39;線に沿ったグラデーション&#39;に設定されている場合は使用できません。
