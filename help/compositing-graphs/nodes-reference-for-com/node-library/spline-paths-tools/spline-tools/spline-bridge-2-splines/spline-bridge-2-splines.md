# スプラインブリッジ（2スプライン）

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

![ノードアイコン](../../../../../../assets/spline-bridge-2splines-icon.png "ノードアイコン")

<b>イン：</b>スプラインおよびパスツール> スプラインツール

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

これらのスプラインに沿って<b>スプライン#1</b>から<b>スプライン#2</b>までスプラインを生成します。 生成されるスプラインは、直線（直線）または三次ベジェ（曲線）になります。

</td>
</tr>
</table>

>[!IMPORTANT]
>
> <b>スプライン#1</b>および<b>スプライン#2</b>入力に指定されたデータに複数のスプラインが含まれている場合、各リストの最後のスプラインのみが使用されます。

<a name="inputs"></a>

## 入力

|  |  |
|:---|:---|
| <b>プレビュー#1</b> <i>グレースケール</i> | 入力スプラインのプレビューグレースケールイメージとして表示されます。 |
| <b>スプライン座標#1</b> <i>色</i> | 入力スプラインの点の座標#1カラー画像のRGBAチャンネルでエンコードされています。<br><b>R</b> - X位置<br><b>G</b> - Y位置<br><b>B</b> - Height<br><b>A</b> – パックデータ：<br> – 記号：スプラインが閉じている（負）か開いている（正）;<br>-絶対値: Thickness + 1。 |
| <b>スプラインデータ#1</b> <i>色</i> | 入力スプラインの追加データ#1、カラー画像のRGBAチャンネルでエンコードされます。<br><b>R</b> - 正接 X<br><b>G</b> - 正接 Y<br><b>B</b> – 未使用<br><b>A</b> – 未使用 |
| <b>スプラインの量#1</b> <i>整数</i> | 入力スプラインの#1数です。 |
| <b>プレビュー#2</b> <i>グレースケール</i> | 入力スプラインのプレビューグレースケールイメージとして表示されます。 |
| <b>スプライン座標#2</b> <i>色</i> | 入力スプラインの座標#2、カラー画像のRGBAチャンネルでエンコードされた点です。<br><b>R</b> - X位置<br><b>G</b> - Y位置<br><b>B</b> - Height<br><b>A</b> – パックデータ：<br> – 記号：スプラインが閉じている（負）か開いている（正）;<br>-絶対値: Thickness + 1。 |
| <b>スプラインデータ#2</b> <i>色</i> | 入力スプラインの追加データ#2、カラー画像のRGBAチャンネルでエンコードされます。<br><b>R</b> - 正接 X<br><b>G</b> - 正接 Y<br><b>B</b> – 未使用<br><b>A</b> – 未使用 |
| <b>スプラインの量#2</b> <i>整数</i> | 入力スプラインの#2数です。 |
| <b>開始正接長カーブ</b> <i>グレースケール</i> （&#39;ブリッジスプラインの種類&#39;が&#39;キュービックベジェ&#39;に設定されている場合に使用可能） | 1行目のピクセルの値を使用して曲線を表す画像。<br>この入力は、スプライン#1に沿って生成された各スプラインの始点の&#39;out&#39; 正接の長さを制御するために使用されます。<br>曲線ノードを使用して曲線を作成できます。 |
| <b>正接の回転カーブの開始</b> <i>グレースケール</i> （&#39;ブリッジスプラインの種類&#39;が&#39;キュービックベジェ&#39;に設定されている場合に使用可能） | 1行目のピクセルの値を使用して曲線を表す画像。<br>この入力は、スプライン#1に沿って生成された各スプラインの始点の&#39;out&#39; 正接の回転を制御するために使用されます。<br>イメージのグレースケール値は、回転の回数を表します。<br>曲線ノードを使用して曲線を作成できます。 |
| <b>終了正接長カーブ</b> <i>グレースケール</i> （&#39;ブリッジスプラインの種類&#39;が&#39;キュービックベジェ&#39;に設定されている場合に使用可能） | 1行目のピクセルの値を使用して曲線を表す画像。<br>この入力は、スプライン#2に沿って生成された各スプラインの終点の&#39;in&#39; 正接の長さを制御するために使用されます。<br>曲線ノードを使用して曲線を作成できます。 |
| <b>正接回転曲線の終了</b> <i>グレースケール</i> （&#39;ブリッジスプラインの種類&#39;が&#39;キュービックベジェ&#39;に設定されている場合に使用可能） | 1行目のピクセルの値を使用して曲線を表す画像。<br>この入力は、スプライン#2に沿って生成された各スプラインの終点の&#39;in&#39; 正接の回転を制御するために使用されます。<br>イメージのグレースケール値は、回転の回数を表します。<br>曲線ノードを使用して曲線を作成できます。 |

<a name="outputs"></a>

## 出力

|  |  |
|:---|:---|
| <b>プレビュー</b> <i>グレースケール</i> | 出力スプラインをグレースケールイメージとしてプレビューします。 |
| <b>スプライン座標</b> <i>色</i> | 出力スプラインの座標がカラー画像のRGBAチャンネルにエンコードされました。<br><b>R</b> - X位置<br><b>G</b> - Y位置<br><b>B</b> - Height<br><b>A</b> – パックデータ：<br> – 記号：スプラインが閉じている（負）か開いている（正）;<br>-絶対値: Thickness + 1。 |
| <b>スプラインデータ</b> <i>色</i> | カラー画像のRGBAチャンネルでエンコードされた出力スプラインの追加データ。<br><b>R</b> -正接X<br><b>G</b> -正接Y<br><b>B</b> – 未使用<br><b>A</b> – 未使用 |
| <b>スプラインの量</b> <i>整数</i> | 出力スプラインの数。 |

<a name="parameters"></a>

## パラメーター

|  |  |
|:---|:---|
| <b>ブリッジスプライン量</b> <i>整数</i> | スプライン#1に沿って生成されたスプラインの数をスプライン#2に変換します。 |
| <b>ブリッジスプラインの種類</b> <i>整数</i> | 生成されるスプラインのタイプ：<br><br> – 線形：始点から終点までの直線スプライン；<br> – 立方ベジェ：始点から終点までの曲線スプライン。曲線は、始点と終点の長さと角度で制御されます。 |
| <b>開始スプライン#1</b> <i>浮動小数</i> | スプラインが生成される場所からスプライン#1に沿って位置をオフセットします。 この値は、スプライン#1の正規化された長さです。<br>値が大きいほど、同じ数のスプラインがより密にパックされます。 |
| <b>開始スプライン#2</b> <i>浮動小数</i> | スプラインが生成される場所からスプライン#2に沿って位置をオフセットします。 この値は、スプライン#2の正規化された長さです。<br>値が大きいほど、同じ数のスプラインがより密にパックされます。 |
| <b>スプラインの終わり#1</b> <i>フロート</i> | スプライン#1に沿って、スプラインが生成される位置までオフセットします。 この値は、スプライン#1の正規化された長さです。<br>値が小さいほど、同じ数のスプラインがより密にパックされます。 |
| <b>スプラインの終わり#1</b> <i>フロート</i> | スプライン#2に沿って、スプラインが生成される位置までオフセットします。 この値は、スプライン#2の正規化された長さです。<br>値が小さいほど、同じ数のスプラインがより密にパックされます。 |
| <b>オフセットスプライン#1</b> <i>フロート</i> | スプライン#1に沿ったすべてのスプラインの始点にオフセットを適用します。 この値は、スプライン#1の正規化された長さです。<br>スプラインの始点または終点に一致するスプラインは、そこに残されています。 |
| <b>オフセットスプライン#2</b> <i>フロート</i> | スプライン#2に沿ったすべてのスプラインの始点にオフセットを適用します。 この値は、スプライン#2の正規化された長さです。<br>スプラインの始点または終点に一致するスプラインは、そこに残されています。 |
| <b>オフセットランダムスタート</b> <i>フロート</i> | スプライン#1に沿った各スプラインの始点にランダムオフセットを適用します。 この値は、スプライン#1上のスプライン間の正規化された距離です。<br>この値を0にすると、スプラインはスプラインの始点とスプラインの終#1の#1点の間に均等な間隔で配置されます。 |
| <b>オフセットのランダムな終了</b> <i>フロート</i> | スプライン#2に沿った各スプラインの終点にランダムオフセットを適用します。 この値は、スプライン#2上のスプライン間の正規化された距離です。<br>この値を0にすると、スプラインはスプラインの始点とスプラインの終#2の#2点の間に均等な間隔で配置されます。 |
| <b>接線の長さの始点</b> <i>浮動小数</i> （&#39;ブリッジスプラインの種類&#39;が&#39;キュービックベジェ&#39;に設定されている場合に使用可能） | 生成されたすべてのスプラインのスプライン#1の始点の「out」正接の長さ。 |
| <b>接線の長さの終了</b> <i>浮動小数</i> （&#39;ブリッジスプラインの種類&#39;が&#39;キュービックベジェ&#39;に設定されている場合に使用可能） | 生成されたすべてのスプラインのスプライン#2上の終点の&#39;in&#39; 正接の長さ。 |
| <b>接線の回転開始</b> <i>浮動小数</i> （&#39;ブリッジスプラインの種類&#39;が&#39;キュービックベジェ&#39;に設定されている場合に使用可能） | 生成されたすべてのスプラインのスプライン#1の開始点の「out」正接の回転。<br>値はターン数です。 |
| <b>接線の回転の終了</b> <i>浮動小数</i> （&#39;ブリッジスプラインの種類&#39;が&#39;キュービックベジェ&#39;に設定されている場合に使用可能） | 生成されたすべてのスプラインのスプライン#2上の終点の&#39;in&#39; 正接の回転。<br>値はターン数です。 |
| <b>プレビュー</b> |  |
| <b>セグメント数</b> <i>整数</i> | プレビュー出力でスプラインのビジュアライゼーションを描画するために使用するセグメントの数を調整します。 値が大きいほど、線は滑らかになります。 |
| <b>方向ヘルパーの表示</b> <i>ブール値</i> | プレビュー出力で、スプラインの始点に点を表示し、終点に矢印を表示します。 |
| <b>Thicknessの封筒を表示</b> <i>ブール値</i> | スプラインのThicknessのエッジに追加の線分を表示します。 |
| <b>Thickness (px)</b> <i>フロート</i> | プレビュー出力のスプラインの表示Thicknessをピクセル単位で調整します。 |
