## 説明

入力リスト内のすべてのスプラインを横断するスプラインを、これらのスプラインに沿って生成します。

生成されるスプラインは、線形（直線）または二次ベジェ（曲線）になります。

</td>
</tr>
</table>

>[!TIP]
>
> 生成されたスプラインは、リストの最初のスプラインから最後のスプラインに移動し、リスト内のこれらのスプラインの順序に厳密に従って中間のスプラインを横断します。
> 
> したがって、事前にスプラインを追加する順序に注意する必要があります。

## 入力コネクタ

<b>プレビュー</b> *グレースケール*&#x200B;入力スプラインをグレースケールイメージとしてプレビューします。

<b>スプライン座標</b> *色*&#x200B;入力スプラインの点の座標は、カラー画像のRGBAチャンネルでエンコードされています：\
<b> R</b> - X位置\
<b> G</b> - Y位置\
<b> B</b> - Height\
<b>A</b> – パックされたデータ：\
*記号：スプラインが閉じている（負）か、開いている（正）;\
*絶対値：Thickness + 1。

<b>スプラインデータ</b> *色*&#x200B;カラー画像のRGBAチャンネルでエンコードされた入力スプラインの追加データです。\
<b> R</b> – 接線X\
<b> G</b> – 接線Y\
<b> B</b> – 未使用\
<b> A</b> – 未使用

<b>スプラインの量</b> *整数*&#x200B;入力スプラインの数です。

## 出力コネクタ

<b>プレビュー</b> *グレースケール*&#x200B;出力スプラインをグレースケールイメージとしてプレビューします。

<b>スプライン座標</b> *色*&#x200B;出力スプラインの点の座標は、色画像のRGBAチャンネルでエンコードされます。\
<b>R</b> - X位置\
<b>G</b> - Y位置\
<b>B</b> -Height\
<b>A</b> – パックされたデータ：\
*記号：スプラインが閉じている（負）か、開いている（正）;\
*絶対値：Thickness + 1。

<b>スプラインデータ</b> *カラー*&#x200B;カラー画像のRGBAチャンネルでエンコードされた出力スプラインの追加データ。\
<b>R</b> – 接線X\
<b>G</b> – 接線Y\
<b>B</b> – 未使用\
<b>A</b> – 未使用

<b>スプラインの量</b> *整数*&#x200B;出力スプラインの数です。

## パラメーター

<b>ブリッジスプラインの量</b> *整数*&#x200B;入力スプライン全体で生成されたスプラインの数です。

<b>ブリッジスプラインの種類</b> *整数*&#x200B;生成されるスプラインの種類：
* リニア：中間スプラインを開始から終了までの直線の軌道で接続する鋭いスプライン。
* 二次ベジェ：開始から終了まで滑らかな軌道を持つ中間スプラインを接続する曲線スプライン。\
  注記：二次ベジェスプラインを計算するには、少なくとも3つの入力スプラインが必要です。

<b>入力スプラインが閉じています</b> *ブール値*&#x200B;入力スプラインの最初の点と最後の点を1点として処理するかどうかを制御します。 これにより、最初と最後のトラバーススプラインが重複するのを防ぐことができます。

<b>方向を反転</b> *ブール値*&#x200B;スプラインの方向を反転します。

<b>ブリッジスプラインを閉じる</b> *ブール値*&#x200B;入力一覧の最初のスプラインに戻るように、トラバーススプラインを拡張します。

<b>最初のブリッジスプラインオフセット&#x200B;</b>*フロート2*&#x200B;トラバースしたすべてのスプラインの始点にオフセットを適用します。 この値は、入力スプラインの正規化された長さです。\
生成されたスプラインがトラバースされたスプラインの始点または終点に一致する場合は、そのまま残ります。

<b>最後のブリッジスプラインオフセット&#x200B;</b>*浮動小数点2*\
すべてのトラバーススプラインの終点にオフセットを適用します。 この値は、入力スプラインの正規化された長さです。\
生成されたスプラインがトラバースされたスプラインの始点または終点に一致する場合は、そのまま残ります。

<b>ランダムオフセット範囲</b> *整数*&#x200B;スプラインに適用されたランダムオフセットに使用される最大距離です。\
*– 親スプライン：*&#x200B;親スプラインの全長が使用されます。 オーバーラップの原因となる可能性があります。\
*– 間隔：*&#x200B;ブリッジスプライン間の間隔が使用されます。 これにより、重複が軽減されます。 この距離は、ブリッジスプラインの量が増えるにつれて減少します。

<b>開始ランダムオフセット</b> *浮動小数点*&#x200B;ブリッジスプラインの開始位置に適用されるランダムオフセットの乗数。最大距離は、<b>ランダムオフセット範囲</b>パラメーターで指定されます。

<b>ランダムオフセットの終了</b> *浮動小数点*&#x200B;ブリッジスプラインの終了位置に適用されるランダムオフセットの乗数。最大距離は、<b>ランダムオフセット範囲</b>パラメーターで指定されます。

<b>グローバルランダムオフセット</b> *浮動小数点*&#x200B;ブリッジスプラインの開始位置と終了位置の&#x200B;*両方*&#x200B;に適用されるランダムオフセットの&#x200B;*等量*&#x200B;の乗数。最大距離は<b>ランダムオフセット範囲</b>パラメーターで指定されます。

<b>均一な分布</b> *ブール値* Trueの場合、生成されたスプラインの点は、開始から終了まで等間隔になります。

+++厚み
<b>Thicknessモード</b> *整数*&#x200B;ブリッジスプラインのThickness値を取得する方式です。\
*– 親スプラインから継承：*&#x200B;ブリッジスプラインの開始位置と終了位置での親スプラインのThicknessが使用されます\
*– オーバーライド：* <b>Thickness</b>パラメーターで指定した任意の値が使用されます

<b>Thickness</b> *浮動小数点*&#x200B;ブリッジスプラインに適用される絶対Thickness値です。

<b>Thicknessランダム</b> *浮動小数*&#x200B;ブリッジスプラインのThicknessのランダム乗数。この乗数が適用される初期Thicknessは、<b>Thicknessモード</b>パラメーターで指定されます。

+++

+++高さ
<b>Heightモード</b> *整数*&#x200B;ブリッジスプラインのHeight値を取得する方式です。\
*– 親スプラインから継承：*&#x200B;ブリッジスプラインの開始位置と終了位置での親スプラインのHeightが使用されます\
*– オーバーライド：* <b>Height</b>パラメーターで指定した任意の値が使用されます

<b>Heightオフセット</b> *浮動小数*&#x200B;ブリッジスプラインにHeightが適用される前に、親スプラインから継承されたHeightに適用されるオフセットの量。

<b>Height</b> *浮動小数点*&#x200B;ブリッジスプラインに適用される絶対Height値です。

<b>Heightランダム</b> *浮動小数*&#x200B;ブリッジスプラインのHeightに対するランダムな調整です。調整は、選択した<b>Heightモード</b>パラメーターに依存します。\
*– 親スプラインから継承：*&#x200B;この値は、継承されたHeightの乗数です。\
*– オーバーライド：*&#x200B;この値は、Heightに追加されたオフセットです。

+++

<b>非正方形の修正&#x200B;</b>*ブール値*

点の位置とThicknessを調整して、非正方形の解像度でスプラインの形状を保持します。\
これは均一な分布にも影響を与えます。

+++プレビュー
<b>方向ヘルパーの表示</b> *ブール値*&#x200B;プレビュー出力のスプラインの始点に点を表示し、終点に矢印を表示します。

<b>Thicknessの封筒を表示</b> *ブール値*\
スプラインのThicknessのエッジに追加の線分を表示します。

<b>セグメント数</b> *整数*&#x200B;プレビュー出力でスプラインの視覚化を描画するために使用するセグメントの数を調整します。\
値が大きいほど、線は滑らかになります。

<b>Thickness (px)</b> *フロート*&#x200B;プレビュー出力のスプラインの表示Thicknessをピクセル単位で調整します。

<b>背景プレビューの適用度</b> *フロート*&#x200B;プレビューの視覚エフェクトの強さ。

+++
