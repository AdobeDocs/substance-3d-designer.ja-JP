<td width="100.00%" style="border: 0;" valign="top">

## 説明

入力の強さマップまたはベクトルマップに基づいて、入力スプラインを変位させます。

ワープエフェクトの強度は、減衰コントロールを使用してスプラインに沿って調整できます。

<a name="inputs"></a>

## 入力

|  |  |
|:---|:---|
| <b>プレビュー</b> <i>グレースケール</i> | 入力スプラインをグレースケールイメージとしてプレビューします。 |
| <b>スプライン座標</b> <i>色</i> | カラー画像のRGBAチャンネルでエンコードされた入力スプラインの点の座標：<br><b>R</b> - X位置<br><b>G</b> - Y位置<br><b>B</b> - Height<br><b>A</b> – パックデータ：<br> – 記号：スプラインが閉じている（負）か開いている（正）;<br> -絶対値: Thickness + 1。 |
| <b>スプラインデータ</b> <i>色</i> | カラー画像のRGBAチャンネルでエンコードされた入力スプラインの追加データ。<br><b>R</b> -正接X<br><b>G</b> -正接Y<br><b>B</b> – 未使用<br><b>A</b> – 未使用 |
| <b>スプラインの量</b> <i>整数</i> | 入力スプラインの数。 |
| <b>強度マップ</b> <i>グレースケール</i> | （[ベクトルマップを使用]が[False]に設定されている場合に使用可能）入力スプラインのワープ効果の方向と強さを制御するために使用される入力グレースケールイメージ。<br>イメージ内の各ピクセルの色により、スプラインの点を、イメージの全範囲に至るまで、法線（つまり、スプラインに垂直な方向）に沿って変位させるための乗数を指定します。<br>マルチプライヤ： 0と1を使用して読み込むと、イメージ内の[0; 1]の値が[-1; 1]の範囲に再マップされます。スプラインは、同じ距離だけ、反対方向に置き換えられます。 0.5は、スプラインを所定の位置に残します。 |
| <b>ベクターマップ</b> <i>グレースケール</i> | （[ベクトルマップを使用]が[True]に設定されている場合に使用可能）入力スプラインのワープ効果の方向と強度をコントロールするために使用される入力カラーイメージ。<br>画像内の各ピクセルの色は、赤(X)および緑(Y)のチャンネルでエンコードされる座標のベクトル(X、Y)を指定します。 +Xが右、+Yが下。<br>画像の[0; 1]の値は、ベクトル座標として読み込まれると、[-1; 1]の範囲に再マップされます。0は左に置き換え、0は上に置き換えます。 0.5赤と緑は、スプラインを所定の位置に残します。 |
| <b>減衰曲線</b> <i>グレースケール</i> | 1行目のピクセルの値を使用して曲線を表す画像。<br>減衰カーブの使用パラメータをTrueに設定すると、この入力を使用して、スプラインの開始付近と終了付近のワープ効果の減衰を制御します。<br>曲線は減衰のプロファイルを提供します。行の最初のピクセルはスプラインの始点でのワープ効果の強度で、最後のピクセルは終点での強度です。 グレースケールの値は適用度です。<br>曲線ノードを使用して曲線を作成できます。 |

<a name="outputs"></a>

## 出力

|  |  |
|:---|:---|
| <b>プレビュー</b> <i>グレースケール</i> | 出力スプラインをグレースケールイメージとしてプレビューします。 |
| <b>スプライン座標</b> <i>色</i> | 出力スプラインの座標がカラー画像のRGBAチャンネルにエンコードされました。<br><b>R</b> - X位置<br><b>G</b> - Y位置<br><b>B</b> - Height<br><b>A</b> – パックデータ：<br> – 記号：スプラインが閉じている（負）か開いている（正）;<br> -絶対値: Thickness + 1。 |
| <b>スプラインデータ</b> <i>色</i> | カラー画像のRGBAチャンネルでエンコードされた出力スプラインの追加データ。<br><b>R</b> -正接X<br><b>G</b> -正接Y<br><b>B</b> – 未使用<br><b>A</b> – 未使用 |
| <b>スプラインの量</b> <i>整数</i> | 出力スプラインの数。 |

<a name="parameters"></a>

## パラメーター

|  |  |
|:---|:---|
| <b>ワープの強さ</b> <i>フロート</i> | スプラインを移動する際の強度。 |
| <b>ワープの中心</b> <i>フロート</i> | スプラインを所定の位置に残すことに対応する強度マップの値を指定します。<br>値が0または1の場合、スプラインは片側にのみ変位させることができます。 |
| <b>サンプリングモード</b> <i>整数</i> | 強度マップまたはベクトルマップの値をスプラインにマッピングする方式：<br>- <i>テクスチャ空間</i>：値は、テクスチャのUV座標を使用してテクスチャに配置する場合にスプラインに適用されます。 これにより、値がスプラインに「その場で」適用されます。<br>- <i>スプラインに沿った水平</i>：値は、エンコードされたスプラインの座標に直接適用されます（「スプライン座標」の入力を参照）。ここで、各行は上から下まで異なるスプラインに適用されます。<br>- <i>Hor。 スプラインに沿って（ランダム偏差） オフセットX)</i>：値は、エンコードされたスプラインの座標に直接適用され（スプライン座標の入力を参照）、各スプラインのスケールマップ内のランダムな水平オフセット（スプライン座標の各行）で使用されます。<br>- <i>水平 スプラインに沿って（ランダム偏差） オフセットY)</i>：値は、エンコードされたスプラインの座標に直接適用され（スプライン座標の入力を参照）、各スプラインのスケールマップ内のランダムな垂直オフセット（スプライン座標の各行）を伴います。 |
| <b>ベクターマップを使う</b> <i>ブール値</i> | スプラインを置き換える方法を、ディスプレイスメントの方向を指定するベクトルマップ入力に切り替えます。<br>画像内の各ピクセルの色は、赤(X)および緑(Y)のチャンネルでエンコードされる座標のベクトル(X、Y)を指定します。 +Xが右、+Yが下。<br>画像の[0; 1]の値は、ベクトル座標として読み込まれると、[-1; 1]の範囲に再マップされます。0は左に置き換え、0は上に置き換えます。 0.5赤と緑は、スプラインを所定の位置に残します。 |
| <b>減衰曲線を使用</b> <i>ブール値</i> | 減衰カーブ入力画像でエンコードされたカーブを使用して、スプラインに沿ったワープエフェクトの強さを制御できます。 |
| <b>照度マップのタイル表示</b> <i>フロート</i> | （「サンプリングモード」が「テクスチャ空間」に設定されていない場合に使用可能）スプライン座標に直接マップする場合に、強度マップのタイリングを調整します（「スプライン座標」の入力を参照）。 |
| <b>減衰の開始</b> <i>フロート</i> | （[減衰曲線を使用]が[偽]に設定されている場合に使用可能）スプラインの開始付近でのワープ効果の減衰の乗数です。<br>1の値は、スプラインの開始にワープが適用されていないことを意味します。 |
| <b>減衰の終了</b> <i>フロート</i> | （[減衰曲線を使用]が[偽]に設定されている場合に使用可能）スプラインの端近くのワープ効果の減衰の乗数。<br>1の値は、スプラインの端にワープが適用されていないことを意味します。 |
| <b>接線を再計算</b> <i>ブール値</i> | Trueの場合、ワープ効果が適用された後にスプラインの正接が再計算されます。<br>これにより、スプライン上の散乱やスプラインフローマッパーなどのノードで使用する場合に、スプラインの正接が軌道と一致した状態を保つことができます。 |
| <b>プレビュー</b> |  |
| <b>セグメント数</b> <i>整数</i> | プレビュー出力でスプラインの視覚化に使用するセグメントの数を調整します。<br>値を大きくすると、より滑らかな線になります。 |
| <b>方向ヘルパーの表示</b> <i>ブール値</i> | プレビュー出力で、スプラインの始点に点を表示し、終点に矢印を表示します。 |
| <b>Thicknessの封筒を表示</b> <i>ブール値</i> | スプラインのThicknessのエッジに追加の線分を表示します。 |
| <b>Thickness (px)</b> <i>フロート</i> | プレビュー出力のスプラインの表示Thicknessをピクセル単位で調整します。 |
| <b>背景プレビューの適用度</b> <i>フロート</i> | 背景プレビューの入力画像に対して乗算される値。 |
