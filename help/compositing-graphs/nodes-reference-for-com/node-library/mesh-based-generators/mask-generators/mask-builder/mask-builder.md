# マスクビルダー

<table>
<tr style="border: 0;">
<td width="33.33%" style="border: 0;" valign="top">

<b>In:</b> メッシュベースのジェネレーター> マスクジェネレーター

</td>
<td width="100.00%" style="border: 0;" valign="top">

## 説明

ベイク済みマップとユーザー設定に基づいて白黒マスクを生成します。 これは、PainterのマスクビルダーのDesigner版とほぼ同じです。

これは、ベイク済みマップ、ユーザーパラメーター、経年劣化パターン、およびマップに基づいて、包括的なマスクビルダーとして意図された複雑なツールです。 主に、折り目のDirtとエッジの摩耗にブレンドする非常に高度なフルコントロールノードとして意図されています。 このノードは、他のすべてのマスクジェネレータを模倣できるほど強力です。

明示的に必要なパンはありませんが、供給すればするほど、このノードは実行できます。
