# マスクジェネレータ

このカテゴリには、黒と白のマスクを生成するノードの選択肢が含まれます。 ベイク済みマップ情報に基づいてマスクが生成され、それを使用してマテリアルやその他のエフェクトをブレンドできます。 これらのノードは、Substance Painterの[スマートマスク](https://experienceleague.adobe.com/ja/docs/substance-3d-painter/using/features/smart-materials-and-masks)および[ジェネレーター](https://experienceleague.adobe.com/ja/docs/substance-3d-painter/using/content/creating-custom-effects/generators)に似ています。

これらのノードはすべて[ベイク済みマップ、](../../../../../bakers/bakers.md)を必要とします。[ベイク済みマップ](../../../../../bakers/bakers.md)なしでは、あまり結果が得られません。

主な使用目的は、これらのマスクジェネレーターを[マルチチャンネルマテリアル](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/material-filters.md)と共に使用することです。 マスクが生成されると、[ブレンド](../../../../../compositing-graphs/nodes-reference-for-com/node-library/material-filters/blending-material/material-blend/material-blend.md)の描画マスクとして使用されます。

このカテゴリの対象となるノードは次のとおりです。

* [滴下錆](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/dripping-rust/dripping-rust.md)
* [エッジの損害賠償](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/edge-damages/edge-damages.md)
* [下から上](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/bottom-to-top/bottom-to-top.md)
* [マスクビルダー](../../../../../compositing-graphs/nodes-reference-for-com/node-library/mesh-based-generators/mask-generators/mask-builder/mask-builder.md)
