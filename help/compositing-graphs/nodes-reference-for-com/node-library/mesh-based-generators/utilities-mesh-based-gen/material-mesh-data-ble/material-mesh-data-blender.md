## 説明

このノードは、ベイク処理されたデータに基づいてディテールを簡単に追加できるようにすることを目的としています。 すべてのベイク済みマップを入力として使用し、入力全体のマテリアルを編集するためのスライダーが多数用意されています。 多くの選択肢があるので、試してみてください。

曲率やその他のマップに基づいてエッジハイライトを追加したり、拡散反射光/ベースカラーを使用して一部のAOをブレンドしたり、曲率やAOに基づいてオクルージョンを追加したりするのに便利です。

## パラメーター

### 入力

* **マテリアルの全入力（グループ「マテリアル」）:**&#x200B;マテリアルマップの完全なセット。\
  これらは、このノードによって変更され、再度出力として返されます。
* **環境オクルージョン**: *グレースケール入力*\
  内部エフェクトおよびマスクに使用されるベイク済みマップ。
* **曲率**: *グレースケール入力*\
  内部エフェクトおよびマスクに使用されるベイク済みマップ。
* **Height**: *グレースケール入力*
* **標準**: *カラー入力*
* **頂点カラー**: *カラー入力*
* **ワールドスペース標準**: *カラー入力*

### パラメーター

* **チャネル**
  * この領域でマテリアルチャンネルのオンとオフを切り替えます。たとえば、メタリック/ラフネスの代わりにSpecular/光沢マップを使用する場合などです。 以下のパラメーターの可用性に影響します。
* **ベイク済みマップ**
  * 表示されたベイク済みマップを計算に使用するかどうか。 以下のパラメーターの可用性に影響します。
* **拡散反射光AO**: *0.0 ～ 1.0*&#x200B;拡散反射光にブレンドする周囲オクルージョン量。
* **拡散反射光の鋭いエッジ**: 0.0 ～ 1.0\
  拡散にブレンドする曲率マップの量。
* **頂点カラーからの拡散反射光カラー**: 0.0 ～ 1.0\
  拡散にブレンドする頂点カラーベイク処理の量。
* **拡散反射光プリライティング**: 0.0 ～ 1.0\
  ワールド空間法線に基づく（フェイク）プリライティングの量。
* **拡散カートゥーンの照明バランス**: 0.0 ～ 1.0\
  拡散反射光のリアリスティック照明と漫画照明の間で切り替えます。
* **漫画用にレイヤーを事前に明るくする**: 0 ～ 10\
  カートゥーンライティングの計算の外観を制御します。
* **拡散するカートゥーンのアウトライン**: 0.0 ～ 1.0\
  カートゥーンライティングの計算の外観を制御します。
* **基本色AO**: 0.0 ～ 1.0\
  ベースカラーにブレンドするアンビエントオクルージョンの量。
* **基本色のシャープなエッジ**: 0.0 ～ 1.0\
  ベースカラーにブレンドする曲率マップの量。
* **頂点カラーからの基本カラー**: 0.0 ～ 1.0\
  ベースカラーにブレンドする頂点カラーベイク処理の量。
* **標準マテリアルの強度**: 0.0 ～ 1.0\
  ベイク処理された（接線）法線マップのブレンド強度。
* **鏡面反射光**: 0.0 ～ 1.0\
  Specularに対するAOのブレンド強度。
* **Specularの明るいシャープなエッジ**: 0.0 ～ 1.0\
  Specularの曲率のブレンド強度。
* **Specular漫画のアウトライン**: 0.0 ～ 1.0\
  曲率に基づく、アニメSpecularのエッジからアウトラインへの効果のブレンド強度。
* **光沢の暗いシャープなエッジ**: 0.0 ～ 1.0\
  光沢における曲率のブレンド強度。
* **明るいシャープなエッジの粗さ**: 0.0 ～ 1.0\
  粗さの曲率のブレンド強度。
* **カートゥーンのアウトラインの粗さ**: 0.0 ～ 1.0\
  曲率に基づいたカートゥーンの粗さエッジとアウトラインの効果のブレンド強度。
* **金属の明るくシャープなエッジ**: 0.0 ～ 1.0\
  メタリックの曲率のブレンド強度。
* **メタリックカートゥーンのアウトライン**: 0.0 ～ 1.0\
  曲率に基づいた、アニメのメタリックエッジのアウトラインエフェクトのブレンド強度。
* **AOマテリアルの強度**: 0.0 ～ 1.0\
  ベイク済みマップAOとマテリアルのブレンド強度 – 生成されたAO、で両方のAOマップを結合する程度。
* **Heightマテリアルの適用度**: 0.0 ～ 1.0\
  Heightの強度とマテリアルで生成されたHeightをブレンドし、両方のハイトマップをどの程度組み合わせるかを指定します。
* **Heightマテリアルのブレンドの種類**：強化、補間\
  両方のハイトマップを組み合わせるための描画モード。
