# Tutorials学習

ドキュメントは主に、完全な技術的なリファレンスを提供することを目的としています。 ビデオや他のより焦点を絞った学習教材を使用したい場合は、これらのチュートリアルが役立ちます。

## 最初のステップ

Designerを使って最初の一歩を踏み出すことに焦点を当てた初級レベルシリーズ。 UIと基本的な概念を紹介し、次に主要なテクニックに移り、最後にパラメーターを公開し、完全なマテリアルを構築する方法について説明します。 短くて焦点が絞られていますが、物事を軽く保つので、初心者にとっては最高のスタートです。

### 最初のマテリアルを作成する

大規模なスタータービデオシリーズでは、広範で完全にプロシージャルなマテリアルを作成するプロセス全体を通して説明します。 プロセスのすべてのステップがカバーされ、説明されているので、あなたは完了時に多くを学ぶでしょう、しかし、絶対的な初心者のために集中することができます。
