# Substance 3Dファイルとは

![パラメトリックレンガ壁マテリアル](what-is-a-substance-3d-file.resources/what-is-a-substance-3d-file-01.gif "パラメトリックレンガ壁マテリアル")

*Käy Vriendが作成したレンガの壁のマテリアルの例\
パラメーターを変更して、マテリアルの外観を動的に制御できます。*

Substance 3Dファイルは、多くのアプリケーションで直接使用できるダイナミックテクスチャジェネレータです。

これは動的な処理です。従来のビットマップファイルとは異なり、Substance 3Dファイルの作成者は、<b>パラメーターの表示</b>を選択して、生成される最終結果の<b>制御</b>を指定できます。

例えば、物体のDust量やサッカーチームのジャージの色を変えることができる。 自分の才能と想像力が、自分にできることに対する唯一の限界だ。

Substanceの素材を公開して、<b>Substance 3Dエンジン</b> （*Unity*&#x200B;や&#x200B;*Unreal Engine*&#x200B;など）を統合する<b>外部アプリケーション</b>で使用できます。

Substance 3Dのマテリアルは&#x200B;*100%プロシージャル*&#x200B;であるため、出力サイズは非常に明るくなります。
