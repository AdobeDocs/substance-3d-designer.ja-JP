## ショートカットリスト

### グローバル

| アクション | Windows | macOS |
|:-------------------------------------------------------------------------------------------------------------------|:----------|:------|
| [新しいSubstanceグラフ](../../compositing-graphs/creating-compositing-gra/creating-a-substance-compositing-graph.md) | Ctrl + N | ⌘ + N |
| パッケージを読み込み | Ctrl + O | ⌘ + O |
| 選択したパッケージを閉じる | Ctrl + F4 | ⌘ + W |
| パッケージを保存 | Ctrl + S | ⌘ + S |
| 取り消し | Ctrl + Z | ⌘ + Z |
| やり直す | Ctrl + Y | ⌘ + Y |

### グラフビュー

**ビューポート**

| アクション | Windows | macOS |
|:-----------------------------------------------------------------------------------|:---------------------------------------|:-------------------------------------|
| ズーム | マウスホイール<br>Alt + RMBキーを押しながらドラッグ | MouseWheel<br>⌥ + RMBキーを押しながらドラッグ |
| 高速ズーム | ⇧ +マウスホイール<br>⇧ + Alt + RMB +ドラッグ | ⇧ +マウスホイール<br>⇧ + ⌥ +右マウスボタンを押しながらドラッグ |
| パン | MMB +ドラッグ<br>Ctrl + RMB +ドラッグ | MMB +ドラッグ<br>⌘ + RMB +ドラッグ |
| ズームをリセット | Z | Z |
| ビューに合わせる | F | F |
| コピー | Ctrl + C | ⌘ + C |
| ペースト | Ctrl + V | ⌘ + V |
| コンテキストメニュー | RMB | RMB |
| ノードメニュー | スペースバー | スペースバー |
| [ナビゲーションピン](../../interface/the-graph-view/graph-items/graph-items.md)を切り替える | F2 | F2 |

{style="table-layout:fixed"}

**リンク作成モード**

>[!NOTE]
>
> このドキュメントの[このページ](../../interface/the-graph-view/link-creation-modes/link-creation-modes.md)のリンク作成モードについて説明します。

| モード | Windows | macOS |
|:-----------------|:--------|:------|
| 標準 | 1 | 1 |
| マテリアル | 2 | 2 |
| コンパクトマテリアル | 3 | 3 |

{style="table-layout:fixed"}

**グラフでオブジェクトが選択されたとき**

| アクション | Windows | macOS |
|:------------------------------------|:-------------|:----------|
| 選択範囲をコピー | Ctrl + C | ⌘ + C |
| 選択範囲を複製 | Ctrl + D | ⌘ + D |
| リンクなしで複製 | Ctrl + ⇧ + D | ⌘ + ⇧ + D |
| 選択範囲を削除 | 削除 | 削除 |
| 選択範囲を削除してリンクを保持 | ⌫ | ⌫ |
| ノードのドッキング/ドッキング解除 | D | D |
| ノードを無効にする | ⇧ + D | ⇧ + D |

{style="table-layout:fixed"}
