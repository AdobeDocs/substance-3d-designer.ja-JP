## ショートカットリスト

### グローバル

| アクション | Windows | macOS |
| --- | --- | --- |

| やり直す | Ctrl + Y | ⌘ + Y |

### グラフビュー

<b>ビューポート</b>

| アクション | Windows | macOS |
| --- | --- | --- |
| ズーム | MouseWheel Alt + RMB +ドラッグ | マウスホイール⌥ +右マウスボタンを押しながらドラッグ |
| 高速ズーム | ⇧ + MouseWheel ⇧ + Alt + RMB +ドラッグ | ⇧ + MouseWheel ⇧ + ⌥ + RMB +ドラッグ |
| パン | MMB +ドラッグCtrl + RMB +ドラッグ | MMB +ドラッグ⌘ +元のファイル+ドラッグ |
| ズームをリセット | Z | Z |
| ビューに合わせる | F | F |
| コピー | Ctrl + C | ⌘ + C |
| ペースト | Ctrl + V | ⌘ + V |
| コンテキストメニュー | RMB | RMB |
| ノードメニュー | スペースバー | スペースバー |
| [ナビゲーションピン](../../interface/the-graph-view/graph-items/graph-items.md)を切り替える | F2 | F2 |

<b>リンク作成モード</b>

>[!NOTE]
>
> このドキュメントの[このページ](../../interface/the-graph-view/link-creation-modes/link-creation-modes.md)のリンク作成モードについて説明します。

| モード | Windows | macOS |
| --- | --- | --- |
| 標準 | 1 | 1 |
| マテリアル | 2 | 2 |
| コンパクトマテリアル | 3 | 3 |

<b>グラフでオブジェクトが選択されたとき</b>

| アクション | Windows | macOS |
| --- | --- | --- |
| 選択範囲をコピー | Ctrl + C | ⌘ + C |
| 選択範囲を複製 | Ctrl + D | ⌘ + D |
| リンクなしで複製 | Ctrl + ⇧ + D | ⌘ + ⇧ + D |
| 選択範囲を削除 | 削除 | 削除 |
| 選択範囲を削除してリンクを保持 | ⌫ | ⌫ |
| ノードのドッキング/ドッキング解除 | D | D |
| ノードを無効にする | ⇧ + D | ⇧ + D |
