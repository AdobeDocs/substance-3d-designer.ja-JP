## ショートカットリスト

### グローバル

| アクション | Windows | macOS |
|:------------------------|:-------------|:-------------|
| 新規 Substance グラフ | Ctrl + N | ⌘ + N |
| パッケージを読み込み | Ctrl + O | ⌘ + O |
| パッケージを保存 | Ctrl + S | ⌘ + S |
| すべてのパッケージを保存 | Ctrl + ⇧ + S | ⌘ + ⇧ + S |
| 取り消し | Ctrl + Z | ⌘ + Z |
| やり直す | Ctrl + Y | ⌘ + Y |
| コンテキストメニュー | RMB | RMB |
| ドックを最大化 | ⇧ +スペースバー | ⇧ +スペースバー |
| エンジンを切り替え | F9 | F9 |
| エンジンを一時停止 | ⇧ + Escape | ⇧ + Escape |

{style="table-layout:fixed"}

### グラフビュー

**ビューポート**

| アクション | Windows | macOS |
|:----------------------|:---------------------------------------|:-------------------------------------|
| ズーム | マウスホイール<br>Alt + RMBキーを押しながらドラッグ | MouseWheel<br>⌥ + RMBキーを押しながらドラッグ |
| 高速ズーム | ⇧ +マウスホイール<br>⇧ + Alt + RMB +ドラッグ | ⇧ +マウスホイール<br>⇧ + ⌥ +右マウスボタンを押しながらドラッグ |
| パン | MMB +ドラッグ<br>Ctrl + RMB +ドラッグ | MMB +ドラッグ<br>⌘ + RMB +ドラッグ |
| ズームをリセット | Z | Z |
| ビューに合わせる | F | F |
| コピー | Ctrl + C | ⌘ + C |
| ペースト | Ctrl + V | ⌘ + V |
| 検索 | Ctrl + F | ⌘ + F |
| ノードメニュー | スペースバー | スペースバー |
| ナビゲーションピンを切り替え | F2 | F2 |

{style="table-layout:fixed"}

**選択範囲を作成しています**

| アクション | Windows | macOS |
|:--------------------------|:-------------------|:---------------|
| 「追加」を選択 | Ctrl + A | ⌘ + A |
| 選択状態を切り替え | Ctrl + LMB | ⌘ + LMB |
| 選択範囲の選択（追加） | Ctrl + LMBキーを押しながらドラッグ | ⌘ + LMB +ドラッグ |
| 選択範囲(減算) | Shift + LMB +ドラッグ | ⇧ + LMB +ドラッグ |

{style="table-layout:fixed"}

**選択したアイテム上**

| アクション | Windows | macOS |
|:------------------------------------|:-------------|:----------|
| 選択範囲をコピー | Ctrl + C | ⌘ + C |
| 選択範囲を複製 | Ctrl + D | ⌘ + D |
| リンクなしで複製 | Ctrl + ⇧ + D | ⌘ + ⇧ + D |
| 選択範囲を削除 | 削除 | 削除 |
| 選択範囲を削除してリンクを保持 | ⌫ | ⌫ |
| ノードのドッキング/ドッキング解除 | D | D |
| ビューに合わせる | F | F |
| 参照グラフを開く | ⌘ + E | ⌘ + C |
| ノードを水平方向に整列する | H | H |
| ノードを垂直方向に整列 | V | V |
| グリッドへのノードのスナップ | S | S |

{style="table-layout:fixed"}

**ノード接続**

| コネクターの訴え | Windows | macOS |
|:---------------------|:-----------|:--------|
| 接続を移動 | ⇧ + LMB | ⇧ + LMB |
| 同じソースから新規 | Ctrl + LMB | ⌘ + LMB |
| 接続を削除 | Alt + LMB | ⌥ + LMB |

{style="table-layout:fixed"}

| リンクに対するアクション | Windows | macOS |
|:---------------------------------|:----------|:--------|
| リンクを切り替える（一度に2つのリンク） | X | X |
| ドットノードを追加 | Alt + LMB | ⌥ + LMB |

{style="table-layout:fixed"}
