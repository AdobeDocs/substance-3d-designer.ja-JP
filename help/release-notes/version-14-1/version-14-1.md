# バージョン14.1

このアップデートには、Substance 3D Designerの日常使用を強化する新機能が導入されています。グラフのレイアウトをすばやく改善するためのノード配置ツール、パラメータセットを別のノードに適用するためのパラメーターのコピー&amp;ペースト、グラフのデバッグ中に特定のピクセルをトラッキングするための2Dビューのピクセルピンが含まれています。 また、主にスプラインノードセットとパスノードセットを完成させるために、新しい内容も追加されます。

*リリース日：2025年1月14日*

![スプライン上の散乱スプライン](../../assets/fond.png)

## スプラインとパスの更新

スプラインとパスノードは、バージョン13.0で導入されました。皆様からのフィードバックにより、一連の改良を行いました。 最初に、[[スプライン上の散乱スプライン]](../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/scatter-splines-splines/scatter-splines-on-splines.md)ノードを追加しました。このノードは、親スプラインに沿ってスプラインを分配し、通常の散乱ノードと同様のオプションを提供します。 さらに、[パスへのマスク](../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/path-tools/mask-to-paths/mask-to-paths.md)ノードが強化され、パス上の最初の頂点の位置をより詳細に制御できるようになりました。 また、[スプラインブリッジリスト](../../compositing-graphs/nodes-reference-for-com/node-library/spline-paths-tools/spline-tools/spline-bridge-list/spline-bridge-list.md)ノードにランダム性を導入できるようにしました。

## ノード整列ツール

グラフをクリーンで読みやすいものに保ちたい場合は、[ノードアライメントツール](../../interface/the-graph-view/node-alignment-tools/node-alignment-tools.md)が役立ちます。このツールは完全に刷新されました。 ノードを（水平または垂直に）均等に配置できるようになりました。また、ノードを整列すると、ノードを正確に積み重ねることで重なり合う必要がなくなります。 チェリーを上に：両方の機能は、ノードの実際のサイズを考慮に入れています！

![ノードの整列](../../assets/alignment.gif){zoomable="yes"}

## パラメーターのコピーとペースト

[あるノードのパラメーターをコピーして別のノードに貼り付ける](../../compositing-graphs/manage-parameters/manage-parameters.md)ことができるようになりました。これにより、ターゲットノードで一致するすべてのパラメーターがソースノードの値に更新されます。 これは、カラーノードのパラメータをグレースケールに、またはその逆に引き継ぐ場合などに非常に便利です。 （例：「タイルSampler」ノード）

## 2D ビューでピクセルをピン留め

2Dビューの新しい[カラーSamplerツール](../../interface/2d-view/color-sampler/color-sampler.md)を使用すると、選択したピクセルにピンをドロップして、そのピクセルの値をトラッキングできます。 これは、グラフ内の複数のノードにわたる同じピクセルの情報を常に表示する場合に非常に便利です。 情報パネルを開いてツールにアクセスし、試してみてください。

![カラーサンプラー：ツールを使用](../../assets/color-sampler-demo.gif "カラーサンプラー：ツールを使用"){width="640px" zoomable="yes"}

## 検索の改善

[ノードファインダー](../../interface/the-graph-view/node-finder/node-finder.md)ツールが少し改善されました：

* 再帰的モードを有効にして、より深い検索ができるようになりました。
* 完全に一致する用語を検索する場合は、ファジーモードを無効にすることができます。
* ノードファインダーツールを有効にすると、検索フィールドにフォーカスが自動的に設定されます。
* スペースを節約するために、ツールバーのレイアウトが見直されました。

![ツールバーの検索](../../assets/search-53.png){width="640px"}
