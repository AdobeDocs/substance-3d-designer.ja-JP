# バージョン2019.3(9.3)

**Substance Designer 2019.3**&#x200B;では、OpenColorIOをサポートするカラーマネジメントが導入され、パン屋のアップデートが改善され、新しいAtlas Scatterーノードが追加されました。

リリース日： *2019年12月19日*

## 主な機能

### カラーマネジメントとOpenColorIOのサポート

![](../../../assets/banner-color-management.jpg)

Substance Designerは、カラーマネジメントをサポートするようになりました。これにより、カラーの解釈と変形の方法を制御できます。 この機能は、エンターテイメントやVFX業界で広く使用されているカラーマネジメントシステムである[OpenColorIO](https://opencolorio.org/)をサポートしています。

* **メイン設定でのカラーマネジメントの設定**\
  デフォルトでは、Substance Designerは「レガシー」モードに設定されます。つまり、特定の設定は読み込まれず、以前と同様に動作し続けます。 例えば、OpenColorIOに切り替えるには、メイン設定に移動し、プロジェクト設定で構成して有効にします。

  ![](../../../assets/sd-color-management-settings.png){width="600px"}
* **カラーマネジメントは3つの異なる方法で適用されます**\
  アプリケーションの各部分が受け取るカラーマネジメントは、それぞれ異なる意味を持ちます。

  * **2Dおよび3Dビュー**\
    リアルタイムの開いたビューポートとRayの両方をカラーマネジメントできます。 これにより、マテリアルとテクスチャリングを状況に応じてプレビューできます。 カラープロファイルは、専用のドロップダウンから簡単に切り替えることができます。 カラー補正なしでプレビューするために、リニアガンマでビューを表示することもできます。

    ![](../../../assets/color-2d-view.png){width="400px"}

    ![](../../../assets/color-3d-view.png){width="400px"}
  * **グラフの入力と出力およびビットマップの書き出し**\
    カラーマネジメントを使用すると、グラフの最初と最後でビットマップ画像の読み書きを行うときに、画像を調整して変換し、適切な条件で動作させることができます。 これは、グラフのビットマップのメイン環境設定で制御でき、書き出しプロセス中に書き出しダイアログで変更できます。 2Dビューから画像を保存すると、カラースペースを選択することもできます。

    ![](../../../assets/color-export-outputs.png){width="400px"}

    ![](../../../assets/color-export-2d.png){width="505px"}

### Mesh Bakerの新規曲線

![](../../../assets/banner-curvature-1.png)

メッシュベイカーの曲率がゼロから再作成されました。 レイトレーシングを利用してGPUアクセラレーションを利用できるようになりましたが、メッシュ交差のサポートも追加されました。

詳しくは、[メッシュからの曲率](https://experienceleague.adobe.com/en/docs/substance-3d/bakers/bakers-settings/curvature-from-mesh)のドキュメントを参照してください。

>[!NOTE]
>
> 以前のメッシュベイカーの曲率は非推奨になりました。 新しいバージョンに切り替えることをお勧めします。

### Mesh Bakerの環境オクルージョンの向上

![](../../../assets/banner-ao-v2.png)

[メッシュから環境オクルージョン]ベイカーには、「グリッド」という新しい設定が追加されました。この設定は、メッシュの下にある平面をシミュレーションして地面のオクルージョンを生成します。 これにより、静的なジオメトリや非有機的なオブジェクトに対してより興味深い外観の結果を得ることができます。 グリッドは、デフォルトではメッシュのバウンディングボックスの下部にありますが、専用の設定を使用してさらに押し出すことができます。

詳細については、[メッシュの環境オクルージョン](https://experienceleague.adobe.com/en/docs/substance-3d/bakers/bakers-settings/ambient-occlusion-from-mesh)のドキュメントを参照してください。

### 改善されたプロパティとプリセットエディター

![](../../../assets/banner-presets.png)

プリセットエディターと同様にプロパティエディターが改善されました。

* **高速プレビューモード**\
  グラフパラメーターを編集する際にプレビューモードに切り替えるほうが、特に公開パラメーターの多いグラフでより高速になりました。 プレビューモードは、パラメーターエディターとそのプレビューを簡単に切り替えることができる専用タブになりました。
* **修正されたプリセットエディター**\
  プリセットをSubstance Designerで管理する方法が、はるかに簡単かつ迅速になりました。プリセットエディターに専用のタブが追加され、各プリセットに影響するパラメーターが一覧表示されるようになりました。
* **2D変形ギズモを考慮した場合に表示**\
  変換2DギズモにVisible If条件がある場合、2Dビューで非表示にして、パラメータに対してコンテキストを持たせることができます。

### 新規コンテンツ

![](../../../assets/banner-content-8.jpg)

このバージョンでは、新しい&#x200B;**Atlas Scatter**&#x200B;ノードについて説明します。 このノードは、アトラス画像（サブ画像を含む画像）を読み取り、その内容を自動的に個々のコンポーネントに分離して、ランダムに散乱させることができます。 このノードは、たとえば、Dirtの地表マテリアルに枝や葉を配置するために使用できます。 [Substance Source](https://source.substance3d.com/allassets?q=atlas)には、この新しいノードで散在できる多くのアトラスマテリアルが含まれています。

>[!WARNING]
>
> このリリースではCentOS 6.xがサポートされなくなりました。\
> CentOS 7.xでは、一部の依存関係の問題が原因でアプリケーションが起動しない場合があります。この問題を解決するには、システムを更新するか、インストールフォルダーに[次のライブラリ](https://centos.pkgs.org/7/centos-x86_64/freetype-2.8-12.el7.x86_64.rpm.html)をコピーします。
