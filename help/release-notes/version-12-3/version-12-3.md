# バージョン 12.3

<b>Substance 3D Designer 12.3</b>では、<b>サブグラフのサポート</b> （またはグラフインスタンス）に加えて、<b>により、Substanceモデルのグラフが新しいレベルに変わります トーンカーブ編集専用のノードおよび一部<b>個の新しい表示されるパラメーター</b>の&#39;Visible if&#39; </b>コントロール。 このバージョンでは、ユーザーオンボーディングを改善するための2つの新しいパネル（<b>ようこそ</b>と<b>新機能</b>）や、以下で説明するその他のマイナーな機能またはバグ修正も導入されています。

リリース日： *2022年10月6日*

![](version-12-3.resources/largef.png){width="1111px"}

## 主な機能

### Substanceモデルグラフでのグラフインスタンスのサポート

グラフの作成に慣れているユーザーは、サブグラフ（またはグラフインスタンス）を作成して作業を再利用できるようにし、グラフを整理して効率的にしたいと考えています。\
Substanceモデルグラフでも使用できるようになりました。エクスプローラーからメイングラフにサブグラフをドラッグ&amp;ドロップして、インスタンス化として使用します。

![](version-12-3.resources/subgraph.gif){width="600px"}

また、出力シーンなどのSubstanceモデルグラフの出力ノードの概念も導入しました。 これで、グラフに1つ以上の出力を設定できるようになりました。\
各出力は、グラフを別のグラフでインスタンス化する際の出力ピンに対応しています。

![](version-12-3.resources/image2022-10-4-15-31-27.png){width="600px"}

インスタンス化を右クリックすると、もちろん参照サブグラフにアクセスして表示や編集を行うことができます。

![](version-12-3.resources/image2022-10-4-16-28-36.png){width="600px"}

サブグラフと表示されるパラメーターのおかげで、complexeアセットを作成し、以下の図に示すように無限のバリエーションを適用できます。

![](version-12-3.resources/seasons.gif){width="600px"}

### Substanceモデルグラフのその他の機能強化

* <b>表示されるパラメーターの場合に表示する</b>\
  パラメーターを表示する際に、他のパラメーターのステータスに基づいてパラメーターを非表示または表示することができます。 例えば、ボタンがオンの場合にのみ表示されるスライダーです。\
  <b>Visible If</b>を使用すると、パラメーターの可視性に条件を追加して、クリーンで機能的なUIを維持できます。 グラフで既に使用可能なこのメカニズムは、Substanceモデルグラフにも拡張されました。もちろん同じシンタックスを使用します。<b>\
  </b>

  ![](version-12-3.resources/visibleif.gif){width="600px"}

* <b>カーブエディション専用の新しいノード\
  </b>カーブ編集専用の新しい節点が追加されました。<b>カーブを反転</b>してカーブの両端を入れ替え、<b>カーブを分割</b>して2つの方式に従ってセグメントの頂点を増やします。<b>カーブを滑らかにする</b>2Dカーブのすべての角度を滑らかにし、最後に<b>カーブをオフセット</b>して、次に示すように2Dカーブを膨張またはさせます。<b>

  </b>

  ![](version-12-3.resources/curve-offset-4.gif){width="600px"}
* <b>新しいグラフウィンドウ</b>\
  <b>新しいSubstanceモデルグラフ</b>ウィンドウは、Substanceモデルグラフでも使用できるようになりました。 独自のテンプレートを追加することも、デフォルトのテンプレートを選択することもできます。その後、グラフの名前を直接入力し、グラフの追加先となるパッケージを選択します。

  ![](version-12-3.resources/image2022-10-5-15-25-42.png){width="600px"}

### ようこそパネルと新機能パネル

Designerの使用を開始するのに役立つ2つの新しいパネルが導入されました。

まず、<b>ようこそ</b>パネルは、*Designerを初めて起動*&#x200B;したときに表示されます。このパネルでは、ソフトウェアの概要とSubstance 3Dエコシステムにおけるその役割について説明します。 次に、Designerの&#x200B;*新しいバージョン*&#x200B;を初めて実行したときに表示される<b>新機能</b>パネルに、このバージョンで導入された主な機能がすぐに表示されます。

これら2つのパネルには、ヘルプメニューからもアクセスできます。

![](version-12-3.resources/image2022-10-3-15-47-28.png)

![](version-12-3.resources/image2022-10-3-15-47-55.png)

### その他

* <b>表示されたブール型パラメーターの2つのボタンウィジェット</b>\
  グラフにブール値パラメーターを表示する新しい方法が追加されました。 [切り替え]ボタンに加えて、カスタムテキストで<b>並べて表示ボタン</b>を使用して、ブール値パラメーターによって駆動される2つの異なるモードを見やすくすることができます。
* <b>高DPI画面のスケーリングの問題を解決する</b>\
  以前のバージョンでは、Designerはオペレーティングシステムで設定されたスケーリング係数を正しく処理できませんでした。 下の図からわかるように、すべてのフォントとボタンを一貫したサイズで表示し、125%の拡大率を備えた4Kディスプレイですべてが完全に管理されています。\
  この新しいバージョンでは、使用可能なインターフェイスを持つためにこのオプションは必要ないため、環境設定の「高DPIを無効にする」オプションが&#x200B;*False*&#x200B;にリセットされました。

  ![](version-12-3.resources/highdpi-fix.gif){width="600px"}

* **SteamバージョンのApple Siliconネイティブサポート(M1 / M2)**\
  Designerの12.2バージョンは、M1やM2チップを使った新しいAppleマシンを完全にサポートした最初のバージョンでしたが、このサポートはSteamエディションには存在しませんでした。 今後、Designerのすべてのユーザーは、これらのマシンでより高速かつ効率的なエクスペリエンスを利用できるようになります。
