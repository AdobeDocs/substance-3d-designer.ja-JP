# バージョン 12.2

<b>Substance 3D Designer 12.2</b>では、Appleシリコンマシン(M1)のネイティブサポート、Substanceモデルグラフの機能強化、その他の小規模なアップデートが提供されます。 このページでは、この新しいバージョンに関するすべての詳細を説明します。

リリース日： *2022年7月19日*

![](../../assets/final3.png)

## 主な機能

### Apple silicon(M1)チップのネイティブサポート

Designerの12.2バージョンは、M1チップを搭載した新しいAppleマシンをネイティブにサポートする最初のバージョンです。 Designerは以前は技術的にはAppleシリコンデバイスで実行できましたが、ネイティブサポートにより、より高速で効率的なエクスペリエンスが実現します。 以下の画像からわかるように、これらのコンピューターでこの新しいバージョンを使用すると、計算が&#x200B;*最大2倍高速*&#x200B;になります。

![](../../assets/ds-perf-applem1.png){width="600px"}

### Substanceモデルグラフの機能強化

* ノード上の<b>ツールチップ\
  </b>ノードの機能を説明するために、アイコンとタイトルだけしか使用できない場合があります。そのため、ライブラリまたはグラフビューを使用しているときに、*ノードの完全な説明*&#x200B;を示すツールヒントが表示されました。 探しているノードを見つけたり、その機能を理解したりするのに役立ちます。![](../../assets/tootlipnode.png)

* <b>ノード作成のショートカット\
  </b>よく使うノードの作成を高速化するために、他の種類のグラフと同様に、環境設定で独自のショートカットを定義できるようになりました。![](../../assets/shorcuts.png)

* <b>ノードコンテキストメニューのプレビューノード\
  </b>最新のリリースでは、キーボードショートカット（*Shiftキーを押しながらノードをクリック*）を使用して、3Dビューでノードをプレビューできるようになりました。 この機能は、より見つけやすくするために、*ノードコンテキストメニュー*&#x200B;からも利用できるようになりました。

  ![](../../assets/previewnode.gif){width="600px"}
* <b>ノードの互換性に基づく検索\
  </b>ノードメニューからノードを探している場合（グラフビューで&#x200B;*スペースバー*&#x200B;を押すとアクセスできます）、グラフで&#x200B;*現在選択されているノード*&#x200B;と互換性があるノードのみを表示するように、ノードが正しくフィルターされるようになりました。 探しているノードをすばやく見つけるのに役立ちます。

### その他

* <b>2Dビューの改善</b>\
  以前のバージョンでは、Substanceグラフの&#x200B;*コンテキストメニュー*&#x200B;を使用して3Dビューでグラフの出力を表示できましたが、2Dビューでグラフ出力を表示することはできませんでした。 このオプションはこのメニューに追加され、2Dビューに表示されるすべてのグラフ出力を一覧表示するサブメニューを使用できるようになりました。\
  2D表示ツールバーの「出力を表示」ボタンも、動作をより明確にするために下矢印とツールチップで更新されました。\
  最後に、環境設定の「グラフを読み込むときにグラフを自動表示する」オプションが&#x200B;*2つの個別の設定*&#x200B;に分割されました（それぞれ2Dビューと3Dビュー）。グラフを読み込むときに、どのビューを開いて自動的に設定するかを制御できます。

* <b>CLOテンプレート</b>\
  CLOソフトウェアとの相互運用性を向上させるために、*新しい専用テンプレート*&#x200B;が追加されました。 CLOに素材を正しく読み込むために必要なすべての&#x200B;*メタデータ*&#x200B;がグラフに自動的に追加されます。

  ![](../../assets/clo.png){width="600px"}

* <b>VFXリファレンスプラットフォームの要件</b>\
  VFX Reference Platformは毎年、ソフトウェア間の互換性を最小限に抑えるために、VFX業界で使用されるツールとライブラリのバージョンのリストを公開しています。 通常どおり、これらのすべての推奨事項に従って&#x200B;*すべての依存関係を更新*&#x200B;します。
