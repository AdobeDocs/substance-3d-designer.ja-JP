# バージョン 13.1

<b>Substance 3D Designer 13.1</b>では、マテリアル作成のエクスペリエンスを向上させるために、主にフレームに関して、ノードグラフの品質が大幅に向上しています。 AxF形式を使用するユーザーの相互運用性ワークフローを可能にするAxF書き出しの追加もあります。

*リリース日： 2023年12月12日*

![Substance 3D Designer 13.1バナー](version-13-1.resources/version-13-1-01.png "Substance 3D Designer 13.1バナー")

## フレームの改善

フレームは、グラフを適切に整理し、読みやすくするための必須ツールです。 それが、この新しいバージョンでそれらを磨くことにした理由です。

### 自動拡張

グラフが大きくなると、フレームの内容の並べ替えが必要になる場合があります。 ノードを移動して追加するスペースを確保したり、コンテンツを読みやすくするためにより多くの間隔を空ける必要がある場合があります。 これらの調整を容易にするために、取り込んだオブジェクトを移動する際に、フレームを自動的に拡張できるようになりました。オブジェクトを移動する際に<b>Shift</b>を押したままにすると、オブジェクトが境界内に収まるようにフレーム境界線が自動的に調整されます。

![自動拡張](version-13-1.resources/version-13-1-02.gif)

### サイズをコンテンツに合わせる

グラフで調整を行っているときに、フレームの内容を適切に調整できない場合があります。 この新しいコマンドを使用すると、フレームの位置とサイズを自動的に調整して、コンテンツの範囲に合わせて、1つのミディアムグリッドセルの余白を調整できます。 枠に説明が付いている場合は、可能であれば、説明の横の空白を使用するように調整されます。

![fitsize](version-13-1.resources/version-13-1-03.gif)

### 詳細な説明

HTMLコードにより、フレームの説明内のテキストを書式設定できるようになりました。 これはコメントにも適用されます。

![richtext](version-13-1.resources/version-13-1-04.png)

### <b>...その他の機能</b>

再考されたものは数多くあります許容度の高いルールへの所属、フレームのサイズ変更が簡単なインタラクションゾーン、グリッド上のノードの位置がずれないようにルールをスナップする、鮮度を少し上げる視覚的な要素などです 詳しくは、フレームの[ドキュメント](../../interface/the-graph-view/graph-items/frame/frame.md)を参照してください。

## QOLの改善

* <b>ノードメニューの改善： </b>必要なノードを検索する際の時間を節約するために、ノードメニューを少し改善しました。 検索がより寛大になり、完全な一致がない場合でも結果が得られます。 また、上向き矢印を使用して、リストの最後のエレメントに直接アクセスできるようになりました。
* <b>ノードの配置： </b>グラフのレイアウトを最適化するには、この2つの小さな変更が役に立ちます。 あるグラフから別のグラフにノードをコピー/ペーストすると、ペーストされたノードはメイングリッドに整列するようになりました。 また、長いリンクにノードを追加すると、すべての状況でノードを表示できるように、このノードはリンクの表示部分の中央に配置されます。
* <b>2Dビューのオプション： </b>[2Dビュー](../../interface/2d-view/2d-view.md)を頻繁に使用する場合は、「市松模様を表示」、「ビューのサイズを維持」、「物理サイズを使用」、「表示タイル」などのオプションが保存されるため、新しい2Dビューを作成するときやDesignerを再起動するときに設定を変更する必要がありません。

AxFは[X-Rite](https://www.xrite.com/axf)の形式です。 デジタル設計ワークフロー全体を通じて、数値データを使用して複雑なマテリアル特性をキャプチャ、保存、編集、伝達する方法を提供します。 Designerの以前のバージョンでは、[AxFファイルをインポート](../../resources/axf-appearance-exchange/axf-appearance-exchange-format.md)して、並べて表示を改善したり、手続き型の効果を追加したりできましたが、変更を新しい.sbsarファイルとしてエクスポートする必要がありました。

この新しいリリースでは、AxFマテリアルを適切な位置で編集し、読み込まれたAxFファイルに新しいレイヤーとして[変更内容を書き出し](../../resources/axf-appearance-exchange/axf-appearance-exchange-format.md)る機能が導入されています。

## API

最後に、この13.1バージョンでは、さらに2つの可能性が追加され、引き続きPython APIが改善されています。

* <b>&#39;Visible if&#39;プロパティ： </b>グラフのパラメーター、入力および出力用にこのプロパティを設定できるようになりました。
* <b>グラフの順序Inputs/Output:</b> sdsbscompgraph::reorderGraphInputおよびsdsbscompgraph::reorderGraphOutputを使用して、必要に応じてパラメーターを整理します。

>[!NOTE]
>
> Designer 13.1はQt5をベースにした最後のメジャーバージョンで、次のメジャーバージョンはQt6にアップグレードされます。 カスタムプラグインに影響を与える可能性があります。
