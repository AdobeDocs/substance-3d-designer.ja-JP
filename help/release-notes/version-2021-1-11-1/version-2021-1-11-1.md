# バージョン 2021.1（11.1）

**Substance Designer 2021.1**&#x200B;では、Pantoneカラーのサポート、グラフのノードの無効化、テッセレーションされたメッシュの書き出しなどの新機能が追加され、QOLが向上しました。

リリース日： *2021年1月28日*

## 主な機能

### 新しいPantoneカラーのサポート

![](../../assets/header-pantone.jpg)

このリリースでは、Pantoneスポットカラーのサポートが追加されています。 Pantoneは、グラフィックデザイン、ファッションデザイン、マニュファクチャリングなど、様々な業界で使用される大きなカラーセットで知られています。 この新しい機能により、マテリアルのカラーを実際の値に合わせることがはるかに簡単になりました。 詳細については、専用の[ドキュメントページ](../../color-management/spot-colors-pantone/spot-colors-pantone.md)を参照してください。

>[!NOTE]
>
> これらの新しいPantoneカラーを使用するには、アプリケーションの環境設定でカラーマネジメント設定を&#x200B;**Adobe ACE**&#x200B;に設定する必要があります。

* **RGBの色とPantoneの色を選ぶ**\
  カラーピッカーには、カラーを編集できるモードを選択するオプションが追加されました。 デフォルトではRGBに設定されていますが、Pantoneブック（カラーライブラリ）に切り替えることもできます。 デフォルトでは複数のブックが含まれています。

  ![](../../assets/color-picker-mode.png)

  カラーピッカーモードを変更すると、選択したブックによって使用可能なカラーが定義されます。

  ![](../../assets/color-picker-pantone.png)

* **現在のブック内の色を検索する**\
  リストの一番上にあるテキストフィールドを使用すると、Pantoneブック全体で特定の色を検索できます。 他の本は調べられないので、何かを探す時には必ず切り替えてください。

  ![](../../assets/color-picker-pantone-search.gif)

* **適切な色を選んで探す**\
  カラーピッカーでは、画面上の任意のカラーを選択して、現在のブック内で最も近いカラーを検索できます。

  ![](../../assets/color-picker-pick-pantone.gif)

### グラフのノードを無効にする新機能

![](../../assets/header-disable-node.png)

このリリースでは、ノードを無効にして、グラフ内をパススルーする機能が追加されています。 これは、マテリアルを比較して繰り返し、特定のノードが最終結果にどのような影響を与えるかを確認する場合などに便利です。

ノードを無効にするには、ノードを右クリックして「**選択を無効にする**」を選択するか、キーボードショートカット&#x200B;**Shift + D**&#x200B;を押します。すべてのノードを無効にできるわけではありません。これは、いくつかの条件に依存します。 詳細については、次の[ドキュメントページ](../../interface/the-graph-view/the-graph-view.md)の専用セクションを参照してください。

![](../../assets/disable-node.gif)

### ビューポートから新しい[モザイク分割メッシュを書き出し]

![](../../assets/header-export-mesh.jpg)

3Dビューのテッセレーションされたメッシュは、複数のファイル形式でエクスポートできるようになりました。

これを行うには、**3Dビュー**&#x200B;で&#x200B;**ファイル/書き出し**&#x200B;シーンアクションを使用します。 詳細については、専用の[ドキュメントページ](../../interface/3d-view/3d-view.md)を参照してください。

![](../../assets/export-mesh.jpg){width="700px"}

### 全般的な改善

![](../../assets/header-misc-1.jpg)

このリリースでは、日々の業務に役立ついくつかの小さくても役に立つ改善と新機能が追加されています。

* **エンジンのメモリ予算の自動割り当て**\
  アプリケーションのRAMおよびVRAMの管理が改善され、使用可能なシステムメモリに合わせて調整しやすくなりました。 大量のVramを搭載したGPUで、オンボードメモリをさらに活用できるようになりました。

* **3Dビューは、新しい「physicalSize」セマンティックをサポートするようになりました。**\
  カスタムシェーダは、マテリアルの物理サイズを考慮してその動作を調整できるようになりました。 詳細については、アプリケーションに付属のシェーダを参照してください。

* **ライブラリからコンテンツを除外するための新しい設定**\
  ライブラリでは、特定のファイル拡張子や特定の名前パターンを除外できるようになりました（ワイルドカードをサポートしています）。 これにより、[ライブラリ](../../interface/the-library/the-library.md)ウィンドウ内の不要なコンテンツを無視できます。

* **ビットマップをエクスポートするときにフォルダーを作成する**\
  グラフからビットマップを書き出すときに、スラッシュを指定して、存在しない場合にフォルダーとサブフォルダーを作成できるようになりました。 これにより、グラフごとのビットマップを独自のフォルダーに整理できます。例えば、**プロジェクト/$（グラフ）/$（識別子）**&#x200B;を使用します。

* **SBSRenderは、Adobe ACEとICCプロファイルをサポートするようになりました**\
  Adobe ACEエンジンを使用する場合、SBSRenderプロセス（Automation Toolkitの一部）で適切なカラーマネジメントを使用してSubstance出力をレンダリングできるようになりました。
