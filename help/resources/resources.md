# リソース

「リソース」は、Substance 3D Designerパッケージの内容です。 マテリアルおよびテクスチャデータの構築、生成、プレビューに使用されます。 リソースは、グラフリソースと非グラフリソースの2つの主要なカテゴリに分割できます。 リソースの作成またはインポートに使用する方法は型によって異なります。[リンク、インポート、および新しいリソース](../resources/importing-linking-and-new/importing-linking-and-new-resources.md)に関する専用ページを参照して、この点をより深く理解できます。
