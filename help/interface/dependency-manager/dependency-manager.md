# 依存関係マネージャー

<b>依存関係マネージャー</b>を使用すると、パッケージのすべての依存関係を表示し、問題が発生した場合に検出して修復できます。

Explorerでパッケージを右クリックし、コンテキストメニューで「Dependency manager」オプションを選択すると、このファイルにアクセスできます。
