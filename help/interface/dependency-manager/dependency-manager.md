# 依存関係マネージャー

<b>依存関係マネージャー</b>を使用すると、パッケージのすべての依存関係を表示し、問題が発生した場合に検出して修復できます。

エクスプローラー内のパッケージを右クリックし、コンテキストメニューから「Dependency manager」を選択してアクセスすることができます。
