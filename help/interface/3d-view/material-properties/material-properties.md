# マテリアルのプロパティ

[3D ビュー](../../../interface/3d-view/3d-view.md)は、*シェーダー*と呼ばれるプログラムを使用してモデルの表面をレンダリングします。 シェーダーはマテリアルを定義します
モデルの外観のさまざまな側面に影響を与えるプロパティのリストを使用して、モデルに適用されます。

3D ビューの&#x200B;**マテリアル**&#x200B;メニューを使用すると、シーンの各マテリアルに使用されているシェーダーを確認できます。

<a name="openpbr"></a>

## OpenPBR

Designerでは、初期設定で[OpenPBR](https://academysoftwarefoundation.github.io/OpenPBR/) マテリアルモデルが使用され、異方性などのいくつかの複雑なエフェクトがサポートされています。
送信とファズ。

Designerに含まれているデフォルトの[グラフテンプレート](../../../compositing-graphs/creating-compositing-gra/creating-a-substance-compositing-graph.md#graph-templates)と[マテリアルサンプル](../../../compositing-graphs/creating-compositing-gra/creating-a-substance-compositing-graph.md#material-samples)は、すべてOpenPBRモデルに基づいています。

このシェーダーのプロパティは、[OpenPBRパラメーター参照](https://academysoftwarefoundation.github.io/OpenPBR/#parameterreference)に従い、ラスタライザー間で&#x200B;*共有*されます。
GPU パストレーサーおよびOpenGL [3Dレンダラー](../3d-renderers/3d-renderers.md)。

+++ UV

| パラメーター | タイプ | デフォルト | 説明 |
|---------------------------------|---------|----------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| タイリング | 浮動小数 | 1.0 | 1つのUVセル内でのテクスチャの繰り返し量。この場合、値を<br/>にすると、より多くのテクスチャの繰り返しが行われます。 |
| グラフからの物理サイズを有効にする | ブーリアン | 偽 | マテリアルを適切な尺度で表すために、グラフの[物理サイズ](../../../compositing-graphs/graph-parameters/graph-parameters.md)<br/>に従ってタイリングを自動調整します。 |
| UV スケール | Float2 | 1.0, 1.0 | タイリングのスケールをUとVの別々の係数で調整します。<br/>値を大きくすると、より多くのテクスチャ反復が得られます。 |

### 既存のグラフとの互換性

一部のマテリアルプロパティは、Designerに含まれている他のモデルと比較して使用識別子が異なります。
Designerでは、一部の識別子が自動的に照合され、デフォルトモデルとしてのOpenPBRとの互換性が確認されます。

## Adobe Standard Material

Adobe Standard Material(ASM)モデルはDesigner 11.2で導入されたもので、Designerのデフォルトシェーダーです
バージョン15.1まで。

Designerは新しいデフォルトモデルとしてOpenPBRに移行されますが、ASMは引き続き含まれ、そのプロパティも共有されます
ラスタライザー、GPU パストレーサー、OpenGL [3Dレンダラー](../3d-renderers/3d-renderers.md)全体。

モデルは、[こちら](https://experienceleague.adobe.com/ja/docs/substance-3d/general-knowledge/asm/adobe-standard-material)で文書化されています。

<a name="usdpreviewsurface"></a>

## UsdPreviewSurface

UsdPreviewSurfaceモデルの目的は、互換性を高める基本的な機能セットを使用してマテリアルをプレビューすることです
USDやHydraを含むレンダラー間

Designerでは、このマテリアルモデルはラスタライザーおよびGPU パストレーサー [3Dレンダラー](../3d-renderers/3d-renderers.md)でのみサポートされています。

モデルは、[こちら](https://openusd.org/dev/spec_usdpreviewsurface.html)で文書化されています。
